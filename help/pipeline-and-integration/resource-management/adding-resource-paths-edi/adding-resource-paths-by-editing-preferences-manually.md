# 수동으로 환경 설정을 편집하여 리소스 경로 추가

애플리케이션을 열지 않고도 사용자 정의 셸프 또는 에셋 경로를 추가할 수 있습니다.

이렇게 하려면 플랫폼별로 다르게 저장된 응용 프로그램 환경 설정을 편집해야 합니다. 추가한 새 선반은 기본 환경 설정의 선반 목록에 표시되어야 합니다. 자세한 내용은 이 페이지를 참조하십시오. [라이브러리 구성](../../../interface/settings/libraries-configuration.md)

>[!NOTE]
>
> 네트워크 경로가 지원되지 않습니다. 문제를 방지하려면 탑재된 경로를 사용해야 합니다. 참조: [네트워크에서 파일 로드](../../../technical-support/workflow-issues/project-issues/loading-files-from-a-network.md).
