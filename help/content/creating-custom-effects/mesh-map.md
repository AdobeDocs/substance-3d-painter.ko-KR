# 메시 맵

레이어에 효과를 추가할 때 메시 맵(구워진 텍스처)을 자동으로 연결하려면 특정 이름 지정 규칙을 따라야 합니다.

>[!NOTE]
>
> 입력 노드에서 **사용량** 또는 **식별자**&#x200B;를 사용할 수 있습니다(사용량에 우선 순위가 있음).

다음은 각 메시 맵에 대한 명명 규칙입니다.

| 메시 맵 | 사용 | 식별자 |
| --- | --- | --- |
| *주변 오클루전* | **ambientOcclusionBase** | **앰비언트\_오클루전** |
| *ID* | **id** | **id** |
| *곡률* | **곡률** | **곡률** |
| *표준* | **normalBase** | **일반\_기본** |
| *세계 우주 표준* | **normalWS** | **월드\_스페이스\_표준** |
| *위치* | **위치** | **위치** |
| *Thickness* | **Thickness** | **Thickness** |
| *Height* | **heightBase** | **Height\_기본** |
| *구부러진 표준* | **bentNormalsBase** | **구부러진\_정상\_기본** |
| *불투명도* | **opacityBase** | **불투명도\_기본** |
