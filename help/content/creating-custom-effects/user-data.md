# 사용자 데이터

이 페이지에서는 특정 동작을 실행하기 위해 Substance 그래프에 추가할 수 있는 사용자 정의 속성(사용자 데이터)에 대해 설명합니다.\
사용자 데이터 설정은 일반적으로 그래프의 입력 또는 출력 노드에 적용되어 응용 프로그램이 이를 해석하는 방법을 나타냅니다. 그러면 특정 색상 공간을 요청하는 것과 같이 알려진 컨텍스트에서 효과를 적용하기 위해 특정 방식으로 그래프를 입력하도록 요청하거나, 이후에 애플리케이션에서 추가 변환을 적용해야 하는 경우 출력이 어떻게 만들어졌는지 나타낼 수 있습니다.

* 데이터 설정 사용이 **키 = 값**(으)로 정의됨
* 여러 설정이 세미콜론(**;**)으로 구분됩니다.

## 색상 공간

**색상 공간** 설정을 사용하여 특정 색상 공간으로 Substance 그래프 입력을 요청하거나 특정 방식으로 구성된 출력을 정의할 수 있습니다. 예를 들어, 표준 맵 출력의 형식을 지정합니다.

구문 예: **colorspace=$working**

컨텍스트 개요:

* **색상 단추**: Substance 그래프의 속성에 있는 색상 단추 위젯입니다.
* **그래프 입력/출력**: 채널에 연결된 그래프의 입력 또는 출력 노드(예: BaseColor).
* **이미지 입력**: 특정 채널과 관련이 없는 그래프의 일반 입력입니다.

>[!NOTE]
>
> 색상 관리가 도입되면서 색상 공간 설정과 관련된 몇 가지 비헤이비어가 변경되었습니다.
> 
> * 아래 표에는 버전 8.1 이전과 호환되는 색상 공간 설정이 먼저 나열되어 있습니다. 두 번째 섹션은 버전 8.1 이상에만 해당합니다.
> * 색상 공간 설정을 사용할 수 있는 컨텍스트와 관련해서는 버전 8.1에서만 버튼을 사용하여 색상 공간을 정의할 수 있기 때문입니다. 이전 버전에서는 이 파일이 표시 공간(sRGB)에 있는 것으로 가정되었습니다.
> 
> **snorm** 및 **unorm** 색상 공간/변환은 GPU 텍스처 형식과 혼합하면 안 됩니다. 목적은 다릅니다.

| 색상 공간 | 컨텍스트 가용성 | 설명 |
| --- | --- | --- |
| **자동** | 색상 버튼 그래프 입력/출력 이미지 입력 | 기본값입니다. 애플리케이션은 입력 노드 속성 및 입력에 꽂힌 이미지에 따라 수행될 색상 공간 변환을 결정한다. |
| **선형** | 색상 버튼 그래프 입력/출력 이미지 입력 | 선형 감마/톤 곡선을 사용하는 표준 sRGB IEC 61966-2-1:1999 색상 공간입니다. **레거시** 색상 관리 모드에서만 사용할 수 있습니다. |
| **srgb** | 색상 버튼 그래프 입력/출력 이미지 입력 | 표준 sRGB IEC 61966-2-1:1999 색상 공간. **레거시** 색상 관리 모드에서만 사용할 수 있습니다. |
| **통과** | 색상 버튼 그래프 입력/출력 이미지 입력 | 사용되지 않습니다. 레거시 색상 관리 모드에서 **선형**, OCIO/ACE에서 **원시**(으)로 해석됩니다. 대신 **raw**(으)로 대체해야 합니다. |
| **스노움** | 그래프 입력/출력 이미지 입력 | 서명됨 정규화되었습니다. 입력 이미지를 [0, 1] 범위로 요청합니다. 8비트 입력 이미지의 경우 중간 값이 127임을 의미합니다. 부동 이미지 입력의 경우 가운데가 0.5이고 클램핑을 수행하지 않습니다. |
| **normalxyzright** | 그래프 입력/출력 이미지 입력 | OpenGL 표준 맵 포맷 |
| **normalxyzleft** | 그래프 입력/출력 이미지 입력 | DirectX 표준 맵 포맷. |
|  |  |  |
| **형식 해제** | 그래프 입력/출력 이미지 입력 | 범위/클램핑 없이 부동 입력입니다. |
| **데이터** | 색상 버튼 그래프 입력/출력 이미지 입력 | 부호 없는 정규화되었거나 부동 소수점. 색상 정보가 아닌 정보. |
| **원시** | 색상 버튼 그래프 입력/출력 이미지 입력 | 이 설정을 사용하면 색상 변환이 적용되지 않습니다. |
| **$standardsrgb** | 색상 버튼 그래프 입력/출력 이미지 입력 | 표준 sRGB IEC 61966-2-1:1999 색상 공간. |
| **$작업 중** | 색상 버튼 그래프 입력/출력 이미지 입력 | 작업 색상 공간은 색상 관리 설정에 따라 다릅니다. 색상 관리를 사용하지 않는 채널 및 모노 채널(스텐실, 알파, 마스크)의 데이터와 동일 |
| **$raw** | 색상 버튼 그래프 입력/출력 이미지 입력 | **raw**&#x200B;에 대한 별칭입니다. |
| **$auto** | 색상 버튼 그래프 입력/출력 이미지 입력 | **자동**&#x200B;에 대한 별칭입니다. |

## Alpha 모드

**알파** 설정을 사용하여 RGBA(색상 입력 또는 출력)의 알파 결합 방식을 지정할 수 있습니다.

구문 예: **알파=미리 곱하기**

| 설정 | 설명 |
| --- | --- |
| 일직선 | 알파를 직선으로 요청하거나 정의합니다. |
| 미리 곱하기 | 알파를 미리 곱하기로 요청하거나 정의합니다. |
| 없음 | 통과 시 지정된 알파를 그대로 사용합니다. |

>[!NOTE]
>
> **불투명도** 채널은 기본적으로 **스트레이트**(으)로 간주됩니다.

## 이미지 입력 기본 색상

Substance 그래프 이미지 입력의 기본 색상은 검정색이며 알파 값은 0으로 설정됩니다. **defaultcolor** 설정을 사용하면 그래프의 이미지 입력이 비어 있는 경우 다른 값을 정의할 수 있습니다

부동 값(범위 [0, 1]) 또는 정수 값(범위 [0, 255])을 사용하여 색상을 지정할 수 있습니다. 각 구성 요소 값은 쉼표로 구분되며 부동 소수점 값은 소수점 구분 기호로 점을 사용합니다. 부동 소수점 자리가 없으면 정수로 간주됩니다.

구문 예:

* **defaultcolor=(1.0,0.5,0.0)**
* **defaultcolor=(0,128,255)**

## 이미지 입력 패딩

기본적으로 Substance 그래프의 이미지 입력에 패딩이 없는 경우 성능 상의 이유로 UV 섬 외부 영역이 보통 균일한 색상으로 채워집니다. 패딩 설정을 사용하여 무한 확장을 요청할 수 있습니다. 무한 확장을 요청하면 필터를 사용하여 예를 들어 이음새를 만들지 않을 수 있습니다.

구문 예: **p**&#x200B;**adding=extend**

## 기본적으로 출력 사용 안 함

칠 레이어 도구의 재질 슬롯과 같은 슬롯에 물질을 추가할 때 메타데이터 텍스트 필드를 통해 특정 채널을 활성화하지 않도록 지정할 수 있습니다 .

* 특정 출력 노드(예: 재질)에서 : **disable=(true)**
* 일반 출력 노드(필터 등): **disable=(Height,확산,Specular)**

Substance를 로드할 때 이 채널은 사용자 인터페이스에서 활성화되지 않으므로 레이어 스택에서 영향을 주지 않습니다. 사용자는 계속 채널을 다시 활성화할 수 있습니다.

## 출력을 일반 마스크/알파로 지정

Substance 그래프의 출력은 다른 출력에서 공유된 알파 채널/마스크를 사용할 수 있습니다.

두 가지 방법이 있습니다.

* 식별자가 **channels\_node**&#x200B;인 출력 Alpha을 만듭니다.
* 또는 특정 출력 노드에 다음 사용자 데이터를 추가합니다. **IsChannelsAlpha=true**

다음과 같은 조건이 적용될 수 있습니다.

* 식별자가 **channels\_user**&#x200B;인 출력 Alpha이 있고 다른 출력에 userdata가 없는 경우 이 노드가 채널 마스크로 사용됩니다.
* 출력에 userdata가 있는 경우 **channels\_user** Alpha이 없으면 채널 마스크로 사용됩니다.
* **channels\_node** Alpha과 userdata가 있는 노드가 모두 있으면 **channels\_node** 출력 노드가 먼저 사용됩니다.
* 여러 노드에 userdata가 있는 경우 애플리케이션에서 찾은 첫 번째 노드가 채널 마스크로 사용됩니다. 출력이 발견되는 순서는 Substance 그래프에 정의된 것과 동일하게 보장되지 않는다.

>[!NOTE]
>
> 이 설정은 **재질 모드**&#x200B;에서 사용된 Substance 그래프에만 적용됩니다. 필터, 생성기 등에는 적용되지 않습니다.
