# 버전 2.4

**Substance Painter 2.4**&#x200B;에서는 선반 창 및 리소스 관리에 초점을 맞춥니다.

출시일: *27 2016년 10월*

## 주요 기능

### 고급 필터링이 적용된 새 선반 창

![](../../assets/new-shelf-240.jpg)

새 셸프 창은 **콘텐츠를 필터링하는 새로운 방법**&#x200B;과 함께 **더 나은 조직** 리소스를 제공합니다. 각 사전 설정에 고유한 필터링이 있는 **사용자 지정 사전 설정**&#x200B;을 만들 수 있는 가능성이 추가되었습니다(다른 쿼리 사이를 빠르게 전환할 수 있음). 이러한 사전 설정을 **새 창으로 분리**&#x200B;할 수도 있으므로, 셸프의 **여러 보기**&#x200B;를 사용할 수 있으며 이전과 같은 보기만 사용할 수 있습니다. 필터링은 또한 **디스크에서 폴더 계층 구조를 찾아보기**&#x200B;하는 방법을 제공하여 보다 일반적인 쿼리를 조정할 때 편리해집니다. 또한 **컨텍스트 메뉴**&#x200B;를 개선하여(리소스를 마우스 오른쪽 단추로 클릭할 때) **더 유용한 정보**&#x200B;를 제공합니다.

고급 쿼리를 만들려면 설명서의 전용 부분([고급 검색 쿼리](../../interface/assets/advanced-search-queries.md))을 참조하십시오.

### 새 자원 가져오기 창

![](../../assets/import-window-240.png)

셸프를 다시 사용하여 **리소스 가져오기 창**&#x200B;을 개선했습니다. 이 창은 이제 일관성이 더 높아졌으며 **세 가지 다른 방법으로 호출할 수 있습니다**: 파일 메뉴를 통해, 선반 창의 버튼을 통해 또는 이전과 마찬가지로 리소스를 선반 창으로 끌어 놓아 호출할 수 있습니다. 새 창에서 **한 번에**&#x200B;여러 리소스&#x200B;**에 대한 사용을 빠르게 설정**&#x200B;할 수 있습니다. 즉, 더 이상 리소스를 올바른 위치로 끌어서 놓을 필요가 없습니다. 또한 새 트리 보기를 활용하기 위해 하위 폴더를 만들 수 있는 **사용자 지정 경로 지정**&#x200B;에 가능성을 추가했습니다.

자세한 내용은 설명서의 전용 부분을 참조하십시오. [가져오기 창을 통해 리소스 추가](https://helpx.adobe.com/kr/substance-3d/unlisted/documentation/spdoc/adding-content-via-the-import-window-151584824.html)

### 새 입자 사전 설정

![](../../assets/particle-240.png)

더 사용할 준비가 되도록 이전 **입자 사전 설정**(특히 **비** 사전 설정)을 **다시 작업**&#x200B;했습니다. 또한 이 기회에 새로운 동작으로 **새로운 사전 설정을 추가**&#x200B;했습니다. **전기 회로, 전선, 로코코 및 혈관 소형**&#x200B;을 살펴보세요!

## 튜토리얼

새로운 선반 기능 및 사용법은 최신 튜토리얼에서 다룹니다.

## 릴리스 정보

### 2.4.1

(2016년 10월 28일 릴리스)

**고정:**

* 템플릿을 사용하여 프로젝트를 만들 때 충돌
* 내보내기 중 내보내기 대화 상자를 닫을 때 충돌 발생
* [Mac] 프로젝트 저장 시 오류 발생(내보내기 사전 설정 저장 실패)
* [Shelf] 새 사전 설정을 만들면 두 번 표시됩니다
* [Shelf] 관리자 권한이 없으면 읽기 전용 모드에서 사전 설정을 로드할 수 없습니다.

### 2.4.0

(2016년 10월 27일에 릴리스됨)

**추가됨 :**

* [Shelf] 리소스(트리 보기, 필터 등)를 검색하는 새로운 인터페이스
* [Shelf] 검색을 사전 설정으로 저장 가능
* [Shelf] 사전 설정에서 새 창 만들기 허용
* [Shelf] 리소스 가져오기를 위한 새 인터페이스
* [Shelf] Documents 폴더에 기본 알레르기 셸프를 복사하지 않음
* [선반] 새로운 입자 사전 설정 : 전기 회로, 전선, 로코코, 혈관 소형
* [Shelf] 이전 입자 사전 설정을 사용하기 쉽게 개선했습니다(예: &quot;Rain&quot;)
* [Shelf] 리소스 컨텍스트 메뉴에 새로운 정보 추가
* [뷰포트] 환경 맵 로드 시 성능 향상
* [뷰포트] 2의 강력한 기능이 아닌 환경 맵 지원 추가

**고정:**

* 마스크를 제거할 때 충돌
* 사전 설정을 저장한 후 페인팅할 때 충돌
* 일부 GPU에서 환경 흐림 효과 사용 시 충돌
* 미니 쉘프를 사용하여 잘못된 리소스를 할당할 때 충돌
* [Shelf] 정리 + 저장 프로젝트의 리소스에 대한 태그 및 메타데이터 제거
* [Shelf] 사전 설정을 가져오면 셸프에 해당 리소스가 표시됩니다.
* [내보내기] Height 채널에서 생성된 노멀 맵의 강도가 낮습니다.
* [내보내기] 메시에서 표준이 최종 노멀 맵에 항상 있는 것은 아닙니다
* [내보내기] 투명도를 사용하여 확장하면 경우에 따라 투명도가 없는 경우도 있습니다
* [스크립팅] &quot;alg.plugin\_root\_directory&quot;는 잘린 네트워크 경로를 반환할 수 있습니다.
* [TextureSet] 정사각형이 아닌 프로젝트를 다시 열 때 잠금 버튼이 활성화됨
