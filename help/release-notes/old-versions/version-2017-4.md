# 버전 2017.4

**Substance Painter 2017.4**&#x200B;에서는 **레이어 인스턴싱**&#x200B;에 새 워크플로 기능을 추가하여 프로젝트 내의 다른 텍스처 집합에서 레이어를 쉽게 동기화할 수 있습니다.

출시일: *23 2017년 11월*

## 주요 기능

### 레이어 인스턴싱

![](../../assets/instancing.jpg)

**레이어 인스턴싱**&#x200B;은(는) **다른 레이어 및 텍스처 집합**&#x200B;에서 **동기화된** 레이어 **매개 변수**&#x200B;를 유지할 수 있는 새로운 시스템입니다. 레이어 인스턴스를 만들 때 원본 레이어는 **소스**&#x200B;가 되며 인스턴스 간의 연결이 끊어지지 않는 한 인스턴스는 **업데이트 유지**&#x200B;됩니다. 인스턴스 레이어는 **좋은 방법**&#x200B;으로서 **몇 번의 클릭으로 에셋을 텍스처링**&#x200B;하고 앞뒤로 레이어 업데이트를 하지 않는 방법입니다. 에셋을 쉽게 텍스처링하려면 다른 텍스처 집합에서 **폴더를 인스턴스화**&#x200B;하고 스마트 재질 또는 다른 레이어를 넣으면 즉시 **모든 곳에서 복제**&#x200B;됩니다.

인스턴스를 만드는 방법에는 두 가지가 있습니다.

* 레이어를 복사한 후 &quot;**인스턴스로 붙여넣기**&quot;를 선택하거나 바로 가기 Ctrl+Shift+V를 사용합니다.
* 한 레이어를 선택한 후 &quot;**텍스처 세트 간 인스턴스화**&quot;를 선택하거나 바로 가기 CTRL+SHIFT+D를 사용합니다.

>[!NOTE]
>
> 레이어 인스턴싱 와 관련된 몇 가지 제한 사항이 있습니다.
> 
> * 페인팅 동작은 소스 레이어에만 표시되며, 인스턴스 레이어는 브러시 획을 복제하지 않습니다.
> * 앵커 참조에는 인스턴스의 같은 수준에 앵커 포인트가 있어야 합니다. 앵커 포인트는 인스턴스 폴더 외부에 있을 수 없습니다. 그렇지 않으면 연결이 끊어집니다.
> * 스마트 재질을 인스턴스 레이어와 함께 저장할 경우 소스 레이어가 스마트 재질 폴더에 있어야 합니다. 그렇지 않으면 인스턴스 링크가 끊어집니다.
> * 레이어 스택 설정에 따라 인스턴스 레이어에서 순환을 만들 수 있습니다. 이 순환은 지원되지 않으며 인스턴스 결과를 중단합니다. 인스턴스를 삭제하거나 이동하여 수정하십시오.

자세한 내용과 예제는 전용 페이지 [레이어 인스턴싱](../../interface/layer-stack/layer-instancing.md)를 참조하세요.

### Unreal Engine 4 지원 DCC Live-link

![](../../assets/livelink.jpg)

**live-link 플러그인**&#x200B;의 이전 Beta 버전이 이제 Substance Painter에서 **통합**&#x200B;되었습니다. 우리는 Unreal Engine 4를 지원하기 위한 기회를 가졌으며, 이제 엔진 속으로 프로젝트의 결과를 자동으로 볼 수 있습니다.

응용 프로그램을 **Unreal Engine 4**(필요한 최소 버전 **4.18**)과(와) 연결하려면 여기에 Substance 플러그인을 다운로드하십시오. <https://www.unrealengine.com/marketplace/substance-plugin>

### 새 셸프 콘텐츠

![](../../assets/materials-1.jpg)

**20개의 새 절차 자료**&#x200B;를 추가하고 **40개의 새 그런지 지도**&#x200B;도 추가했습니다(일부 절차 자료 포함). 새 재질은 **선반**&#x200B;의 &quot;**재질**&quot; 섹션에서 찾을 수 있습니다(예: 6개의 새 금속, 8개의 새 플라스틱, 몇 개의 직물 및 2개의 새 목재 표면). 새 그런지 맵은 **선반**&#x200B;의 &quot;**그런지**&quot; 섹션에서 직접 찾을 수 있습니다.

![](../../assets/grunges-1.jpg)

Clément Feuillet과 Nicolas Longchamps에게 이 새로운 버전에 대한 콘텐츠 라이선스를 부여해 주셔서 감사합니다.

### Sketchfab 내보내기 개선

![](../../assets/sketchfab.jpg)

Sketchfab 내보내기를 업데이트했고 프로젝트를 초안으로 게시하고 이미 업로드된 프로젝트도 업데이트하는 기능을 추가했습니다. 이렇게 하면 프로젝트 반복 작업이 훨씬 쉬워집니다.

### 성능 개선

우리는 실적 개선에 관한 업무를 계속했다. 이 새로운 버전에서는 보기 포트에 OpenGL 렌더링을 상당히 많이 재작업하여 속도가 훨씬 빨라졌습니다. 또한 브러쉬 획의 계산 방법을 개선하여 메모리에 훨씬 더 큰 텍스처 계산이 필요하지 않게 되었습니다. 전체적으로 훨씬 더 빠른 결과와 더 나은 페인팅 감각을 제공합니다.

## 튜토리얼

새로운 기능은 최신 비디오 의 세부 사항에서 다룹니다.

## 릴리스 정보

### 2017.4.2

(2018년 1월 24일 릴리스)

**추가됨:**

* [내보내기] 단계 진행률과 함께 내보내기 상태를 가져옵니다.
* [내보내기] 내보내기 취소 허용
* [내보내기] 표준 맵 품질을 손실하지 않고 텍스처를 Sketchfab으로 내보내기
* [내보내기] glTF 이진 형식(glb)으로 내보냅니다
* [내보내기] 내보내기 창의 구성 탭에서 열 크기를 조정할 수 있습니다.
* [Shader] 셰이더 API 변경 로그를 추가합니다
* [스크립팅] 텍스처를 내보낼 때 이전 및 이후 콜백 함수를 추가합니다
* [Iray] SDK 2017.1로 업그레이드(Volta GPU 지원)

**&#x200B;**&#x200B;고정:**&#x200B;**

* 기본 창이 표시되기 전에 애플리케이션을 종료할 때 충돌 발생
* [MAC] IRAY를 사용하여 회색 음영 맵을 로드할 때 충돌이 발생합니다
* [MAC] 새로운 High Sierra OS에서 VRAM 감지가 올바르지 않음
* [플러그인] Substance Source에서 에셋 다운로드가 더 이상 작동하지 않습니다
* [스크립팅] 잘못된 최소 플러그인 버전 검색
* [내보내기] 텍스처를 내보낸 후 내보내기 사전 설정을 저장하지 못함
* [인스턴스화] 추가 맵이 없는 TextureSet에서 인스턴스화된 생성기에서 문제가 발생합니다.
* [뷰포트] 4k 이상의 해상도에서는 디더링이 작동하지 않습니다.
* [뷰포트] 2D View 재질 디스플레이가 노이즈로 덮여 있음
* [셸프] 셸프 사전 설정의 로드 시간 개선
* [엔진] 색상 선택 아래 페인팅할 때 잘못된 혼합

### 2017.4.1

(2017년 12월 15일 릴리스)

**추가됨:**

* [스크립팅] 스크립팅 API를 통해 메시 내보내기
* [가져오기] 지원되지 않는 메시 파일 형식 가져오기를 비활성화합니다(obj, fbx, dae, ply만 허용).
* [Log] 로그 파일에서 TDR 문제를 더 정확하게 표시합니다.

**고정:**

* 리소스 크롤링이 완료되기 전에 응용 프로그램을 닫으면 충돌이 발생합니다.
* 손가락/복제 도구로 프로젝트를 열 때 충돌 발생
* 뷰어 설정에서 셰이더 변경 실행 취소 후 다시 실행을 사용할 때 충돌이 발생합니다
* [엔진] 텍스처링은 Painter 2017.2와 2017.4에서 서로 다릅니다.
* [뷰포트] 인스턴스에서 ID 맵을 선택하면 잘못된 색상이 샘플링됩니다
* [내보내기] 잘못된 일반 또는 오클루전 텍스처를 내보낼 때 충돌이 발생합니다
* [Export] Photoshop CS6에서 열 때 PSD 파일의 그룹이 잠겨 있음
* [플러그인] Photoshop 플러그인은 채널 선택을 무시하고 항상 모든 것을 내보냅니다
* [레이어] 텍스처 세트 간에 복사/붙여넣기 시 고정점 나누기
* [레이어] 일부 앵커 참조가 손상되면 복원할 수 없습니다
* [Shader] pbr 코팅 보조 roughness 매개 변수가 손상됨
* [Steam] 실행 시 버전 검사기 팝업이 표시되지 않습니다.

**알려진 문제:**

* [AMD] 메시에 페인팅하려고 할 때 충돌/멈춥니다. GPU 드라이버 업데이트로 수정할 수 있습니다.

### 2017.4

(2017년 11월 23일 릴리스)

**추가됨:**

* [인스턴스화] 레이어 간에 매개 변수를 인스턴스화할 수 있습니다.
* [인스턴스화] 소스 레이어와 인스턴스 간에 이동할 수 있습니다.
* [인스턴스화] &quot;텍스처 세트 간 인스턴스화&quot; 작업 추가
* [인스턴스화] 레이어 스택에서 인스턴스(주기) 재진입을 나타냅니다.
* [인스턴스] 소스가 제거되면 인스턴스 삭제
* [인스턴스화] 인스턴스화된 폴더 외부에서 앵커 참조를 허용하지 않음
* [UI] 실행 취소 스택을 &quot;기록&quot;이라는 자체 창으로 이동합니다.
* [Plugin] DCC 라이브 링크 플러그인 통합
* [엔진] 스파스 페인팅으로 페인팅 성능 향상
* [내보내기] Sketchfab 내보내기에 초안 및 다시 내보내기 옵션을 추가합니다
* [Shelf] 글꼴 재질에 대한 &quot;뒤집기&quot; 컨트롤 추가
* [Shelf] 20개의 새로운 절차 자료 추가
* [Shelf] 40개의 새로운 그런지 맵 추가(비트맵 기반 및 절차)
* [뷰포트] 보이는 다른 텍스처 세트에서 브러시 미리 보기 충돌 활성화
* AMD GPU 드라이버 최소 요구 사항 업데이트

**고정:**

* 너무 큰 해상도에서 Substance을 계산할 때 충돌 발생
* 입자를 사용하여 과하게 페인팅할 때 충돌 발생
* [뷰포트] 특정 메시가 있는 2D 뷰에서 Specular 반사가 잘못됨
* [UI] 일부 원치 않는 동작이 [작업 내역] 창에 나타납니다

**알려진 문제:**

* [레이어] 일부 앵커 참조가 손상되면 복원할 수 없습니다
* 뷰어 설정에서 셰이더 변경 실행 취소 후 다시 실행을 사용할 때 충돌이 발생합니다
