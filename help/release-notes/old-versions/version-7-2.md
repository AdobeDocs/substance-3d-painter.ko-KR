# 버전 7.2

**Substance 3D Painter 7.2**&#x200B;은(는) Adobe Standard Material 워크플로를 통한 새로운 렌더링 기능, [Substance 3D 응용 프로그램](https://www.adobe.com/products/substance3d/3d-augmented-reality.html)에서 콘텐츠를 공유하는 새로운 방법, 그리고 개선된 에셋 창을 제공합니다.

출시일: *23 2021년 6월*

## 주요 기능

### 새 에셋 창

![](../../assets/banner-assets.jpg)

기존 Shelf 창이 개선되었으며 이름이 Assets 창으로 변경되었습니다. 새로운 전용 아이콘을 사용하여 콘텐츠를 보다 빠르게 액세스하고 필터링하기 쉽게 만드는 데 중점을 두었습니다. 또한 이동 경로(breadcrumbs)를 사용하여 보다 쉽게 탐색할 수 있습니다. 이번 재설계에서는 다른 Substance 3D 소프트웨어와 유사한 환경을 만들어 애플리케이션 간에 콘텐츠를 보다 쉽게 관리할 수 있도록 하는데 중점을 두었습니다.

>[!NOTE]
>
> 이 릴리스에서는 애플리케이션 환경 설정 및 Shelf/Assets 콘텐츠를 관리하는 방법에 대한 변경 사항을 소개합니다. 데이터를 마이그레이션하는 방법을 알아보려면 [전용 페이지](../../pipeline-and-integration/resource-management/preferences-and-content-migration.md)를 살펴보세요.

* **새 디자인 및 레이아웃**\
  새 디자인은 단순화뿐만 아니라 창의 손쉬운 구성에 초점을 맞춥니다. 이제 공간을 낭비하지 않고 창을 수직으로 도킹할 수 있습니다. 새로운 &quot;목록&quot; 표시 모드를 통해 이름으로 에셋을 훨씬 쉽게 검색할 수 있습니다.

  ![](../../assets/assets-vertical.png)

* **새로운 탐색 경로 탐색**\
  탐색 리소스가 작은 UI에서 어려울 수 있습니다. 이제 이동 경로를 사용하면 전체 폴더 계층 구조를 표시할 필요 없이 폴더 간에 이동하는 것이 더 쉬워지지 않습니다.

  ![](../../assets/breadcrumbs-2.png)

* **새 사용 필터**\
  에셋 창에는 다양한 콘텐츠가 있으며, 콘텐츠를 필터링하여 특정 리소스를 분리하는 데 유용한 방법입니다. 특정 용도를 선택하려면 전용 버튼을 클릭하기만 하면 됩니다. 여러 사용을 추가하거나 제거하려면 단추를 클릭하면서 Ctrl 키를 누르고 유지합니다.

  ![](../../assets/demo-filters.gif)

* **축소판 렌더링 향상**\
  시간을 들여 썸네일 생성 시스템을 재구성하여 품질을 개선하고 Substance 3D 생태계 전체에서 더 일관성 있게 보이도록 만들었습니다. 또한 변위에 대한 지원도 추가되었습니다.

  ![](../../assets/cropped-icons-before-after.jpg){width="500px"}

* **Substance 보관 파일(sbsar)에서 축소판 불러오기**\
  Substance 파일 내에 포함된 사용자 정의 축소판은 에셋 창에 로드되지 않고 표시됩니다. 이제 사용자 정의 아이콘에 대한 리소스 메타데이터를 포함할 필요가 없으므로 사용자 정의 리소스를 더 쉽게 공유할 수 있습니다.

* **향상된 성능**&#x200B;축소판의 로드 및 생성 시간이 여러 측면에서 개선되었으며 이제 훨씬 빨라졌습니다.

* **미리 보기 메모리 예산을 늘려 더 많은 축소판을 로드하십시오**\
  기본적으로 제한된 용량의 메모리가 축소판 표시에 할당되어 성능에 절약됩니다. 그러나 많은 리소스가 있는 라이브러리가 있으면 축소판을 계속 로드하고 언로드할 수 있으므로 탐색 및 리소스 검색이 어려울 수 있습니다. 이제 기본 예산 값을 재정의할 새 [환경 변수](../../pipeline-and-integration/configuration/environment-variables.md)가 있습니다.

### 새로운 Adobe 표준 재질 작업 과정

![](../../assets/banner-asm.jpg)

**Adobe Standard Material**(ASM)이라는 새 셰이더가 추가되어 여러 기능을 동시에 지원하므로 단일 텍스처 세트 내에서 더 복잡하고 정확한 재질을 만들 수 있습니다. 이 새로운 셰이더로 우리는 또한 더 쉽게 재료를 만들 수있는 새로운 채널을 추가 할 수있는 기회를 잡았다.

* **새 Adobe Standard Material 셰이더**\
  새로운 ASM 셰이더는 PBR 렌더링의 진화와 함께 여러 기능을 다시 그룹화하는 셰이더입니다. 동시에 다음을 지원합니다.
  * **비등방성**
  * **코트 지우기**
  * **광택**
  * **Specular edge color**
  * **추가 하위 표면 분산 방법**
  * 그리고 물론 Parralex 오클루전, 변위 등과 같은 다른 기존 기능.

* **새 채널 및 사용자 채널**\
  새 ASM 셰이더를 지원하기 위해 새 채널이 추가되었습니다. 또한 사용자 채널을 두 배로 늘려 사용자 정의 정보와 사용자 정의 셰이더의 가능성을 확장할 수 있습니다.
  * 코팅 색상
  * 코팅 거칠기
  * 코팅 정상
  * 코팅 불투명도
  * 코팅 반사 수준
  * 산란 색상
  * 광택 색상
  * 광택 거칠기
  * 광택 불투명도
  * 반사 가장자리 색상
  * 8개에서 15개 사이의 사용자 채널

* **개선된 텍스처 집합 설정**\
  이제 텍스처 세트 설정의 채널 목록 메뉴에서 현재 셰이더와의 호환성을 기반으로 채널을 그룹화합니다. 이를 통해 뷰포트에 어떤 채널이 영향을 주는지 확인할 수 있습니다.

  ![](../../assets/channel-list-grouping.png)

* **if 및 recompilation이 표시된 새 셰이더 API 기능**\
  ASM 셰이더의 개발로 API의 일부 변경 사항이 두 가지 주요 기능으로 이루어졌습니다.
  * **Visible If**: 셰이더 UI를 읽기 쉽게 만드는 조건에 따라 셰이더 매개 변수를 표시하거나 숨길 수 있습니다.
  * **다시 컴파일**: 특정 방법으로 매개 변수를 선언함으로써 이제 셰이더의 일부를 사용하지 않도록 설정하고 매개 변수 변경 시 최적화하도록 다시 컴파일할 수 있습니다. 이렇게 하면 사용하지 않는 기능을 버릴 수 있습니다.

### 새로운 Substance 3D 에코시스템 교환

![](../../assets/banner-send-to.jpg)

이제 이 새로운 워크플로우를 통해 Substance 3D 애플리케이션 간에 리소스와 에셋을 보내는 작업이 훨씬 쉽고 한 번의 클릭으로 액세스할 수 있습니다. 이제 Substance 3D Designer 또는 Substance 3D Sampler에서 Substance 파일을 수신하거나 프로젝트를 Substance 3D Stager으로 매우 쉽게 전송하여 콘텐츠를 빠르게 반복할 수 있습니다.

>[!WARNING]
>
> 이 보내기 및 받기 기능은 특정 기술을 통해 가능해지기 때문에 응용 프로그램의 Creative Cloud 데스크탑 버전을 통해서만 사용할 수 있습니다. 이는 Steam 또는 Substance 3D 독립 버전이 이러한 기능을 지원하지 않음을 의미합니다.

* **Painter에서 Stager로**\
  업데이트된 내보내기 사전 설정을 사용하여 Painter에서 Stager로 내보내거나 **Substance 3D Stager으로 보내기** 작업을 사용하여 현재 프로젝트를 자동으로 내보내고 Stager로 가져옵니다. 수동 구성이 필요하지 않습니다.

* **Painter으로 Stager**\
  Stager에서 직접 비슷한 원클릭 동작으로 Stager의 모델을 텍스처로 수신합니다.

* **Designer 또는 Sampler에서 Painter으로**\
  단 한 번의 클릭으로 Designer 또는 Sampler에서 에셋 창으로 Substance 자료, 필터 등을 바로 받을 수 있습니다.

* **Painter Substance 3D Assets**\
  Creative Cloud 데스크탑에서 Substance 자료와 같은 콘텐츠를 Painter의 에셋 창으로 직접 수신합니다.

* **Bridge에 표시**\
  Adobe Bridge에서 관리하는 라이브러리에 있는 에셋 창의 리소스는 특정 리소스 위에서 마우스 오른쪽 버튼을 클릭해 메뉴를 사용하여 Bridge에서 바로 열 수 있습니다.

### 향상된 자동 UV 언래핑

![](../../assets/banner-uv.jpg)

UV 타일의 지원 및 UV 생성에 대한 추가 제어를 제공하는 자동 UV 언래핑의 새로운 업데이트가 추가되었습니다.

* **UV 타일 양**\
  UV를 생성할 때 생성하고자 하는 UV 타일의 최대 수를 구체화할 수 있습니다. 이렇게 하면 UV 타일 작업 과정에서도 UV 생성을 사용할 수 있습니다.

* **UV 섬 방향**\
  압축할 때 UV 섬 방향에 구속을 추가하기 위해 새 매개변수가 추가되었습니다. 이를 통해 UV 섬을 조금 더 정렬하여 일부 오브젝트를 더 쉽게 텍스처링할 수 있습니다(예: 나무 도어를 사용하여 나무 패턴을 정렬하는 경우).

* **향상된 패킹 성능**\
  새로운 UV 타일 지원으로 패킹 기능도 향상되어 좋은 성능을 제공합니다.

### 일반적인 개선 사항

![](../../assets/banner-misc-2.jpg)

이 새로운 버전에는 삶의 질 개선을 위한 몇 가지 사항이 추가되었습니다.

* **그래픽 태블릿의 펜으로 개선된 슬라이더 성능**\
  이제 펜으로 슬라이더 드래그 시 응답성이 훨씬 높아집니다. 슬라이더가 더 이상 끈적거리지 않아야 합니다.

* **이미 칠해진 레이어로 성능을 개선했습니다**\
  기존의 브러시 획이 많은 레이어로 페인트하는 것은 더 이상 속도가 느려지지 않고 훨씬 빨라야 합니다.

* **프로젝트를 연 후 더 빠르게 페인팅**\
  이제 프로젝트를 연 직후에 레이어 스택의 맨 위에 있는 레이어에 페인팅이 수행됩니다. 엔진 캐시 계산이 나중으로 연기되어 이 맥락에서 오래된 프로젝트의 리에디션이 조금 더 빨라졌습니다.

* **일반 메서드**\
  [텍스처 세트] 설정에 Height 채널을 표준 맵으로 변환하는 방식을 제어할 수 있는 새로운 [Height-표준] 메서드 매개 변수가 있습니다. 이 새로운 매개변수는 직물 재료와 같이 다양한 디테일로 표면의 품질을 향상시키는 데 유용합니다.

  ![](../../assets/normal-mode.jpg){width="450px"}

* **새 인터페이스 스타일**\
  일반 인터페이스가 일반 Substance 3D 에코시스템에 맞게 약간 조정되었습니다. 따라서 한 응용 프로그램에서 다른 응용 프로그램으로 이동하는 것이 덜 놀랍고 쉽게 이동할 수 있습니다.

* **새 번역**\
  프로그램 인터페이스를 번역하기 위해 세 가지 새로운 언어가 추가되었습니다.
  * 프랑스어
  * 독일어
  * 중국어 간체
