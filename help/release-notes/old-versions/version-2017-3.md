# 버전 2017.3

**Substance Painter 2017.3**&#x200B;은(는) **Adobe 프로젝트 Felix**&#x200B;과 개방형 형식 **glTF**&#x200B;을(를) 지원하는 새로운 고급 내보내기 사전 설정에 집중합니다. 이 새 릴리스는 인터페이스를 개선하고 자동 저장 플러그인을 추가하여 사용자 경험에 초점을 맞춥니다.

출시일: *28 September 2017*

## 주요 기능

### Adobe 표준 재질 내보내기 사전 설정

![](../../assets/adobe-dimension-meetmat.jpg)

이 릴리스에 포함되는 새 내보내기 도구 중 하나는 Adobe Dimension(이전의 Adobe Project Felix)와 함께 사용할 Adobe Standard Material을 지원하는 것입니다. 한 번의 클릭으로 장면 메쉬와 해당 텍스처를 Project Felix로 가져올 수 있도록 내보낼 수 있습니다. 액세스하려면 텍스처 내보내기 창에서 &quot;**Adobe Standard Material**&quot;을(를) 선택하면 됩니다. 자세한 내용은 [http://www.adobe.com/products/dimension.html](https://www.adobe.com/products/dimension.html)을 참조하세요.

이에 대한 블로그 게시물(<https://www.allegorithmic.com/blog/new-dimension-substance-ecosystem>)을 확인할 수도 있습니다.

### glTF 2.0 내보내기 사전 설정

![](../../assets/gltf-export.jpg)

또한 **장면 메시** 및 **PBR 텍스처**(금속/거칠기)를 내보내는 방식으로 **glTF** 파일 형식에 대한 지원을 추가했습니다. 액세스하려면 텍스처 내보내기 창에서 &quot;**glTF PBR Metal Roughness**&quot;을(를) 선택하면 됩니다. **glTF**&#x200B;은(는) 크로노스 그룹이 감독하는 오픈 소스 파일 형식입니다. **Windows 10**&#x200B;에서 glTF 파일을 보거나 간단히 [**Babylon**](http://sandbox.babylonjs.com/)과 같은 WebGL 뷰어를 사용할 수 있습니다.

자세한 내용은 <https://github.com/KhronosGroup/glTF>을(를) 참조하십시오.

### 플러그인 자동 저장

![](../../assets/autosave-details.png)

이 릴리스에는 현재 열려 있는 프로젝트의 **백업을 작성**&#x200B;할 수 있는 새 플러그인도 포함되었습니다. 이렇게 하면 현재 열려 있는 프로젝트 쪽에 백업 파일이 만들어집니다.\
이 때문에 [파일] 메뉴에 &quot;**사본으로 저장**&quot; 항목도 추가되었습니다. 플러그인 자체를 비활성화하여 **자동 저장**&#x200B;을 중지할 수 있으며, **설정**&#x200B;은 구성 패널&#x200B;**을 통해**&#x200B;에 액세스할 수 있습니다. 경고 시간 지연에 도달하면 기본 도구 모음의 버튼 아래에 **진행률 표시줄**&#x200B;이 표시되어 필요한 경우 몇 분 동안 스누징할 수 있습니다(백업 전에 작업을 완료하려는 경우 편리합니다).

백업이 만들어졌지만 프로젝트가 저장되지 않은 경우(기울이지 않음), 백업은 **문서/알레고리즘/Substance Painter/자동 저장** 폴더 내에 저장됩니다. 그렇지 않으면 백업이 프로젝트 자체 옆에 표시됩니다(구성 패널에서 경로를 재정의하지 않는 경우).

### 개선된 그레이디언트 필터

![](../../assets/gradient-rust.jpg)

**그레이디언트 필터**&#x200B;가 완전히 개선되었습니다. **Substance Designer**&#x200B;에서 사용할 수 있는 **그레이디언트 맵** 노드와 훨씬 더 유사한 방식으로 작동합니다. 이제 최대 **10개의 다른 색상**&#x200B;을 지원하며, **색상이**&#x200B;그레이디언트&#x200B;**&#x200B;**&#x200B;내부에 있는 위치를 지정하여 많은 새 문을 열 수 있습니다. 이를 통해 더 많은&#x200B;**고급 색상 패턴**&#x200B;을 만들 수 있지만&#x200B;**높이 지도 다시 매핑**&#x200B;과&#x200B;**새 모양**&#x200B;을 만들 수도 있습니다.

기본 슬라이더(색상 양)는 그레이디언트를 만드는 데 사용되는 총 색상 수를 정의합니다. 바로 아래에 있는 버튼은 색상 혼합 모드(sRGB 또는 선형)를 정의합니다. 색상 간의 적절한 혼합을 원하는 경우 이 설정이 중요합니다. 예를 들어 순수한 빨강과 순수한 녹색을 혼합하면 중간 중간에 멋진 노란색을 만들 수 있습니다. 이 버튼을 비활성화하면(대신 진한 갈색이 표시됨) 이것은 그렇지 않습니다. Height 또는 다른 회색 음영 채널을 다시 매핑할 때 감마 변환을 수행하지 않도록 이 버튼을 비활성화해야 합니다.

맨 위에 있는 단추를 클릭하면 필터 결과를 그레이디언트 자체로 교체하여 2D 보기에서 그레이디언트를 시각화할 수 있습니다.

![](../../assets/gradient-height-demo.jpg)

### 인터페이스 및 동작 개선

![](../../assets/tabs-top.png)

이 릴리스에서는 응용 프로그램의 다른 도크의 **탭**&#x200B;이 해당 창의 아래쪽&#x200B;**이 아닌 위쪽**&#x200B;에 있습니다. 이 선택은 인터페이스의 가독성을 돕지만 다른 애플리케이션과 더 일관성을 유지하기 위해 이루어졌다. 이 변경 다음에 탭 제목 옆에 **작은 십자**&#x200B;를 도입하여 **쉽게 닫기**&#x200B;합니다. 탭을 **마우스 오른쪽 단추로 클릭**&#x200B;하여 **컨텍스트 메뉴**&#x200B;를 가져올 수도 있습니다(창을 닫거나 고정 해제할 수 있음). 창 고정을 해제하는 바로 가기는 탭을 창 영역 밖으로 드래그하여 놓는 것입니다.

이제 파일 탐색기에서 **뷰포트로**&#x200B;끌어서 놓기만 하면 **프로젝트를 열 수 있습니다**. 이 기능은 **메시** 파일에도 적용됩니다. 메시 파일을 **빈 뷰포트**&#x200B;에서 드래그하여 놓으면 **새 프로젝트 창**&#x200B;이 열리지만 **이미 열려 있는 프로젝트**&#x200B;에서 수행하면 **프로젝트 구성 대화 상자**&#x200B;가 열리므로 **메시를 빠르게 업데이트**&#x200B;할 수 있습니다.

**참고** : 드래그하여 놓기에 문제가 있는 경우 [주제에 대한 FAQ를 확인하세요](../../technical-support/technical-issues/miscellaneous-issues/impossible-to-drag-and-drop-files-into-the-shelf.md).

### 성능 개선

이 버전의 Substance Painter은 또한 GPU 메모리(VRam)를 관리하는 방식과 관련하여 새롭고 강력한 성능 개선을 포함합니다. 칠 레이어와 같은 균일한 색상이 이제 더 작은 텍스처로 압축되어 기본 메모리와 GPU 메모리 간의 전송 속도를 높이지만 메모리 점유 공간과 계산 시간을 줄일 수 있습니다. 이 문제는 특히 큰 프로젝트를 열 때와 GPU 메모리 한계에 도달할 때 특히 두드러지게 나타나야 합니다.
