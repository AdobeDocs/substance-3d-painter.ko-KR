# 버전 12.1

<b>Substance 3D Painter 12.1</b>은(는) 자동 리베이크 및 기울이기 보정 페인팅으로 개선된 베이킹 작업 과정과 OpenPBR 재질 정의를 지원하며 자동 UV 감싸기를 위한 새로운 하드 표면 모드를 제공합니다.

출시일: <b>2026년 6월 22일</b>

>[!NOTE]
>
> 이 버전은 지원되는 최소 macOS 버전을 13.0(Ventura)으로 높입니다. 자세한 내용은 [시스템 요구 사항 페이지](../getting-started/system-requirements.md)를 확인하세요.

## 주요 기능

### 기울이기 페인팅으로 베이킹 작업 과정 개선

![](../assets/v12/v12_banner_skew.jpg)

연속 다시 굽기, 메시 내 기울이기 보정 페인팅, 가장자리 보호 및 다시 디자인된 메시 맵 목록을 지원하도록 굽기 작업 과정이 재작업되었습니다.

* <b>자동 다시 굽기</b>

  메쉬 맵은 베이킹 매개변수가 조정되면 지속적으로 다시 베이킹될 수 있으므로 변경 때마다 베이크를 수동으로 트리거할 필요가 없습니다. 자동 다시 굽기는 지도별로 전환되며 한 번에 하나의 지도에 적용됩니다. 이는 특히 기울이기 페인팅 작업 과정에 편리할 뿐 아니라 일반 베이크 설정을 조정할 때도 유용합니다.

  ![](../assets/v12/v12_auto_rebake.png)

* <b>기울이기 보정 페인팅</b>

  케이지가 <b>거리 기반</b> 모드로 설정되면 스큐 교정을 낮은 폴리 메시에 직접 페인트하여 굽는 동안 사용되는 투영 방향을 제어할 수 있습니다. 간단한 회색 음영 값 피커, 대칭 및 일반적인 브러시 컨트롤을 사용하여 브러시, 지우개 및 다각형 채우기 도구를 사용할 수 있습니다(<b>Ctrl+마우스 오른쪽 버튼을 클릭하여</b> 브러시 크기를 조정하고, 칠해진 값을 반전하려면 <b>X</b>). 페인트 기울이기 작업은 실행 취소할 수 있습니다.

  ![](../assets/v12/v12_skew_fix_rebake.gif)

* <b>에지 보호</b>

  기울이기 교정을 페인트할 때 새로운 가장자리 보호 옵션을 사용하면 선명한 가장자리에 투영되는 높은 폴리 부드러움을 유지할 수 있습니다. 결과는 <b>가장자리 거리</b> 및 <b>가장자리 대비</b> 매개 변수에 의해 제어됩니다.

  ![](../assets/v12/v12_skew_edge_distance.gif)

* <b>다시 디자인된 메시 맵 목록</b>

  메시 맵 목록은 맵별 컨트롤을 제공합니다. 맵을 뷰포트로 <b>미리 보기</b>, 단일 맵으로 <b>빠른 굽기</b>, 맵을 <b>자동 다시 굽기</b>로 전환하고, 텍스처 세트 간에 설정을 <b>동기화</b>(프로젝트에 여러 텍스처 세트가 있는 경우 사용 가능)합니다. 각 컨트롤에는 마우스 오버 시 도구 설명이 있습니다.

  ![](../assets/v12/v12_quick_bake.png)

* <b>간단한 굽기 단추</b>

  뷰포트 굽기 버튼이 구울 맵의 수를 표시하는 단일 <b>굽기</b> 버튼으로 대체되었습니다(텍스처 세트 x UV 타일 x 선택한 메시 맵).

  ![](../assets/v12/v12_bake_button.png)

>[!NOTE]
>
> 굽기에 대한 자세한 내용은 [전용 문서 페이지](../baking/baking.md)를 참조하세요.

### OpenPBR 지원

![](../assets/v12/v12_banner_openpbr.jpg)

이제 OpenPBR 음영 모델이 Painter에서 지원되며 기본 워크플로로 사용되므로 응용 프로그램 간에 수행될 수 있는 표준화된 재질 정의를 제공할 수 있습니다.

* <b>새 OpenPBR 셰이더 및 기본 워크플로</b>

  OpenPBR 1.1 사양을 구현하는 셰이더를 기본적으로 사용할 수 있고 사용할 수 있습니다. 템플릿 없이 생성된 새 프로젝트에서는 OpenPBR 셰이더가 사용되며 새 프로젝트 창의 첫 번째 항목에 <b>ASM</b> 대신 <b>OpenPBR</b> 레이블이 지정됩니다. OpenPBR의 새 프로젝트 템플릿이 포함되어 있고 샘플 프로젝트가 이를 사용하도록 업데이트되었습니다.

  ![](../assets/v12/v12_openpbr_shader_icon.jpg)

* <b>가져올 때 프로젝트 템플릿에서 셰이더 선택됨</b>

  USD 또는 GLTF 파일을 가져오는 경우 셰이더는 이제 파일 컨텐츠에서 추측되지 않고 프로젝트 템플릿에서 설정됩니다. 자료와 템플릿이 일치하지 않는 워크플로우를 사용하는 경우 메시지가 로그에 보고됩니다.

  ![](../assets/v12/v12_openpbr_template.png)

* <b>내보낼 때 OpenPBR 명명 규칙</b>

  <b>텍스처 내보내기</b> 창에는 명명 규칙을 선택할 수 있는 새 드롭다운이 있습니다. 프로젝트에서 하나 이상의 셰이더가 해당 셰이더를 사용하고 선택한 스키마가 각 텍스처 세트의 맵 목록에 반영되면 기본적으로 OpenPBR이 됩니다.

  ![](../assets/v12/v12_openpbr_export.png)

* <b>USD 및 MDL 지원</b>

  OpenPBR 재질은 USD 포맷을 통해 지원됩니다. Iray에서 OpenPBR 재질을 렌더링할 수 있도록 새로운 MDL이 추가되어 보다 정확한 재질 표현이 제공됩니다.

>[!NOTE]
>
> 사용자 정의 셰이더를 업데이트해야 할 수 있습니다. OpenPBR을 지원하도록 셰이더 API이 변경되었습니다. 자세한 내용은 응용 프로그램의 도움말 메뉴에 있는 변경 로그를 참조하십시오.

### 새로운 하드 표면 자동 언랩

![](../assets/v12/v12_banner_uvs.jpg)

단단한 표면 에셋에 맞춘 새로운 자동 래핑 해제 모드가 추가되었습니다.

* <b>하드 표면 감싸기 해제 모드</b>

  자동 흐름 풀기 설정에서 <b>단단한 표면</b> 옵션을 사용할 수 있습니다. UV 왜곡을 최소화하고 맞춤형으로 정렬된 UV 레이아웃을 생성하여 기계적 및 단단한 표면 메시에 더 적합합니다.

  ![](../assets/v12/v12_unwrap_mode.jpg)

>[!NOTE]
>
> 자동 래핑에 대한 자세한 내용은 [전용 문서 페이지](../features/automatic-uv-unwrapping.md)를 참조하세요.

### 기타

![](../assets/v12/v12_banner_misc.jpg)

이 버전에 추가 기능 및 개선 사항이 추가되었습니다.

* <b>한 번에 여러 채널 추가 또는 제거</b>

  OpenPBR이 도입된 후에는 <b>텍스처 집합 설정</b>에서 액세스할 수 있는 새 창에서 한 번에 여러 채널을 선택할 수 있으므로 OpenPBR 워크플로에서 사용하는 큰 채널 목록을 설정할 때 편리합니다.

  * <b>채널 추가/제거</b> 단추를 통해 [텍스처 설정]에서 새 창에 액세스할 수 있습니다.

    ![](../assets/v12/v12_channel_add_remove_button.png)

  * 이 창에서는 Painter에서 사용할 수 있는 모든 채널의 개요를 제공합니다.

    ![](../assets/v12/v12_channel_window_small.jpg)

  * <b>모든 텍스처 집합에 적용</b> 단추를 사용하여 모든 텍스처 집합의 채널 구성을 한 번에 편집할 수 있습니다.

    ![](../assets/v12/v12_channel_apply_all.png)

* <b>텍스처 집합 간에 모든 인스턴스 병합</b>

  인스턴스화된 레이어 및 그룹에는 새로운 <b>모든 인스턴스 병합</b> 옵션을 사용할 수 있습니다. 인스턴스가 나타나는 모든 텍스처 세트에서 전체 인스턴스 트리를 따라 아래로 내려가면서 병합된 결과를 생성하고 단일 실행 취소 단계로 기록됩니다.

  ![](../assets/v12/v12_flatten_instances.png)

* <b>통합 실행 취소 기록</b>

  베이킹 및 페인팅 모드는 이제 동일한 실행 취소 작업 내역을 공유합니다. [베이킹] 모드와 [페인트] 모드 간에 전환하면 실행할 수 없는 단계로 기록되므로 작업이 발생한 모드에서만 실행 취소할 수 있습니다.

<b>고정</b>:

* [충돌][메시 맵 설정] 다른 텍스처 세트에 설정을 적용합니다
* [충돌] 세계 공간 정상 없이 지도에서 곡률을 굽을 때
* [충돌][베이킹] 사용자 정의 케이지가 활성화되었지만 선택한 파일이 충돌하지 않는 베이킹
* [충돌] AO 베이킹 취소
* [자동 케이지] 높은 폴리 파일 경로가 잘못된 경우 무한 로드
* [Linux][Windows] 색상 피커가 완전히 검정색이거나 표시되지 않는 경우가 있습니다
* [다각형 칠 도구] 도구가 PBR이 아닌 경우 작동하지 않습니다.
* &lbrack;[Paint] 기본 색상 채널을 삭제해도 이전에 칠한 색상은 삭제되지 않습니다.
* [USD] 셰이더 인스턴스가 모두 올바르게 감지되지 않음
* [Substance] 입출력 노드의 첫 번째 사용만 고려합니다.
* [Shader] 서로 다른 혼합 방법을 사용하여 [텍스처 세트]에 대해 [앰비언트] 오클루전을 두 번 적용합니다
* [엔진] 빈 파란색 채널(검정)이 있는 일반 텍스처가 잘못된 블렌드 결과를 초래할 수 있습니다.
* [GLTF 가져오기] Alpha 혼합이 모든 텍스처 세트에서 활성화됩니다
* [GLTF 내보내기] Alpha 혼합은 내보낼 때 항상 활성화됩니다
* [내보내기] GLTF 파일을 가져올 때는 양면 형상이 항상 비활성화됩니다
* [Javascript] 음영 설정을 수정해도 작업 내역 취소가 수행되지 않음
* [샘플] Meet Mat에 대한 디스플레이 설정에서 서브표면 분산이 활성화되지 않음
