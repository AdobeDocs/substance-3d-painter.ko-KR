# 내보내기 창

![](../../assets/export-textures-window.png){width="500px"}

<b>파일 > 내보내기 텍스처 </b> 또는 키보드 단축키 <b>Ctrl + Shift + E</b>를 사용하여 <b>내보내기 창 </b>을(를) 엽니다.

<b>내보내기 창 </b>은(는) 세 개의 탭으로 나뉩니다.

* [내보내기 설정](export-settings.md)
* [출력 템플릿](output-templates.md)
* [내보내기 목록](list-of-exports.md)

창 아래쪽에는 여러 개의 단추가 있습니다.

* <b>모두 재설정</b>(<b>설정 탭</b>에만 해당): 프로젝트의 내보내기 구성을 재설정합니다.
* <b>취소</b>: 변경 내용을 저장하지 않고 창을 닫습니다.
* <b>설정 저장</b>: 현재 내보내기 설정을 프로젝트에 저장합니다.
* <b>내보내기</b>: 현재 내보내기 설정으로 내보내기를 시작하고 내보내기 진행률을 추적하기 위해 자동으로 <b>내보내기 목록</b> 섹션으로 전환합니다.
