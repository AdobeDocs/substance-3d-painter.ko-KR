# 기본 출력 템플릿

아래는 기본적으로 제공되는 추가 출력 템플릿 목록입니다.  기본 출력 템플릿은 <b>내보내기 창</b>의 <b>출력 템플릿 탭 </b>에서 복사 및 수정할 수 있습니다.

>[!NOTE]
>
> 여기에 나열되지 않은 다른 소프트웨어(**옥탄** 등)도 지원될 수 있습니다. 자세한 내용은 [에코시스템 및 플러그인](https://experienceleague.adobe.com/ko/docs/substance-3d/ecosystem/home)을 참조하세요.

| *사전 설정* | *설명* |
| --- | --- |
| <b> Amazon Lumberyard </b> | Amazon Lumberyard에서 가져와서 사용할 텍스처의 이름과 팩을 지정합니다. |
| <b> Arnold(AiStandard) </b> | Arnold(AiStandard 셰이더)에 대한 사전 설정입니다. |
| <b> Arnold UDIM 레거시(AiStandard)</b> | Arnold UDIM Legacy(AiStandard)에 대한 사전 설정입니다. |
