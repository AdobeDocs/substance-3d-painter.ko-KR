# 출력 템플릿

![](../../assets/preset-list.png)

Substance 3D Painter에는 내보내기 프로세스의 비헤이비어를 제어하는 데 사용할 수 있는 두 가지 유형의 출력 템플릿이 있습니다.

* [기본 출력 템플릿](default-presets.md)은(는) 특정 3D 응용 프로그램 또는 작업 과정에서 작동하도록 설계되었으며 <b>내보내기 창</b>의 <b>출력 템플릿 탭</b>에서 사용할 수 있습니다. 기본 템플릿을 복제 및 수정하거나 템플릿을 처음부터 직접 만들 수 있습니다.
* [미리 정의된 출력 템플릿](../../export/export-presets/predefined-presets/predefined-presets.md)을(를) 수정할 수 없습니다. 미리 정의된 템플릿은 <b>내보내기 창</b>의 <b>설정 탭</b>에서 <b>출력 템플릿 드롭다운 목록</b>의 맨 위에 표시됩니다.
