# 미리 정의된 출력 템플릿

미리 정의된 출력 템플릿은 Substance 3D Painter에서 직접 생성되므로 편집할 수 없습니다. 미리 정의된 출력 템플릿은 <b>내보내기 창</b>의 <b>설정 탭</b>에서 <b>출력 템플릿 드롭다운 목록 </b>의 맨 위에 표시됩니다.

아래는 편집할 수 없는 사전 설정 목록입니다.

* 2D 보기
* 문서 채널 + 일반 + AO(Alpha 없음)
* 문서 채널 + 표준 + AO(Alpha 포함)
* Sketchfab
* Substance 3D Stager
* [USDz(Apple AR)](usd-pbr-metal-roughness-preset.md)
* glTF PBR 금속 거칠음
* glTF PBR 금속 거칠음 + 변위 텍스처(시험적)
