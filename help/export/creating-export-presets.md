# 출력 템플릿 만들기

이 페이지에서는 사용자 정의 출력 템플릿을 만들고 수정하는 방법을 설명합니다. 출력 템플릿은 내보낸 텍스처의 이름 지정 및 구성을 제어합니다. 사용자 정의 출력 템플릿을 만들면 내보내기를 워크플로우에 맞게 완벽하게 구성할 수 있습니다.

내보내기 창의 구성 탭은 다음과 같은 세 가지 주요 부분으로 구분됩니다.

* <b>사전 설정 목록:</b>(왼쪽)에서는 기존 템플릿을 편집하거나 복제하고 이름을 바꿀 템플릿을 선택할 수 있습니다.
* <b>출력 텍스처 목록</b>: (가운데) 선택한 사전 설정의 콘텐츠를 나열하고 명명 규칙 및 채널 패킹 옵션을 표시합니다.
* <b>채널 목록</b> 및 <b>변환된 텍스처</b>: (오른쪽)내보낸 텍스처의 내용을 합성하는 데 사용할 채널 및 텍스처 목록입니다.

![](../assets/image2018-4-25-13-36-44.png){width="800px"}

>[!NOTE]
>
> 출력 템플릿은 디스크에 <b>개별 파일</b>(으)로 저장되며 Substance 3D Painter의 다른 사용자와 공유할 수 있습니다.\
> [Substance 3D Painter 파일](../pipeline-and-integration/resource-management/shelf-and-assets-location.md)의 assets/export-presets 폴더에서 만든 사용자 지정 템플릿의 로컬 파일을 찾을 수 있습니다.

>[!NOTE]
>
> 텍스처를 내보내는 데 템플릿을 사용하면 템플릿 파일이 이후 저장에서 자동으로 프로젝트 파일에 포함됩니다.\
> 이를 통해 텍스처를 내보내기 위한 템플릿을 유지하면서 프로젝트를 다른 컴퓨터로 공유 및/또는 이동할 수 있습니다.\
> 마지막으로 사용한 사전 설정만 프로젝트에 저장됩니다. 그러나 Substance 3D Painter에서 동일한 이름의 사전 설정을 감지하면 프로젝트 내의 사전 설정이 목록에서 &quot;오래됨&quot;으로 표시됩니다.

## 템플릿 만들기

사전 설정 목록의 맨 위에는 세 개의 단추가 있습니다.

![](../assets/image2018-4-25-13-39-6.png)

* <b> 복제</b> : 기존 템플릿을 복제합니다.
* <b> 제거</b> : 선택한 템플릿을 삭제합니다.
* <b> 만들기</b> : 새 빈 템플릿을 만듭니다.

템플릿을 두 번 클릭하거나 <b>마우스 오른쪽 버튼 클릭 > 이름 바꾸기</b>를 통해 템플릿 이름을 변경할 수도 있습니다.

## 출력 맵 만들기

템플릿을 선택하면 창의 가운데 섹션 상단에 있는 전용 버튼을 사용하여 새 출력 맵을 추가할 수 있습니다.

![](../assets/output-buttons.png)

![](../assets/output-map.gif)

맵을 만든 후에는 이름을 지정하고 입력 맵을 사용 가능한 채널 슬롯 중 하나로 끌어 놓을 수 있습니다.\
입력 맵을 출력 맵 섹션에 놓으면 해당 슬롯에 로드할 내용 유형을 묻는 메뉴가 열립니다.

옵션은 <b>RGB</b> 및 <b>개별</b> 채널부터 <b>Alpha</b> 및 <b>회색 음영</b> 입력 변환까지 다양합니다.

>[!NOTE]
>
> 입력 맵을 드래그 앤 드롭할 때마다 임의의 색상이 생성됩니다. 이는 채널 및 로드되는 해당 입력 맵에 대한 시각적 큐를 제공한다.\
> 이 단추는 슬롯에 로드된 항목도 나타냅니다.
> 
> * 배경색: 로드되는 <b>입력</b> 맵을 나타냅니다.
> * RGB 표시줄: 입력 맵의 <b>R</b> , <b>G</b> 및 <b>B</b> 채널이 로드되었음을 나타냅니다.
> * 빨간색 막대: 입력 맵에서 <b>빨강</b> 채널이 로드되었음을 나타냅니다.
> * 녹색 막대 : 입력 맵에서 <b>녹색</b> 채널이 로드되었음을 나타냅니다.
> * 파란색 막대: 입력 맵에서 <b>파란색</b> 채널이 로드되었음을 나타냅니다.
> * 회색 막대: 입력 맵이 <b>회색 음영</b>(RGB에서 회색 음영 변환으로 또는 입력이 이미 회색 음영에 있기 때문에)으로 로드되었음을 나타냅니다.
> * 흑백 선: 입력 맵의 <b>알파</b> 채널이 로드되었음을 나타냅니다. Substance 3D Painter에서 입력의 알파는 칠해진 전체 영역에 해당합니다.

## 출력 맵 이름 지정

![](../assets/output-name.gif)

일부 플래그는 내보내기 프로세스 중에 텍스처 이름을 자동으로 생성하는 데 사용할 수 있습니다.

* <b> $mesh</b>: 프로젝트에 로드된 메시 파일의 이름
* <b> $textureSet</b> : 텍스처 집합 이름
* <b> /</b>(슬래시): 폴더 분리

<b> 예</b> : &quot;MaterialBase&quot;라는 이름의 텍스처 집합이 있는 cymourai.fbx

* <b>$mesh\_$textureSet\_BaseColor</b>은(는) <b>cymourai\_MaterialBase\_BaseColor.png를 생성합니다.</b>
* <b>$mesh/$textureSet\_BaseColor</b>은(는) <b>MaterialBase\_BaseColor.png</b>라는 이름의 텍스처가 있는 <b>cymourai</b> 폴더를 생성합니다.

>[!NOTE]
>
> 내보내기 형식이 **PSD**(Photoshop) 파일 형식으로 설정된 경우 폴더가 그룹으로 자동 변환됩니다.

## 출력 맵에 채널 할당

![](../assets/empty-channel.gif)

출력 맵의 일부 채널을 완전히 비워 둘 수 있습니다. 이 경우 기본 색상이 할당됩니다.

>[!NOTE]
>
> 내보내는 동안 텍스처 세트에 없는 채널을 슬롯이 참조하는 경우 기본 색상도 생성됩니다.\
> 이 색상은 최상의 중간 값을 제공하는 채널에 따라 달라집니다.\
>  **예** : 누락된 경우 Height 채널이 기본 회색 값으로 생성됩니다.

다음과 같이 다양한 유형의 지도가 있습니다.

* <b>입력 맵</b>: 텍스처 집합에 추가할 수 있는 직접 채널입니다. 텍스처 세트 설정 패널에서
* <b> 메시 맵</b>: 텍스처 집합의 추가 맵 슬롯에 텍스처가 있습니다(구워진 텍스처).
* <b> 변환된 맵:</b>개의 가상 텍스처가 문서에 있는 채널을 기반으로 내보내는 동안 생성됩니다.
  * <b>표준 OpenGL/DirectX</b> : 추가 맵의 표준, Height 및 표준 채널을 결합하여 전용 공간에 표준을 출력합니다.
  * <b>혼합된 AO</b>: 앰비언트 오클루전 추가 맵을 앰비언트 오클루전 채널과 결합합니다.
  * <b>확산</b>: BaseColor 및 금속 채널에서 생성된 확산 색상입니다(금속 부분은 검정색으로 대체됨).
  * <b>Specular</b>: BaseColor 및 Metallic 채널에서 생성된 Specular 색상입니다.
  * <b>광택</b>: 거칠음 채널의 반전입니다.
  * <b>Unity4 확산</b>: Unity4 셰이더와 일치하도록 BaseColor에서 생성된 확산 색상입니다.
  * <b>Unity4 광택</b>: Unity4 음영과 일치하도록 거칠음과 금속 채널에서 광택이 생성되었습니다.
  * <b>반사</b>: 흰색이 유전체 재질을 나타내고 금속 재질을 나타내는 다른 색상을 나타내는 지도를 내보냅니다
  * <b>1/ior</b>: 1을 ior 값으로 나누면 ior가 금속 맵에서 생성됩니다. 유전체는 1.4, 금속은 100(흑색)
  * <b>광택<sup>2</sup></b>: 광택 채널의 사각형 버전(광택 \* 광택)
  * <b>f0</b>: 프레넬 0에서의 반사도 값(유전체의 경우 0.04, 금속의 경우 1.0)
