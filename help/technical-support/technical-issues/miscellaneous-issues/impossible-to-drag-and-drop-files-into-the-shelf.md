# 셸프로 파일을 드래그하여 놓을 수 없음

**Windows 8 및 Windows 10**&#x200B;에서 관리자 모드에서 Substance 3D Painter을 실행하면 소프트웨어의 보안 수준이 Windows 탐색기의 보안 수준보다 높을 수 있습니다. 따라서 Windows에서는 이러한 응용 프로그램 간에 파일을 끌어다 놓을 수 없습니다.

이 문제를 해결하려면 다음 중 하나를 수행하십시오.

* Substance 3D Painter을 관리자 권한 없이 정상적으로 실행합니다.
* UAC를 사용하지 않도록 설정합니다(**권장되지 않음** ).

>[!NOTE]
>
> 다음과 같이 가져오기 창을 열면 리소스를 가져올 수도 있습니다.
> 
> 1. &quot;파일&quot; 메뉴를 클릭합니다.
> 1. &quot;리소스 가져오기...&quot;를 선택합니다.
> 1. 가져오기 창에서 &quot;리소스 추가&quot;를 클릭하여 파일을 선택합니다.
