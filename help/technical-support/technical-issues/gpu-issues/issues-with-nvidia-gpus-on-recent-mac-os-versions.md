# 최신 Mac OS 버전의 Nvidia GPU 문제

Mac OS에서 Apple은 GPU 생성자가 제공한 후에 유효성을 검사하여 GPU 드라이버를 제공합니다. Mac OS Mojave 이후 Apple은 최신 Nvidia GPU에 대한 새 드라이버의 유효성을 아직 확인하지 않았습니다. Substance 3D Painter이 제대로 작동하려면 최신 GPU 드라이버가 필요합니다.

자세한 내용은 다음 페이지를 참조하십시오.

* [Mac OS에서 지원되는 GPU 목록](https://support.apple.com/en-us/HT208898) .
* [Mac OS에서 외부 GPU 사용](https://support.apple.com/en-us/HT208544) .
