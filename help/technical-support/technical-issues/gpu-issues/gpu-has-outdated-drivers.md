# GPU에 오래된 드라이버가 있음

![](../../../assets/driver-outdated.png){width="500px"}

Substance 3D Painter을 실행할 때 GPU 드라이버가 오래되었다는 팝업 창이 나타날 수 있습니다. 이 메시지는 소프트웨어에 최소 버전의 GPU 드라이버가 설치되어 있어야 한다는 의미입니다. 최상의 작업 경험을 얻으려면 GPU 드라이버를 가능한 최신 버전으로 업데이트하는 것이 좋습니다.

| *공급업체* | *링크* |
| --- | --- |
| **NVIDIA** | [http://www.nvidia.com/Download/index.aspx](http://www.nvidia.com/Download/index.aspx?lang=en-us) <ul data-preserve-html="true"><li data-preserve-html="true"><strong> GeForce </strong> : &quot;Studio 드라이버&quot;(SD) 버전 권장.</li><li data-preserve-html="true"><strong> Quadro </strong>: &quot;Optimal Driver for Enterprise&quot;(ODE) 버전이 권장됩니다.</li></ul> |
| **AMD** | <http://support.amd.com/en-us/download> |
| **인텔** | <https://downloadcenter.intel.com/> |

>[!NOTE]
>
> 일부 컴퓨터 <b>에는 2개의 GPU</b>가 있을 수 있습니다. 하나는 내장형 칩셋이고 다른 하나는 전용 GPU입니다(예: Nvidia 그래픽 카드). Painter에서 버그 위험을 최소화하려면 <b>둘 다 <b>최신 상태 </b>여야 합니다.</b>
