# 로그 파일 내보내기

이 페이지에서는 응용 프로그램 로그 파일을 찾는 방법과 지원을 요청하기 위해 공유할 수 있는 방법에 대해 설명합니다.

## 로그 파일을 검색하는 중

로그 파일을 얻는 방법에는 두 가지가 있습니다.

### 애플리케이션에서 로그 파일 내보내기

**도움말** 메뉴에서 **로그 내보내기** 작업을 선택하여 로그 파일을 응용 프로그램에서 직접 내보낼 수 있습니다.

![](../assets/screenshot-20210622-195334.png)

### 디스크에서 수동으로 로그 파일 검색

애플리케이션이 실행되지 않으면 로그 파일을 내보낼 수 없습니다. 다행히도 로그 파일은 디스크에서 수동으로 찾을 수 있습니다. 아래에서 운영 체제와 일치하는 폴더로 이동하여 **log.txt** 파일을 수동으로 검색하십시오.
