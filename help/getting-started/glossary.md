# 용어집

Substance 3D Painter은 처음에는 이해하기 어려울 수 있는 많은 기술과 기술 키워드에 의존하는 3D 애플리케이션입니다.\
이 페이지에는 응용 프로그램에 사용되는 가장 일반적인 키워드와 그 뒤에 있는 개념에 대한 간단한 설명이 나열됩니다.

| *키워드* | *정의* |
| --- | --- |
| **맞춤** | 정렬은 페인팅할 때 브러시가 3D 메쉬를 향하는 방식입니다. |
| **Alpha** | 알파 는 세부 사항이나 복잡한 모양(예: 바코드 또는 로고)을 페인트 하는 데 사용할 수 있는 마스크입니다. |
| **굽기** | 베이크(또는 베이크)는 3D 메쉬에서 정보를 연산하여 메쉬의 UV 정보를 바탕으로 텍스처에 저장하는 작용을 말한다. |
| **비트 심도** | 비트 심도는 색상 당 텍스처에 저장할 수 있는 정보의 양입니다. 숫자가 높을수록 정보의 정밀도가 향상됩니다. 그러나 계산을 수행할 때 높은 수치에 따라 성능이 저하됩니다. |
| **브러시** | 브러시는 망 위에 칠하는 도구입니다. 브러시는 크기 및 불투명도와 같은 비헤이비어를 제어하는 여러 매개 변수로 정의됩니다. |
| **카메라** | 카메라는 3D 또는 2D 뷰포트에서 보는 위치와 방향을 제어할 수 있는 개체입니다. |
| **채널** | 채널은 특정 비헤이비어를 사용하는 텍스처입니다. 일부 채널은 재질의 색상을 정의하는 데 사용되고, 일부 다른 채널은 표면 위의 비헤이비어 조명을 제어하는 데 사용됩니다. |
| **복제** | 클론은 페인팅/텍스처의 일부를 다른 위치에 복제하는 데 사용되는 도구입니다. |
| **콘텐츠/마스크** | 콘텐츠와 마스크는 레이어의 두 가지 주요 속성을 말합니다. 콘텐츠는 레이어에 포함된 채널에 저장된 실제 페인팅이며, 마스크는 콘텐츠를 표시하거나 숨기는 데 사용됩니다. 검은색 마스크는 보이지 않는 콘텐츠와 같습니다. |
| **확산** | 확산은 메쉬의 UV 섬 밖에서 정보를 생성하는 방법입니다. 이 효과는 UV 섬 테두리 근처에 있는 마지막 픽셀을 출혈하여 흐린 색상을 만드는 방식으로 작동합니다. |
| **확장/패딩** | 확산과 같은 생각으로, 확장은 픽셀 색상을 확장하여 UV 섬 밖의 정보를 생성하는 방식이다. |
| **효과** | 효과는 레이어나 내용 또는 마스크에 추가할 수 있는 요소입니다. Substance 3D Painter은 필터 등 다양한 유형의 효과를 지원합니다. |
| **환경** | 환경은 장면의 조명을 계산하는 데 사용되는 이미지이며 일반적으로 광범위한 색상 정보를 나타내는 HDR 텍스처입니다. |
| **내보내기** | 내보내기 작업은 응용 프로그램 내부에 구현된 페인팅에서 병합된 텍스처를 생성하는 방법입니다. 내보내기에서 생성된 텍스처는 다른 애플리케이션에서 사용할 수 있습니다. |
| **FOV/시야** | FOV는 카메라에 의해 관찰 가능한 세계의 범위입니다. |
| **채우기** | 채우기는 전체 3D 메시에 색상, 텍스처 또는 재질을 로드할 수 있는 작업(효과나 레이어가 될 수 있음)입니다. |
| **필터** | 필터는 이전 정보를 수정할 수 있는 Substance 효과입니다. 예를 들어 흐림 효과 필터는 이전 이미지를 부드럽게 만듭니다. 필터는 더 복잡할 수 있으며 전체 재질을 수정할 수 있습니다. |
| **필터링** | 필터링은 텍스처가 3D 뷰포트 내에 표시되는 방식을 참조합니다. 가장 일반적인 것은 가장 가까운 거리(픽셀은 있는 그대로 읽히므로 이미지가 위쪽으로 막히게 됨)와 쌍선형 거리(픽셀이 보간되어 이미지가 흐리게 위쪽으로 흐리게 보임)입니다. |
| **GPU** | GPU(그래픽 처리 장치)는 이미지를 생성하기 위한 빠른 계산을 수행하는 컴퓨터의 부분입니다. |
| **생성기** | 제네레이터는 일반적으로 추가 텍스처를 기반으로 새 정보/이미지를 생성하는 Substance입니다. 예를 들어 일부 마스크 생성기는 구운 텍스처를 사용하여 복잡한 마스크를 만듭니다. |
| **막대 그래프** | 히스토그램은 색상 값의 분포를 그래픽으로 표현한 것입니다. 이미지의 어두운 영역, 중간 영역, 밝은 영역 사이에서 색상이 어떻게 균형을 이루는지 시각화하는 데 사용됩니다. |
| **Iray** | Iray는 NVIDIA에서 만든 경로 추적기 렌더러로 3D 메시에 사실적인 조명을 투영하는 데 사용됩니다. 고급 렌더러이므로 실시간 작업에 사용하지 않고 예쁜 이미지를 만들기 위한 것입니다. |
| **지터** | 지터는 페인팅 시 임의의 비헤이비어를 생성하는 브러시의 속성입니다. |
| **레이어** | 레이어 는 혼합 모드 및 불투명도와 같은 추가 속성이 있는 여러 채널이 포함된 요소입니다. |
| **레이어 스택** | 레이어 스택은 레이어를 관리하고 구성할 수 있는 곳입니다. 레이어는 아래에서 위로 구성됩니다. 맨 아래 레이어가 먼저 그려지고 위의 각 레이어가 하나씩 서로의 위에 추가됩니다. |
| **게으른 마우스** | 레이지 마우스는 브러쉬 툴의 비헤이비어입니다. 브러시 패스의 속도를 늦춰서 페인팅 시 정밀도를 높이고 마우스 커서와 실제 페인팅 사이에 지연/오프셋을 만들었습니다. |
| **수준** | [레벨]은 막대 그래프를 통해 범위 또는 색상/회색 음영 정보를 제어할 수 있는 효과입니다. 예를 들어 색상을 반전하거나 색상을 어둡게/밝게 하는 데 사용할 수 있습니다. |
| **로그** | 로그는 일반적으로 응용 프로그램을 실행하는 컴퓨터와 관련된 소프트웨어에서 작성된 정보가 있는 텍스트 파일입니다. |
| **낮은/높은 폴리 메시** | 낮은 폴리 메쉬와 높은 폴리 메쉬는 모두 3D 메쉬이며, 하나는 다각형 밀도가 낮은 반면 다른 하나는 더 많은 양의 폴리 카운트(종종 100배 더 큼)를 사용합니다. 일반적으로 높은 메시 정보는 낮은 메시로 압축됩니다. |
| **재질** | 물질은 특정 물질을 나타내는 특성을 정의합니다. 3D 메쉬에서 재질은 다각형 면 그룹을 정의하는 데도 사용됩니다. |
| **메시** | 메시 는 여러 정보에 의해 정의된 3D 개체입니다. Substance 3D Painter에서 메시는 다각형(일반적으로 삼각형)으로 정의됩니다. **블렌더** 또는 **Autodesk Maya** 같은 3D 모델링 응용 프로그램에서 메시를 만들 수 있습니다. |
| **메시 맵** | 메시 맵은 메시와 관련된 정보를 포함하는 메시에서 작성된 맵입니다. 예를 들어, 포지션의 정보이거나, 오클루전의 정보일 수 있다. |
| **Mip-맵** | Mip-map은 미리 계산된 텍스처으로, 일반적으로 원래 해상도보다 낮은 텍스처로 매번 이미지 시퀀스로 존재합니다. |
| **모드** | 모드는 모드에 따라 특정 도구 및 컨트롤 세트에 액세스할 수 있는 인터페이스 설정을 의미합니다. |
| **노이즈** | 노이즈는 프로시저 임의 이미지로, 일반적으로 유기적인 모양과 색상/회색 음영 값을 나타냅니다. |
| **표준** | 수직 은 3D 메시 표면에서 조명이 동작하는 방식을 변형하여 형상에 없는 세부 사항을 시뮬레이션하는 특수 텍스처입니다. |
| **OpenGL/DirectX** | OpenGL 및 DirectX은 모두 2D 및 3D 정보를 렌더링하는 데 사용되는 API(응용 프로그래밍 인터페이스)입니다. 표준 맵 포맷 정의 |
| **정사영** | 직교 투영은 모든 투영선이 투영 평면에 직교하는 2차원으로 3차원 물체를 나타내는 수단이다. |
| **PBR/PBS** | PBR(Physically Based Rendering) 또는 PBS(Physically Based Rendering)는 실제 환경에서 빛의 흐름을 보다 정확하게 모델링하는 방식으로 그래픽을 렌더링하려는 컴퓨터 그래픽 모델입니다. |
| **패킹** | 패킹은 하나의 텍스처 안에 여러 개의 이미지를 저장하는 작업입니다. 텍스처는 구분된 빨강, 녹색 및 파랑 채널로 구성되어 있으므로 다른 응용 프로그램에서 독립적으로 읽을 수 있는 다양한 정보를 저장할 수 있습니다. |
| **파티클** | 파티클은 물리적 속성이나 기타 복잡한 비헤이비어를 기반으로 브러쉬 획을 생성하는 일종의 도구입니다. |
| **원근감** | 원근감은 (스크린과 같이) 평평한 표면에서 사람의 눈으로 볼 수 있는 개체 또는 장면의 대략적인 표현입니다. 이것은 깊이와 규모의 시뮬레이션입니다. |
| **픽셀/텍스트** | 픽셀은 이미지에서 점이며 색상 정보를 포함하는 요소 중 가장 작은 요소입니다. 해상도가 클수록 더 많은 픽셀을 사용할 수 있으므로 더 나은 정의와 더 많은 세부 사항을 구현할 수 있습니다. 텍셀은 텍스처 내의 픽셀입니다. |
| **플러그 인** | 플러그인은 소프트웨어에 추가될 수 있는 프로그래밍 함수(스크립팅을 통해 종종 표현됨)로, 애플리케이션의 가능성을 확장합니다. |
| **사후 프로세스** | 후처리는 3D 이미지가 렌더링되면 화면에 적용되는 시각 효과로, 색상 교정이나 흐림 효과와 같은 특수 동작을 시뮬레이션하는 경우가 많습니다. |
| **절차** | 프로시저는 일련의 매개 변수를 기반으로 컴퓨터에서 생성되는 프로세스를 설명하는 용어입니다. 단순히 숫자나 복잡한 이미지 같은 수학 결과일 수도 있다. |
| **투영** | 투영은 특정 시점(예: 카메라)에서 이미지/개체를 3D 메시 표면에 적용하는 작업입니다. |
| **해상도(2 전원)** | 해상도는 X 및 Y 축 또는 폭과 Height 상의 텍스처 크기를 정의합니다. 종종 2 규모의 파워 (2, 4, 8, 16... 512, 1024, 2048...) GPU의 계산에 최적화되어 있기 때문입니다. |
| **스크립팅** | 스크립팅은 특정 비헤이비어를 실행하기 위해 텍스트 기반 파일 형식을 통해 특정 명령을 사용하거나 작업을 수행하는 것입니다. |
| **셰이더** | 셰이더는 조명 정보를 수신할 때 재료의 동작을 정의합니다. 일부 셰이더는 단순한 형태(예: 툰 음영)이거나 고급 형태(예: 표면에서 빛 흡수를 시뮬레이션하는 스킨 음영)일 수 있습니다. |
| **선반** | 선반은 응용 프로그램에서 여러 종류의 리소스가 구성되는 위치입니다. 단순한 이미지에서 보다 복잡한 도구로 이동할 수 있습니다. |
| **스마트 마스크** | 스마트 마스크는 스마트 재질과 같이 작동하지만 레이어가 아니라 현재 3D 메시만 기반으로 마스크를 생성하도록 정의된 효과입니다. |
| **스마트 재질** | 스마트 재질 은 하나의 파일로 저장된 레이어 그룹입니다. 스마트 재질은 Substance 3D Painter의 각 프로젝트에 맞게 조정되어 현재 3D 메시에 따라 변경될 재질을 만들 수 있습니다. |
| **손가락** | 손가락 은 번짐, 번짐 또는 색상 혼합 도구입니다. 이 효과는 픽셀을 부드럽게 하는 데 주로 사용됩니다. |
| **스텐실** | 스텐실 은 화면에 정렬되고 카메라 투영과 함께 사용되어 3D 메쉬에 페인트를 지정하는 이미지입니다. |
| **Substance** | Substance은 프로시저 계산과 관련된 매개 변수 집합을 기반으로 텍스처를 생성할 수 있는 파일 형식입니다. 이러한 매개변수를 수정하여 변형을 생성할 수 있습니다. |
| **대칭** | 대칭은 미러에서 동시에 두 위치에서 페인트 할 수 있는 도구의 옵션입니다. |
| **템플릿** | 템플릿은 새 프로젝트를 만들 때 사용되는 미리 정의된 옵션 세트입니다. 예를 들어, 기본 해상도 또는 기본 베이킹 설정을 정의할 수 있습니다. |
| **텍스트 비율** | 텍셀 비율은 UV 섬(2D)의 크기와 이와 관련된 3D 메쉬의 형상을 비교하는 규칙이다. 좋은 텍스처 비율은 2D 형상의 균일한 펼침을 의미합니다. 이는 3D 메쉬에서 페인팅/텍스처링의 모양과 품질을 일정하게 유지하는 데 중요합니다. |
| **텍스처** | 텍스처는 해상도로 정의된 2차원 픽셀로 구성된 파일입니다. 픽셀은 회색 음영이거나 색상이 적용될 수 있습니다. 색상이 지정된 경우 픽셀에는 투명도 정보가 있을 수 있습니다(파일 형식에서 지원하는 경우). |
| **텍스처 집합** | Substance 3D Painter에서 텍스처 세트는 페인트할 특정 UV가 있는 메쉬의 일부를 나타냅니다. 텍스처 세트는 3D 메시를 가져올 때 검색된 고유한 재질에 따라 생성됩니다. |
| **틸링** | 틸링은 테두리에 솔기가 보이지 않는 텍스처의 반복으로, 무한 평면을 시뮬레이션하기 위한 것입니다. 예 : 잔디 또는 pavinations. |
| **도구** | 페인트는 3D 메쉬와 상호 작용하여 효과를 적용하도록 허용하는 작업을 의미합니다. |
| **도구 모음** | 도구 모음은 도구에 대한 모든 아이콘 단축키를 사용할 수 있는 위치입니다. |
| **UDIM** | UDIM 는 일반적인 텍스처 해상도를 높이기 위해 3D 메시의 UV를 여러 범위에 걸쳐 분할하는 방법입니다. |
| **UV** | UV는 3D 메쉬에 정의된 정보로, 어떻게 펼쳐서 평평한 모양이 될 수 있는지 나타냅니다. 이 정보는 3D 메시에 텍스처를 투영하는 데 사용됩니다. Substance 3D Painter에서는 텍스처 크기를 나타내는 0-1 범위에서만 페인트를 수행할 수 있습니다. 다른 범위는 UDIM 시스템을 통해서만 지원됩니다. |
| **VRam** | VRam은 GPU(그래픽 카드)의 메모리이며, 계산을 수행할 때 정보와 텍스처를 저장하는 데 사용됩니다. VRam이 많을수록 Substance 3D Painter 작업을 더 잘 할 수 있습니다. |
| **뷰포트** | 뷰포트는 3D 또는 2D 장면이 화면에 표시되는 곳입니다. 여기서 카메라를 제어하여 도구 및 3D 메시와 상호 작용할 수도 있습니다. |
