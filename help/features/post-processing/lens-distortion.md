# 렌즈 왜곡

![](../../assets/lens-distortion-2.jpg)![](../../assets/lens-distortion-3.png)

렌즈 왜곡은 이미지 둘레에 대해 팽창하거나 수축하는 광학 현상이다. 이러한 팽윤을 배럴 왜곡(barrel diamond)이라 하고, 수축을 핀쿠션 왜곡(pincushion quamond)이라 한다.\
카메라 렌즈가 좋을수록 이러한 현상이 적게 발생합니다. 이 효과는 불완전한 렌즈를 시뮬레이션하여 보다 사실적인 이미지를 만드는 데 사용할 수 있습니다.

| *설정* | *설명* |
| --- | --- |
| **전원** | 화면 가장자리에서 왜곡이 적용되는 속도를 제어합니다. |
| **FOV** | 렌즈 왜곡(시뮬레이션된 시야각)의 양을 제어합니다. |
| **가장자리 원형률** | 모서리나 뷰포트에서 둥근 모양을 제어합니다. |
| **Edge Smoothness** | 뷰포트의 검정색 가장자리의 경도/Smoothness을 제어합니다. |
