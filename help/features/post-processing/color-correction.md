# 색상 교정

![](../../assets/color-correction-example.jpg)![](../../assets/color-correction.png)

색상 교정 매개 변수 :

| *설정* | *설명* |
| --- | --- |
| **채도** | 뷰포트에서 색상의 강도/채도를 제어합니다. 0에서 채도를 사용하여 회색 음영 렌더링을 가져옵니다. |
| **대비** | 밝은 색상과 어두운 색상의 차이를 제어합니다. |
| **밝기** | 색상의 밝기/광도를 제어합니다. |
| **편향** | 뷰포트의 광도를 전체적으로 오프셋합니다. |
| **세피아 톤 비율** | 뷰포트에 세피아 효과를 주는 고급 매개 변수입니다. |
| **흰색 균형 온도(K)** | 색상의 온도(켈빈)입니다. 기본값은 일광에 해당하는 6500K입니다. [자세한 내용은 위키백과](https://en.wikipedia.org/wiki/Color_temperature)를 참조하세요. |
