# 선명하게

![](../../assets/v12_post_sharpen.jpg)

이미지의 가장자리와 미세한 세부 사항을 향상하여 인지되는 선명도를 높입니다.

| <b>매개 변수</b> | <b>설명</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>금액</b> | 선명하게 하기 효과의 강도를 제어합니다. 값이 높을수록 가장자리 대비가 더 급격하게 증가합니다. |
| <b>직경</b> | 선명하게 하기 효과의 크기를 픽셀 단위로 설정합니다. 값이 작을수록 미세한 세부 사항이 선명해지고, 값이 클수록 더 넓은 가장자리에 영향을 미쳐 더 뚜렷한 효과가 만들어집니다. |
