# 측면 수차

![](../../assets/v12_post_aberration.jpg)

이미지 중심에서 바깥쪽으로 색상 채널을 이동하고 실제 카메라 렌즈 가장자리에서 볼 수 있는 색록을 재현하여 색수차를 시뮬레이션합니다.

| <b>매개 변수</b> | <b>설명</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>금액</b> | 색록 효과의 강도를 제어합니다. 값이 높을수록 가장자리를 향한 채널 분리가 더 뚜렷해집니다. |
| <b>반경</b> | 영향을 받지 않는 가운데 영역의 크기를 제어합니다. 이 값이 작을수록 수차 효과가 중심에 가깝게 밀려 이미지에 더 많은 영향을 미칩니다. |
| <b>부드러움</b> | 수정된 가운데와 수정된 가장자리 사이의 전환 Smoothness을 제어합니다. |
| <b>비율</b> | 영향을 받는 영역의 종횡비를 설정합니다. 값을 1로 설정하면 원 모양이 만들어지고 값을 1보다 크게 설정하면 더 넓은 타원 패턴이 만들어집니다. |
| <b>가운데 X</b> | 수차가 방사되는 광학 중심의 가로 위치입니다. |
| <b>Y 가운데</b> | 수차가 방사되는 광학 중심의 수직 위치입니다. |
| <b>무채색 이상</b> | 수차 색상을 표준 무지개색에서 녹색/보라색 톤으로 전환합니다. |
