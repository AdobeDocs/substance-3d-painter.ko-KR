# 개화

![](../../assets/v12_post_bloom.jpg)

장면의 밝은 영역 주위에 부드러운 광선을 만듭니다. 밝은 분위기에서 빛이 어떻게 산란 되는지 시뮬레이션합니다.

| <b>매개 변수</b> | <b>설명</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>금액</b> | 흐림 효과의 강도를 제어합니다. 값이 높을수록 밝은 영역 주변에서 더 뚜렷한 광선이 만들어집니다. |
| <b>임계값</b> | 개화를 트리거하는 데 필요한 최소 밝기 수준을 설정합니다. 이 값보다 밝은 픽셀만 빛납니다. 한계값 1.0은 스크린 흰색보다 밝은 픽셀만 흐른다는 것을 의미합니다. |
| <b>밝기 감소</b> | 밝은 영역에서 개화가 확산되는 거리를 결정합니다. 값이 낮을수록 광선이 더 컴팩트하게 표시되고 값이 높을수록 더 넓은 영역에 효과가 확산됩니다. |
