# 렌즈 플레어

![](../../assets/v12_post_flare.jpg)

밝은 광원이 카메라 렌즈 요소와 상호 작용할 때 생성되는 광학 아티팩트를 시뮬레이션하여, 후광, 줄무늬 및 고스트 반사를 만듭니다.

| <b>매개 변수</b> | <b>설명</b> |
| --- | --- |
| <b>해상도</b> | 렌즈 플레어 효과의 내부 렌더링 해상도를 설정합니다. 값이 높을수록 줄무늬가 선명해지지만 성능에 영향을 줄 수 있습니다. |
| <b>카메라</b> | 플레어를 시뮬레이션하는 데 사용되는 카메라 모델을 선택합니다. 가능한 값은 다음과 같습니다.<ul data-preserve-html="true"> <li data-preserve-html="true"><b>파노라마 렌즈</b>(짧은 초점 거리) </li> <li data-preserve-html="true"><b>망원 렌즈</b>(긴 초점 거리).</li> </ul> |
| <b>금액</b> | 플레어 효과의 전체 강도를 제어합니다. 이 값은 1.0을 초과하여 강도를 높일 수 있습니다. |
| <b>임계값</b> | 플레어를 생성하는 데 필요한 이미지의 최소 광도를 결정합니다. 값이 낮을수록 더 많은 영역에서 플레어가 발생하고, 값이 높을수록 효과가 매우 밝은 광원으로 제한됩니다. |
| <b>조리개 배율</b> | 플레어 계산에 사용되는 조리개 모양의 크기를 조절하며 플레어 요소의 전체 크기에 영향을 줍니다. |
| <b>코팅 두께</b> | 렌즈 요소의 반사 방지 코팅을 시뮬레이션합니다. 코팅 Thickness은 빛의 산란에 영향을 주므로 플레어의 색상을 변경합니다. |
| <b>코트 IOR</b> | Thickness의 굴절률, 즉 빛이 렌즈를 통과하는 방식을 시뮬레이션합니다. 값이 낮을수록 고스트가 더 집중됩니다. |
| <b>오클루전 크기</b> | 영향을 받는 중심 영역의 크기를 설정합니다. |
| <b>오클루전 Smoothness</b> | 렌즈 플레어가 서서히 사라지는 정도를 제어합니다. 값이 높을수록 전환이 더 부드러워집니다. |
| <b>고유 고스트</b> | 플레어 모양의 변화를 정의합니다. 값이 높을수록 성능이 크게 저하될 수 있습니다. |
| <b>고스트 위치 비율</b> | 플레어 고스트의 확산과 크기를 제어합니다. |
| <b>조리개 텍스처</b> | 플레어 패턴을 생성하는 데 사용되는 렌즈 조리개의 모양을 정의합니다. 텍스처는 회절 및 고스트 모양을 제어합니다. |
