# 필름 그레인

![](../../assets/v12_post_grain.jpg)

이미지에 필름 그레인 노이즈 패턴을 추가하여 아날로그 사진 필름의 유기 텍스처를 시뮬레이션합니다.

| <b>매개 변수</b> | <b>설명</b> |
| --- | --- |
|  |  |
| --- | --- |
| <b>금액</b> | 그레인의 가시성과 강도를 제어합니다. 값이 높을수록 더 뚜렷하고 눈에 띄는 노이즈가 생성됩니다. |
| <b>반경</b> | 개별 그레인 입자의 크기를 픽셀 단위로 설정합니다. 값이 작을수록 더 세밀하고 미세한 그레인이 만들어지고, 값이 클수록 텍스처가 거칠고 선명해집니다. |
| <b>유형</b> | 단색 또는 컬러 노이즈 중에서 선택합니다. |

>[!NOTE]
>
> 이 효과로 인해 생성된 노이즈는 뷰포트를 새로 고칠 때마다 다시 생성됩니다. 그림자가 생성되거나 카메라를 회전할 때 노이즈가 업데이트될 수 있는 이유입니다.
