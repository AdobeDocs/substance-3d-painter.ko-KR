# 삼면 고급

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_tri_planar_advanced.png" alt=""/><br><strong>인:</strong> 마스크, 생성기</td>
    <td style="border: 0;" valign="top"><strong>설명</strong><br>Tri-Free Advanced 생성기는 모든 회전 및 각각의 개별 축에 대한 오프셋 값을 제어하는 것을 포함하여 전체 투영을 위한 수동 컨트롤을 제공하는 삼각 평면 혼합 모드의 독립 버전입니다. 기본 채우기 투영과 비교하여 Tri-평면 고급 생성기는 월드-공간 표준을 사용하여 세 개의 투영 축을 혼합하는 반면, 기본 구현은 낮은 폴리 형상에만 의존합니다. 이를 통해 보다 세밀한 제어와 정확한 결과를 얻을 수 있습니다.<br><br>3색 평면 고급 생성기는 흑백 텍스처를 출력합니다. 따라서 마스크로 사용할 사용자 정의 마스크 또는 고정점의 3배 평면 혼합을 생성하는 데 유용합니다.<br><br>구겨진 위치 및 월드 공간 표준 맵이 이미지 입력으로 필요합니다. <a href="../../../baking/baking.md">여기서 굽는 방법에 대해 자세히 알아보세요</a>.</td>
  </tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| **월드 스페이스 표준** 색상 | 구워진 World Space Normals 지도를 사용합니다. |
| **위치** 색상 | 구워진 위치 맵을 사용합니다. |
| **마스크** 회색 음영 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |
