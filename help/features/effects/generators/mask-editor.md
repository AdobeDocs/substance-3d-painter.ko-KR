# 마스크 편집기

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_mask_editor_dark.png" alt=""/><strong>인:</strong> 마스크, 생성기</td>
    <td style="border: 0;" valign="top"><strong>설명</strong><br>마스크 편집기 생성기는 텍스처, 주변 오클루전, 곡률, World Space Normal, 그레이디언트, Thickness 및 미세 세부 사항을 단일 마스크로 결합할 수 있는 다목적 마스크 생성기입니다.<br>마스크 작성기 생성기는 매우 유연하지만 복잡하기 때문에 대부분의 생성기보다 성능에 더 큰 영향을 줄 수 있습니다.<br><br>마스크 편집기 생성기는 흑백 텍스처를 출력합니다. 따라서 다양한 베이킹된 맵을 기반으로 마스크를 생성하는 데 유용합니다. <br><br>구겨진 위치, Thickness, 곡률, 주변 오클루전 및 세계 공간 표준 맵이 이미지 입력으로 필요합니다. <a href="../../../baking/baking.md">여기서 굽는 방법에 대해 자세히 알아보세요</a>.</td>
  </tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| **텍스처** 색상 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |
| **텍스처(보조)** 색상 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |
| **월드 스페이스 표준** 색상 | 구워진 World Space Normals 지도를 사용합니다. |
| **위치 그라디언트** 색상 | 구워진 위치 맵을 사용합니다. |
| **Thickness** 회색 음영 | 구운 Thickness 맵을 사용합니다. |
| **곡률** 회색 음영 | 구워진 곡률 맵을 사용합니다. |
| **주변 오클루전** 회색 음영 | 구워진 Ambient 오클루전 맵을 사용합니다. |
| **마이크로 표준** 색상 | 사용자 정의 표준 텍스처 또는 고정점을 사용합니다. |
| **마이크로 Height** 색상 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| **전역 반전** | 모든 레이어가 결합된 후 최종 결과를 반전합니다. |
| **전역 흐림 효과** | 모든 레이어가 결합된 후 최종 마스크를 균일하게 흐리게 합니다. |
| **전역 균형** | 명도 조정과 같이 모든 레이어를 검정 또는 흰색으로 결합한 후 최종 마스크의 균형을 조정합니다. |
| **전역 대비** | 모든 레이어가 결합된 후 최종 마스크의 대비를 조정합니다. |
| **텍스처 불투명도** | 사용자 정의 텍스처의 가시성을 조정합니다. |
| **텍스처 2 불투명도** | 두 번째 사용자 정의 텍스처의 가시성을 조정합니다. |
| **주변 오클루전 불투명도** | 주변 오클루전 세부 사항의 가시성을 조정합니다. |
| **곡률 불투명도** | 곡률 세부 사항의 가시성을 조정합니다. |
| **월드 스페이스 표준 불투명도** | 월드 스페이스 표준 세부 사항의 가시성을 조정합니다. |
| **위치 그라디언트 불투명도** | 직책 세부 사항의 가시성을 조정합니다. |
| **Thickness 불투명도** | Thickness 세부 사항의 가시성을 조정합니다. |

| **대비** | 위치 그레이디언트 레이어의 대비/밝기 감소를 조정합니다. |

>[!TIP]
>
> 위치 그레이디언트는 최대 3개의 그레이디언트, 오른쪽에서 왼쪽, 위에서 아래, 앞에서 뒤로 로 구성됩니다. 하위 그레이디언트마다 각각 다른 효과를 만들거나 모델의 다른 영역을 마스킹하는 데 사용할 수 있는 자체 혼합 모드가 있습니다. 이러한 그레이디언트의 혼합 모드는 최종 위치 그레이디언트 레이어를 만들기 위해서만 서로 상호 작용하며 위치 그레이디언트 외부의 제네레이터 내의 다른 레이어와 직접 상호 작용하지 않습니다.
