# 앰비언트 오클루전

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_ambient_occlusion.webp" alt=""/><br><strong>인:</strong> 마스크, 생성기, 회색 음영, 혼합</td>
    <td style="border: 0;" valign="top"><strong>설명</strong><br>앰비언트 오클루전 생성기는 구워진 앰비언트 오클루전 맵을 기반으로 텍스처나 미세한 세부 사항을 마스크에 혼합할 수 있는 옵션을 사용하여 마스크를 만듭니다.<br><br>앰비언트 오클루전 생성기를 사용하여 레이어 마스크를 만드는 경우 앰비언트 오클루전 출력을 반전해야 할 수 있습니다. 기본적으로, 생성기는 가려진 영역을 어둡게 그리고 가려지지 않은 영역을 빛으로 출력합니다. 마스크로 사용되는 경우 마스크된 레이어는 가려지지 않은 영역에서만 볼 수 있습니다. 출력을 반전하면 마스크된 레이어가 가려진 영역에만 표시되도록 합니다.<br><br>사전 설정 위치, 주변 오클루전 및 월드 스페이스 표준 맵이 이미지 입력으로 필요합니다. <a href="../../../baking/baking.md">여기서 굽는 방법에 대해 자세히 알아보세요</a>.</td>
  </tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| 텍스처 색상 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |
| 미세 표준 색상 | 사용자 정의 표준 텍스처 또는 고정점을 사용합니다. |
| 마이크로 Height 색상 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |
| 주변 오클루전 회색 음영 | 구워진 Ambient 오클루전 맵을 사용합니다. |
| 월드 스페이스 표준 색상 | 구워진 World Space Normals 지도를 사용합니다. |
| 위치 그라디언트 색상 | 구워진 위치 맵을 사용합니다. |

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| **전역 반전** | 모든 효과가 결합된 후 최종 결과를 반전합니다. |
| **전역 흐림 효과** | 모든 효과가 결합된 후 최종 마스크를 균일하게 매끄럽게 합니다. |
| **전역 균형** | 명도 조정과 같이 모든 효과가 검정이나 흰색 사이에 결합된 후 최종 마스크의 균형을 이동합니다. |
| **전역 대비** | 모든 효과가 결합된 후 최종 마스크의 대비를 조정합니다. |
| **텍스처 사용** | 사용자 정의 텍스처 맵 사용을 설정하거나 해제합니다. |
| **마이크로 세부 사항 사용** | 사용자 정의 마이크로 세부 사항 사용을 켜거나 끕니다. |

### 앰비언트 오클루전

| 매개 변수 이름 | 설명 |
| --- | --- |
| **반전** | 주변광 오클루전과 미세한 세부 사항만 반전합니다. |
| **흐림 효과** | 주변광 오클루전 및 미세한 세부 사항을 매끄럽게 만듭니다. |
| **균형** | 주변 오클루전과 미세한 세부 사항의 밸런스를 조정하여 명도 컨트롤처럼 중간점을 흑백 방향으로 이동합니다. |
| **대비** | 주변 오클루전 및 미세한 세부 사항만 대비/감소를 조정합니다. |

### 마이크로 세부 사항

| 매개 변수 이름 | 설명 |
| --- | --- |
| **마이크로 Height** | 사용자 정의 Micro Height 맵 사용을 켜거나 끕니다. |
| **마이크로 표준** | 사용자 정의 Micro Normal 맵 사용을 켜거나 끕니다. |
| **AO 반경** | 미세한 세부 사항에서 주변 오클루전의 반경(범위)을 조정합니다. |
| **AO 깊이** | 미세한 세부 사항에서 주변 오클루전의 깊이(강도)를 조정합니다. |
