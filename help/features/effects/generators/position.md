# 위치

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_position.webp" alt=""/><br><strong>내부:</strong> 메시, uv, 거리</td>
    <td style="border: 0;" valign="top"><strong>설명</strong><br>위치 생성기는 구워진 위치와 월드 스페이스 표준 맵을 사용하여 3D 공간에서 재질의 위치를 기반으로 그레이디언트 마스크를 만듭니다(위에서 아래로 또는 좌우로).<br><br>위치 생성기는 단색(흑백) 텍스처를 출력합니다. 따라서 월드 공간의 위치를 기반으로 그레이디언트 마스크를 생성하는 데 유용합니다.<br><br>구겨진 위치 및 월드 공간 표준 맵이 이미지 입력으로 필요합니다. <a href="../../../baking/baking.md">여기서 굽는 방법에 대해 자세히 알아보세요</a>.</td>
  </tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| **텍스처** 색상 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |
| **위치 그라디언트** 색상 | 구워진 위치 맵을 사용합니다. |
| **월드 스페이스 표준** 색상 | 구워진 World Space Normals 지도를 사용합니다. |

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| **전역 반전** | 모든 효과가 결합된 후 최종 결과를 반전합니다. |
| **전역 흐림 효과** | 모든 그레이디언트가 결합된 후 최종 마스크를 균일하게 흐리게 합니다. |
| **전역 균형** | 명도 조정과 같이 모든 그레이디언트를 검정 또는 흰색과 결합한 후 최종 마스크의 균형을 조정합니다. |
| **전역 대비** | 모든 그레이디언트가 결합된 후 최종 마스크의 대비를 조정합니다. |
| **텍스처 사용** | 사용자 정의 텍스처 맵 사용을 켜거나 끕니다. |

### 위치 그라디언트

| 매개 변수 이름 | 설명 |
| --- | --- |
| **반전** | 위치 그레이디언트만 반전합니다. |
| **균형** | 위치 그레이디언트만 균형을 조정하고 밝기 컨트롤처럼 중간점을 검정 또는 흰색으로 이동합니다. |
| **대비** | 위치 그레이디언트의 대비/밝기 감소를 조정합니다. |
| **밝기** | 위치 그레이디언트의 광도만 조정합니다. |
| **오른쪽에서 왼쪽** | 메시를 가로질러 왼쪽에서 오른쪽으로 효과가 적용되는 방법을 조정합니다. |
| **위에서 아래로** | 메쉬를 가로질러 위에서 아래로 효과가 적용되는 방법을 조정합니다. |
| **앞에서 뒤로** | 메시를 가로질러 앞에서 뒤로 효과가 적용되는 방법을 조정합니다. |

#### 그레이디언트/오른쪽에서 왼쪽으로 배치

| 매개 변수 이름 | 설명 |
| --- | --- |
| **반전** | 오른쪽에서 왼쪽으로 그라디언트 방향을 반전합니다. |
| **혼합 모드** | 오른쪽에서 왼쪽 그레이디언트에 사용할 [혼합 모드](../../../interface/layer-stack/blending-modes.md)를 선택합니다. |

#### 그레이디언트/위에서 아래로 배치

| 매개 변수 이름 | 설명 |
| --- | --- |
| **반전** | 위에서 아래로 그레이디언트 방향을 반전합니다. |
| **혼합 모드** | 위-아래 그레이디언트에 사용할 [혼합 모드](../../../interface/layer-stack/blending-modes.md)를 선택합니다. |

#### 그레이디언트/앞에서 뒤로 배치

| 매개 변수 이름 | 설명 |
| --- | --- |
| **반전** | [앞에서 뒤로] 그레이디언트 방향을 반전시킵니다. |
| **혼합 모드** | 앞뒤 그레이디언트에 사용할 [혼합 모드](../../../interface/layer-stack/blending-modes.md)를 선택합니다. |
