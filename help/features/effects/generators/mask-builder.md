# 마스크 작성기

<table>
  <tr style="border: 0;">

    <td style="border: 0;" valign="top"><strong>설명</strong><br>마스크 작성기 생성기는 마스크 편집기 생성기의 기존 버전입니다. 그런지, AO, 곡률, 그레이디언트, 월드 스페이스 노멀, Scratches, 산란, 마이크로 디테일 등을 하나의 마스크로 결합할 수 있는 다목적 마스크 생성기입니다.<br><br>마스크 작성기 생성기는 매우 유연하지만 복잡하기 때문에 대부분의 생성기보다 성능에 더 큰 영향을 줄 수 있습니다.<br><br>마스크 작성기 생성기는 단색(흑백) 텍스처를 출력합니다. 따라서 다양한 베이킹된 맵을 기반으로 마스크를 생성하는 데 유용합니다. <br><br>구겨진 위치, 곡률, 주변 오클루전 및 세계 공간 표준 맵이 이미지 입력으로 필요합니다. <a href="../../../baking/baking.md">여기서 굽는 방법에 대해 자세히 알아보세요</a>.</td>
  </tr>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| **월드 스페이스 표준** 색상 | 구워진 World Space Normals 지도를 사용합니다. |
| **사용자 지정 그런지 1** 회색 음영 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |
| **사용자 지정 그런지 2** 회색 음영 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |
| **산란 입력** 회색 음영 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |
| **위치** 색상 | 구워진 위치 맵을 사용합니다. |
| **곡률** 회색 음영 | 구워진 곡률 맵을 사용합니다. |
| **주변 오클루전** 회색 음영 | 구워진 Ambient 오클루전 맵을 사용합니다. |
| **마이크로 표준** 색상 | 사용자 정의 표준 텍스처 또는 고정점을 사용합니다. |
| **마이크로 Height** 색상 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |

### 그런지

| 매개 변수 이름 | 설명 |
| --- | --- |
| **크기 조절** | 그런지 텍스처의 크기를 조정합니다. |
| **사용자 지정 그런지 사용** | 사용자 정의 그런지 맵 사용을 켜거나 끕니다. 사용자 정의 그런지 1의 가시성입니다. 사용자 정의 그런지 2의 가시성을 제어하려면 보조 사용자 정의 그런지 슬라이더를 조정합니다. |
| **보조 사용자 지정 그런지** | 사용자 정의 그런지 2 텍스처의 가시성을 조정합니다. |
| **반전** | 그런지 맵을 반전합니다. |

### 앰비언트 오클루전

| **소음** | 곡률 결과에 노이즈를 추가하여 마스크의 명도를 효과적으로 낮춥니다. |

### 그래디언트

그레이디언트 위치는 전체 장면 또는 질감 당 정규화 배율로 구울 수 있는 위치 맵을 기반으로 합니다. 재질이 장면의 작은 영역에만 나타나고 [전체 장면 표준화] 배율로 위치 맵을 구울 경우 원하는 결과를 얻기 위해 그레이디언트 범위를 조정하는 것이 어려울 수 있습니다.

| 매개 변수 이름 | 설명 |
| --- | --- |
| **범위** | 그레이디언트 범위를 조정합니다. |
| **대비** | 그레이디언트 대비를 조정합니다. |
| **반전** | 그레이디언트를 반전시킵니다. |

### 월드 공간 표준

**앞**, **뒤**, **왼쪽** 및 **오른쪽** 값은 메쉬의 앞, 뒤, 왼쪽 및 오른쪽과 일치하지 않을 수 있습니다. 기본적으로 **정면**&#x200B;은 양의 X축에 해당하고, 오른쪽은 양의 Z축에 해당합니다.

| 매개 변수 이름 | 설명 |
| --- | --- |
| **상위 강도** | 위 아래 그레이디언트의 범위(강도)를 조정합니다. |
| **아래쪽 강도** | 상향식 그레이디언트의 범위(강도)를 조정합니다. |
| **정면 강도** | [앞면 그레이디언트]의 범위(강도)를 조정합니다. |
| **뒤로 강도** | 후면 전면 그레이디언트의 범위(강도)를 조정합니다. |
| **오른쪽 강도** | 오른쪽 왼쪽 그레이디언트의 범위(강도)를 조정합니다. |
| **왼쪽 강도** | 왼쪽 오른쪽 그레이디언트의 범위(강도)를 조정합니다. |

### 분산

| 매개 변수 이름 | 설명 |
| --- | --- |
| **크기 조절** | 산란 효과의 크기를 조정합니다. 배율이 높을수록 스탬프가 더 많이 작아지고 배율이 낮을수록 개별 스탬프 크기가 커지며 더 적게 표시됩니다. |
| **밀도** | 흩어져 있는 스탬프의 수를 조정합니다. |
| **크기** | 흩어져 있는 스탬프의 크기를 조정합니다. |
| **크기 변형** | 흩어져 있는 스탬프의 각 인스턴스 크기에 얼마나 많은 임의성이 있는지를 조정합니다. [크기 변경]을 높이면 스탬프 크기가 임의로 줄어들기 때문에 [크기 변경]을 높이면 [크기] 값을 높여서 동일한 평균 크기를 유지해야 할 수도 있습니다. |
| **불투명도 변형** | 흩어져 있는 스탬프의 각 인스턴스에 대해 불투명도가 어느 정도인지 조정합니다. |
