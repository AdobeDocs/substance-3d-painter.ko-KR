# 실제 공간 표준

  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="../../../assets/generators/icon_world_space_normals.png" alt=""/><br><strong>인:</strong> 마스크, 생성기, 회색 음영, 혼합</td>
    <td style="border: 0;" valign="top"><strong>설명</strong><br>World Space Normal 생성기는 구워진 World-Space 표준 맵을 사용하여 3D 공간에서 각 표면이 향하는 방향을 기준으로 모델에 색상을 적용하거나 효과를 적용합니다. 예를 들어 위에서 아래로<br><br>World Space 표준 생성기는 흑백 텍스처를 출력합니다. 따라서 얼굴 방향을 기반으로 Dirt, Dust, 눈, 녹 등 다양한 효과를 적용하기 위한 마스크를 생성하는 데 유용합니다.<br><br>구겨진 위치 및 월드 공간 표준 맵이 이미지 입력으로 필요합니다. <a href="../../../baking/baking.md">여기서 굽는 방법에 대해 자세히 알아보세요</a>.</td>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| **텍스처** 색상 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |
| **월드 스페이스 표준** 색상 | 구워진 World Space Normals 지도를 사용합니다. |
| **위치 그라디언트** 색상 | 구워진 위치 맵을 사용합니다. |

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| **전역 반전** | 모든 효과가 결합된 후 최종 결과를 반전합니다. |
| **전역 흐림 효과** | 모든 효과를 결합한 후 최종 마스크를 균일하게 부드럽게 합니다. |
| **전역 균형** | 명도 조정과 같이 모든 효과가 검정이나 흰색 사이에 결합된 후 최종 마스크의 균형을 이동합니다. |
| **전역 대비** | 모든 효과가 결합된 후 최종 마스크의 대비를 조정합니다. |
| **텍스처 사용** | 사용자 정의 텍스처 맵 사용을 설정하거나 해제합니다. |

### 월드 공간 표준

| 매개 변수 이름 | 설명 |
| --- | --- |
| **반전** | 월드 스페이스 표준만 반전합니다. |
| **흐림 효과** | 우주 표준만 부드럽게 만들기. |
| **균형** | 명도 컨트롤처럼 중간점을 검정 또는 흰색으로 이동하여 월드 공간 표준의 균형만 조정합니다. |
| **대비** | 월드 공간 표준의 대비/밝기 감소만 조정합니다. |
| **밝기** | 우주 표준의 광도만 조정합니다. |
| **오른쪽에서 왼쪽** | 메시를 가로질러 왼쪽에서 오른쪽으로 효과가 적용되는 방법을 조정합니다. |
| **위에서 아래로** | 메쉬를 가로질러 위에서 아래로 효과가 적용되는 방법을 조정합니다. |
| **앞에서 뒤로** | 메시를 가로질러 앞에서 뒤로 효과가 적용되는 방법을 조정합니다. |

#### 월드 공간 일반/오른쪽에서 왼쪽

| 매개 변수 이름 | 설명 |
| --- | --- |
| **반전** | 오른쪽에서 왼쪽으로 그라디언트 방향을 반전합니다. |
| **혼합 모드** | 현재 레이어에 사용할 [혼합 모드](../../../interface/layer-stack/blending-modes.md)를 선택합니다. |

#### 월드 공간 일반/위쪽에서 아래쪽

| 매개 변수 이름 | 설명 |
| --- | --- |
| **반전** | 위쪽에서 아래쪽으로 그레이디언트 방향을 반전합니다. |
| **혼합 모드** | 현재 레이어에 사용할 [혼합 모드](../../../interface/layer-stack/blending-modes.md)를 선택합니다. |

#### 월드 스페이스 표준/앞쪽에서 뒤쪽

| 매개 변수 이름 | 설명 |
| --- | --- |
| **반전** | [앞에서 뒤로] 그레이디언트 방향을 반전시킵니다. |
| **혼합 모드** | 현재 레이어에 사용할 [혼합 모드](../../../interface/layer-stack/blending-modes.md)를 선택합니다. |
