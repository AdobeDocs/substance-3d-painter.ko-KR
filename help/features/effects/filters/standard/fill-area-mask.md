## 설명

영역 마스크 채우기 필터는 윤곽선을 채워진 모양으로 변환합니다. 테두리가 연속되는 모든 영역이 채워집니다.

이 레이어는 닫힌 페인트 선을 채우기 위해 레이어 페인팅을 추가한 후 마스크(흑백 출력) 레이어에 사용됩니다.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>영역 검색:</b> | 채울 영역을 식별하는 방법을 선택합니다. |
| <b>영역 검색 임계값:</b> | 영역 감지 임계값을 조정합니다. |
| <b>디버그 영역 검색:</b> | [영역 감지] 설정에서 감지한 윤곽선의 표시를 토글합니다. 이는 완전히 닫히지 않을 수 있는 영역을 식별하는 데 도움이 될 수 있습니다. |
| <b>UV 테두리 동작:</b> | 영역 채우기 중에 UV 테두리가 처리되는 방식을 선택합니다. |
| <b>UV 테두리 검색 임계값:</b> | 그렇지 않으면 영역 감지 프로세스로 채워질 수 있는 UV 영역을 무시하는 데 사용되는 임계값을 조정합니다. |
