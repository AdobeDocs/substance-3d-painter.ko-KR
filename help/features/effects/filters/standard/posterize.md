## 설명

[포스터화] 필터는 이미지에서 색상이나 톤 수를 줄여 더 뚜렷한 영역과 가장자리를 가진 계단식 모양을 만듭니다.

텍스처 레이어나 마스크(색상 또는 회색 음영)에서 색상을 단순화하여 스타일화된 그래픽 모양을 만드는 데 사용됩니다. 이는 포스터, 일러스트레이션 또는 세부 사항의 예술적 효과를 줄이는 데 종종 유용합니다.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>색상 양:</b> | 색상 단계 수를 조정합니다. |
| <b>Alpha에 적용:</b> | 알파 채널도 이 필터의 영향을 받는지 여부를 전환합니다. |
