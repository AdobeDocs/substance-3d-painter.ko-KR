# 흐림 경사

<table>
  <tr style="border: 0;">
    <td style="border: 0;" valign="top"><img src="./Resources/icon_blur_slope.png" alt="흐림 효과 경사 아이콘" title="흐림 경사"/><br><strong>인:</strong> 효과/흐림 효과, 회색 음영</td>
    <td style="border: 0;" valign="top">설명<br>경사 흐림 효과 필터는 번짐 또는 페이드 효과를 만듭니다. 특히 색상 간 고대비 가장자리에서 두드러집니다.<br>전체 재질 또는 특정 텍스처를 흐리게 하기 위해 텍스처 레이어에서 직접 사용하거나 마스크를 문지르기 위해 마스크에서 사용합니다. 이 효과를 사용하면 가장자리가 치패되거나 풍화되거나 Dirt이 누출되거나 녹이 얼룩지는 등의 효과를 만들 수 있습니다.</td>
  </tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| **사용자 지정 노이즈:** 회색 음영 | 사용자 정의 텍스처 또는 고정점을 사용자 정의 노이즈로 사용합니다. |

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| **시드:** | 전체 설정을 변경하지 않고 다른 변형을 만들려면 임의의 값을 할당합니다. |
| **강도:** | 흐림 강도 조정 |
| **강도 구분선:** | 흐림 효과 강도를 나누는 방법을 선택합니다. |
| **혼합 모드:** | 경사 흐림 효과에 사용되는 혼합 모드를 선택합니다. |
| **품질:** | 효과의 품질을 조정합니다. |

### 소스 매개 변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| **원본 유형:** | 소스에서 기본 노이즈, 이전 입력 또는 사용자 정의 노이즈를 사용할지 여부를 선택합니다. |
| **흐림 효과:** | 소스 노이즈 또는 입력의 흐림 강도를 조정합니다. |
| **위치:** | 명도 컨트롤과 비슷하게 소스 노이즈 또는 입력의 중간점을 조정합니다. |
| **대비:** | 소스 노이즈 또는 입력의 대비를 조정합니다. |
| **원본 틸링:** | 소스 노이즈 또는 입력의 타일링을 조정합니다. |
