<tr style="border: 0;">

## 설명

[경사 흐림 효과] 필터는 특히 색상 간 고대비 가장자리에서 두드러지는 스미어링 또는 페이딩 효과를 만듭니다.

전체 재질이나 특정 텍스처에 흐림 효과를 적용하려면 텍스처 레이어에서 직접 사용하고 마스크에 문지르려면 마스크에서 사용합니다. 이 효과를 사용하면 가장자리가 치패되거나 풍화되거나 Dirt이 누출되거나 녹이 얼룩지는 등의 효과를 만들 수 있습니다.

</td>
</tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| <b>사용자 지정 노이즈:</b> 회색 음영 | 사용자 정의 텍스처 또는 고정점을 사용자 정의 노이즈로 사용합니다. |

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>시드:</b> | 전체 설정을 변경하지 않고 다른 변형을 만들려면 임의의 값을 할당합니다. |
| <b>강도:</b> | 흐림 강도 조정 |
| <b>강도 구분선:</b> | 흐림 효과 강도를 나누는 방법을 선택합니다. |
| <b>혼합 모드:</b> | 경사 흐림 효과에 사용되는 혼합 모드를 선택합니다. |
| <b>품질:</b> | 효과의 품질을 조정합니다. |

### 소스 매개 변수

<table>
<tr>
<td><b>소스 유형:</b></td>

<tr>

</tr>
<tr>
<td><b>대비:</b></td>

</tr>

<td><b>소스 틸링:</b></td>
