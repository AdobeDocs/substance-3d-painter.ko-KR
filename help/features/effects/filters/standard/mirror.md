</td>

## 설명

거울 필터는 입력의 일부를 복사하는 대칭 필터입니다.

미러링 축 레이어(색상) 또는 마스크에 사용되어 텍스처 기반의 전체 재질, 마스크, 모양 등을 미러링합니다.

</td>
</tr>
</table>

>[!NOTE]
>
> 거울 필터는 UV 공간에서 작동하므로 **뷰포트**&#x200B;에서 2D 보기를 여는 것이 유용할 수 있습니다.

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>표시 디버그:</b> | 디버그 보기 표시를 토글합니다. |
| <b>모드:</b> | 미러 모드를 선택합니다. |
| <b>축 X 오프셋:</b> | X축 오프셋을 조정합니다. |
| <b>축 Y 오프셋:</b> | Y축 오프셋을 조정합니다. |
| <b>축 X 반전:</b> | X축에서 반전을 토글합니다. |
| <b>축 반전 Y:</b> | Y축에서 반전을 토글합니다. |
| <b>모퉁이 유형:</b> | 대칭복사된 모서리를 처리하는 방법을 선택합니다. |
