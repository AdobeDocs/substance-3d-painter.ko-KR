## 설명

[하이패스] 필터는 이름이 같은 Photoshop 액션과 마찬가지로 하이패스 효과를 수행합니다. 타일링을 위해 텍스처를 클리닝하는 경우와 같이 이미지에서 큰 광도 차이를 제거하는 데 유용합니다.

이 효과는 텍스처 레이어나 마스크 레이어에서 광도 차이를 제거하는 데 사용됩니다.

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>색상 공간:</b> | 필터에서 사용하는 색상 공간을 선택합니다. |
| <b>반경:</b> | 하이패스 반경을 조정합니다. |
| <b>Alpha에 적용:</b> | 필터가 알파 채널에 영향을 주는지 여부를 전환합니다. |
