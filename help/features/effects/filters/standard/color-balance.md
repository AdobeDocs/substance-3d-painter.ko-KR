# 색상 균형

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![색상 균형 아이콘](./Resources/icon_color_balance.png "색상 균형")

<b>인:</b> 효과/색상

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 설명

[색상 균형] 필터를 사용하면 밝은 영역, 중간 영역 및 어두운 영역이 미세하게 변경됩니다.

이 효과는 채우기 레이어에서 미세하게 색상을 조정하는 데 사용됩니다.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

### 밝은 영역

<table>
<tr>
<td><b>녹청 &lt;-&gt; 빨강:</b></td>
<td>색상을 청록색이나 빨강 쪽으로 이동합니다.</td>
</tr>
<tr>
<td><b>마젠타 &lt;-&gt; 녹색:</b></td>
<td>색상을 자홍색이나 초록색 쪽으로 이동합니다.</td>
</tr>
<tr>
<td><b>노란색 &lt;-&gt; 파란색:</b></td>
<td>색상을 노랑 또는 파랑 방향으로 이동합니다.</td>
</tr>
</table>
