## 설명

[색상 균형] 필터를 사용하면 밝은 영역, 중간 영역 및 어두운 영역이 미세하게 변경됩니다.

이 효과는 채우기 레이어에서 미세하게 색상을 조정하는 데 사용됩니다.

</td>
</tr>

## 매개변수

### 밝은 영역

| 매개 변수 이름 | 설명 |
| --- | --- |
| **녹청 &lt;-> 빨강:** | 색상을 청록색이나 빨강 쪽으로 이동합니다. |
| **마젠타 &lt;-> 녹색:** | 색상을 자홍색이나 초록색 쪽으로 이동합니다. |
| **노랑 &lt;-> 파랑:** | 색상을 노랑 또는 파랑 방향으로 이동합니다. |
