# 회색 음영 전환

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>인:</b> 효과/색상, 채도 감소, 최소, 최대

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 설명

회색 음영 전환 필터는 각 색상 채널의 휘도를 측정하여 채널/색상 이미지를 회색 음영으로 변환합니다. 변환을 조정할 수 있는 많은 옵션이 있습니다.

이 효과는 텍스처 레이어나 마스크 레이어에서 채널을 회색 음영으로 변환하거나 색상 이미지를 회색 음영으로 변환하여 마스크로 사용하는 데 사용됩니다.

</td>
</tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| <b>사용자 지정 입력:</b> 색상 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>채널 입력:</b> | 변환에 사용할 채널 입력을 선택합니다. |
| <b>반전:</b> | 결과의 반전을 토글합니다. |
| <b>균형:</b> | 명도 조정과 유사하게 검정과 흰색 사이의 결과 균형을 조정합니다. |
| <b>대비:</b> | 결과의 대비/밝기 감소를 조정합니다. |
| <b>모드:</b> | 회색 음영 변환 모드를 선택합니다. |
| <b>빨강:</b> | 빨강 채널에 대한 가중치를 조정합니다. 이 가중치는 회색 음영 결과를 계산하는 데 사용됩니다. |
| <b>녹색:</b> | 녹색 채널에 대한 가중치를 조정합니다. 이 가중치는 회색 음영 결과를 계산하는 데 사용됩니다. |
| <b>파랑:</b> | 파랑 채널의 가중치를 조정합니다. 이 가중치는 회색 음영 결과를 계산하는 데 사용됩니다. |
| <b>Alpha:</b> | 알파 채널에 대한 가중치를 조정합니다. 이 가중치는 회색 음영 결과를 계산하는 데 사용됩니다. |
