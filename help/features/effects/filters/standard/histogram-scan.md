## 설명

[막대 그래프 스캔] 필터는 입력 회색 음영 이미지의 대비와 명도를 다시 매핑합니다.

이 효과는 칠 레이어나 마스크(흑백 출력)에서 직접 사용하여 대비와 명도를 조정합니다.

</td>
</tr>

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>위치:</b> | 막대 그래프 위치를 조정합니다. |
| <b>대비:</b> | 결과의 대비/밝기 감소를 조정합니다. |
| <b>위치 반전:</b> | 위치 반전 전환 [위치] 값이 매우 높거나 매우 낮으면 출력이 효과적으로 반전됩니다. |
