## 설명

[픽셀화] 필터는 입력을 큰 블록으로 변환하여 픽셀화된 모양을 시뮬레이션합니다.

전체 재질, 노이즈, 마스크, 모양 등을 픽셀화하기 위해 텍스처 레이어(색상) 또는 마스크에 사용됩니다.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>픽셀 양:</b> | 픽셀 크기 변경의 부작용이 있는 픽셀 수를 조정합니다. 픽셀이 많을수록 더 작은 픽셀이 됩니다. |
| <b>Alpha에 적용:</b> | 필터가 알파 채널도 수정하는지 여부를 전환합니다. |
