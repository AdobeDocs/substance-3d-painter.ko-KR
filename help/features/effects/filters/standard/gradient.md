# 그래디언트

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![그레이디언트 아이콘](./Resources/icon_gradient.png "그레이디언트")

<b>인:</b> 효과/회색 음영

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 설명

[그레이디언트] 필터는 사용자 정의 그레이디언트를 사용하여 이미지의 회색 음영 값을 다시 매핑합니다.

회색 음영 이미지 값을 조정하거나 사용자 정의 그레이디언트에 매핑하여 회색 음영 입력을 색상화하는 데 사용할 수 있습니다.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>표시 그라디언트(디버그):</b> | 그레이디언트 디버그 보기 표시를 토글합니다. |
| <b>색상 수량:</b> | 그레이디언트에 사용되는 색상 수를 조정합니다. |
| <b>선형의 혼합 색상:</b> | 선형 색상 혼합을 전환합니다. |
| <b>색상 1:</b> | 첫 번째 색상을 선택합니다. |
| <b>색 1 위치:</b> | 첫 번째 색상의 위치를 조정합니다. |
| <b>색상 2:</b> | 두번째 색상을 선택합니다. |
| <b>색상 2 위치:</b> | 두 번째 색상의 위치를 조정합니다. |
| <b>색상 N:</b> | N번째 색상을 선택합니다. |
| <b>색 N 위치:</b> | N번째 색상의 위치를 조정합니다. |

### 입력 변환

<table>
<tr>
<td><b>회색 음영 모드:</b></td>
<td>회색 음영 변형 모드를 선택합니다. 채도 감소, 루마, 평균, 최대 및 최소 중에서 선택할 수 있습니다.</td>
</tr>
<tr>
<td><b>흐림 효과 강도:</b></td>
<td>입력 내용이 흐려지는 정도를 조정합니다.</td>
</tr>
<tr>
<td><b>균형:</b></td>
<td>명도 컨트롤과 비슷하게 중간점을 검정 또는 흰색으로 이동하여 입력의 균형을 조정합니다.</td>
</tr>
<tr>
<td><b>대비:</b></td>
<td>입력 대비를 조정합니다.</td>
</tr>
<tr>
<td><b>반전:</b></td>
<td>입력 색상의 반전을 토글합니다.</td>
</tr>
</table>
