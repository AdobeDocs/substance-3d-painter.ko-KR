## 설명

색상 교정 필터를 사용하면 밝은 영역, 중간 영역, 어두운 영역의 변경 사항을 조정할 수 있습니다.

이 효과는 채우기 레이어에서 미세한 대비, 광도 및 채도를 조정하는 데 사용됩니다.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

### 그림자

| 매개 변수 이름 | 설명 |
| --- | --- |
| **대비:** | 어두운 영역의 대비를 조정합니다. |
| **광도:** | 그림자의 밝기를 조정합니다. |
| **채도:** | 그림자의 채도를 조정합니다. |

### 중간 톤

| 매개 변수 이름 | 설명 |
| --- | --- |
| **대비:** | 중간 톤의 대비를 조정합니다. |
| **광도:** | 중간 영역의 명도를 조정합니다. |
| **채도:** | 중간 영역의 채도를 조정합니다. |

### 밝은 영역

| 매개 변수 이름 | 설명 |
| --- | --- |
| **대비:** | 밝은 영역의 대비를 조정합니다. |
| **광도:** | 밝은 영역의 명도를 조정합니다. |
| **채도:** | 밝은 영역의 채도를 조정합니다. |
