# 색상 보정

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![색 보정 아이콘](./Resources/icon_color_correct.png "색 보정")

<b>인:</b> 효과/색상

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 설명

색상 교정 필터를 사용하면 밝은 영역, 중간 영역, 어두운 영역의 변경 사항을 조정할 수 있습니다.

이 효과는 채우기 레이어에서 미세한 대비, 광도 및 채도를 조정하는 데 사용됩니다.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

### 그림자

<table>
<tr>
<td><b>대비:</b></td>
<td>어두운 영역의 대비를 조정합니다.</td>
</tr>
<tr>
<td><b>광도:</b></td>
<td>그림자의 밝기를 조정합니다.</td>
</tr>
<tr>
<td><b>채도:</b></td>
<td>그림자의 채도를 조정합니다.</td>
</tr>
</table>

### 중간 톤

<table>
<tr>
<td><b>대비:</b></td>
<td>중간 톤의 대비를 조정합니다.</td>
</tr>
<tr>
<td><b>광도:</b></td>
<td>중간 영역의 명도를 조정합니다.</td>
</tr>
<tr>
<td><b>채도:</b></td>
<td>중간 영역의 채도를 조정합니다.</td>
</tr>
</table>

### 밝은 영역

<table>
<tr>
<td><b>대비:</b></td>
<td>밝은 영역의 대비를 조정합니다.</td>
</tr>
<tr>
<td><b>광도:</b></td>
<td>밝은 영역의 명도를 조정합니다.</td>
</tr>
<tr>
<td><b>채도:</b></td>
<td>밝은 영역의 채도를 조정합니다.</td>
</tr>
</table>
