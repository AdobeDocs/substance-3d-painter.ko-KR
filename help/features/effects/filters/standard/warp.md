## 설명

뒤틀기 필터는 다양한 변형 효과에 사용됩니다. 뒤틀기 필터는 일반 뒤틀기, 특정 방향으로 뒤틀리는 방향 뒤틀기 및 다양한 변형을 위한 다방향 뒤틀기에 대한 액세스를 제공합니다.

뒤틀기는 텍스처 레이어나 마스크 내부(흑백 출력)에 사용되어 재질, 모양, 마스크, 윤곽선 등을 변형합니다.

</td>
</tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| <b>사용자 지정 노이즈</b> | 사용자 정의 텍스처를 노이즈 입력 맵으로 사용합니다. |

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>시드:</b> | 전체 설정을 변경하지 않고 다른 변형을 만들려면 임의의 값을 할당합니다. |
| <b>뒤틀기 모드:</b> | 뒤틀기 모드를 선택합니다. |
| <b>강도:</b> | 뒤틀기 강도를 조정합니다. |
| <b>강도 구분선:</b> | 뒤틀기 강도의 나누기 방법을 선택합니다. |
| <b>각도:</b> | 뒤틀기 각도를 조정합니다. |
| <b>혼합 모드:</b> | 뒤틀기에 사용되는 혼합 모드를 선택합니다. |
| <b>방향:</b> | 뒤틀기 방향 수를 선택합니다. |

### 소스 매개 변수

<table>
<tr>
<td><b>소스 모드:</b></td>
<td>소스 모드를 결정합니다.<br><br> - 기본 노이즈: 뒤틀기 효과에 기본 노이즈를 사용합니다.<br> - 이전 입력: 뒤틀기 효과에 이전 입력을 사용합니다. 채우기 레이어에 특정 노이즈 패턴이 적용된 경우 [이전 입력] 모드에서 뒤틀기 효과를 사용하면 효과에서 채우기 레이어와 동일한 노이즈 패턴을 사용합니다.<br> - 사용자 정의 노이즈: 뒤틀기 효과에 사용자 정의 노이즈 입력을 사용합니다.</td>
