## 설명

[광선] 필터는 입력의 표시 부분 주위에 외부 광선을 만듭니다.

텍스처 레이어나 마스크 내부(흑백 출력)에 사용하여 모양과 재질 주위에 부드럽거나 정확한 광선을 추가합니다.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>마스크에 사용됨:</b> | 마스크에서 광선을 사용할지 여부를 전환합니다. |
| <b>모드:</b> | 광선에서 [약하게] 또는 [정밀하게] 모드를 사용할지 여부를 선택합니다. |
| <b>너비:</b> | 광선의 폭을 조정합니다. |
| <b>스프레드:</b> | 광선의 퍼짐을 조정합니다. |
| <b>불투명도:</b> | 광선의 불투명도를 조정합니다. |
| <b>색상:</b> | 광선 색상을 조정합니다. |
