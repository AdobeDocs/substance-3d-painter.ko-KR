# 영역 색상 채우기

## 설명

[채우기 영역 색상] 필터는 윤곽선을 채우기 모양으로 변환합니다. 테두리가 연속되는 모든 영역이 채워집니다. 색상 버전에서는 영역 테두리를 결정하는 데 알파를 사용합니다.

이 효과는 레이어 페인팅(색상 채널)에서 닫힌 페인트 선을 채우는 데 사용됩니다.

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>영역 검색:</b> | 채울 영역을 식별하는 방법을 선택합니다. |
| <b>영역 검색 임계값:</b> | 영역 감지 임계값을 조정합니다. |
| <b>디버그 영역 검색:</b> | [영역 감지] 설정에서 감지한 윤곽선의 표시를 토글합니다. 이는 완전히 닫히지 않을 수 있는 영역을 식별하는 데 도움이 될 수 있습니다. |
| <b>UV 테두리 동작:</b> | 영역 채우기 중에 UV 테두리가 처리되는 방식을 선택합니다. |
| <b>UV 테두리 임계값:</b> | 그렇지 않으면 영역 감지 프로세스로 채워질 수 있는 UV 영역을 무시하는 데 사용되는 임계값을 조정합니다. |
| <b>색상 모드:</b> | 영역 내부를 채우는 데 사용할 방법을 선택합니다. |
| <b>칠 색상:</b> | 채우기 색상을 조정합니다. |
| <b>흐림 강도:</b> | 흐림 강도 조정 |
| <b>흐림 효과 샘플:</b> | 흐림 효과 샘플 수를 조정합니다. |
| <b>확산 반복:</b> | 수행할 확산 반복 수를 조정합니다. 값이 높을수록 결과는 향상되지만 속도는 느려집니다. 유용한 값은 [8, 48] 범위에 있습니다. |
