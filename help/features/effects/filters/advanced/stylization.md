## 설명

[스타일화] 필터는 재질에 손으로 그린 스타일 효과를 적용합니다.

이 효과는 텍스처 레이어에서 브러시로 칠한 획, Smoothness 변형, 색상 다시 매핑 및 구운 조명 효과를 추가하는 데 사용됩니다.

</td>
</tr>
</table>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>스타일화:</b> | 필터의 전체 강도를 조정합니다. |
| <b>브러시 선:</b> | 브러시 획 효과의 전체 강도를 조정합니다. |
| <b>Smoothness:</b> | Smoothness 효과의 전체 강도를 조정합니다. |
| <b>색상화:</b> | 색상화 효과의 전체 강도를 조정합니다. |
| <b>그레이디언트:</b> | 그레이디언트 효과의 전체 강도를 조정합니다. |
| <b>빛바랜 효과:</b> | 구운 조명 효과의 전체 강도를 조정합니다. |
| <b>가장자리 및 공동:</b> | 가장자리와 캐비티 효과의 전체 강도를 조정합니다. |

### 브러시 스트로크

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>스트로크 양:</b> | 필터에 사용되는 브러시 획의 양을 조정합니다. |
| <b>선 모드:</b> | 필터에 사용된 브러시 획의 유형을 선택합니다. |
| <b>선 선택:</b> | 여러 개의 선을 사용할 때 투영할 브러시 선 모양을 선택합니다. |
| <b>선 선택:</b> | 단일 획을 사용할 때 투영할 브러시 획 모양을 선택합니다. |
| <b>선 크기 조절:</b> | 브러시 획의 비율을 조정합니다. |
| <b>균일하지 않은 크기:</b> | 투영된 브러시 획의 비균일 크기 조절을 토글합니다. |
| <b>선 크기:</b> | 투영된 브러시 획의 종횡비를 조정합니다. |
| <b>선 비율 무작위:</b> | 브러시 획에 적용되는 무작위 크기 조절 변동의 양을 조정합니다. |
| <b>획이 표면을 따름:</b> | 브러쉬 선을 망 방향으로 맞춥니다. |
| <b>선 회전:</b> | 브러시 획의 회전 각도를 조정합니다. |
| <b>선 회전 무작위:</b> | 브러시 획에 적용되는 임의 회전의 양을 조정합니다. |
| <b>투영 경도:</b> | 스탬프 투영의 경도를 조정합니다. |
| <b>정상 임계값:</b> | 획 투영에 사용되는 일반 임계값을 조정합니다. |

### 브러쉬 모양 선 효과

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>색상 사용자 지정:</b> | 브러시 획에서 사용자 정의 색상 사용을 전환합니다. |
| <b>색상 변형:</b> | 브러시 획이 기본 색상과 혼합되는 정도를 조정합니다. |
| <b>색상 불투명도:</b> | 브러시 획에 적용된 사용자 정의 색상의 불투명도를 조정합니다. |
| <b>색상:</b> | 브러시 획에 적용된 사용자 정의 색상을 조정합니다. |
| <b>색상 무작위:</b> | 브러시 획에 적용되는 임의의 색상 변화 양을 조정합니다. |
| <b>거칠음 사용자 지정:</b> | 브러시 획에서 사용자 정의 거칠기 값 사용을 전환합니다. |
| <b>거칠음 변형:</b> | 브러시 획의 거칠기 변형을 조정합니다. |
| <b>거칠음:</b> | 브러시 획의 거칠기 값을 조정합니다. |
| <b>금속 사용자 지정:</b> | 브러시 획에서 사용자 정의 금속성 값 사용을 전환합니다. |
| <b>금속 변형:</b> | 브러시 획의 금속 변화를 조정합니다. |
| <b>금속:</b> | 브러쉬 획의 금속 값을 조정합니다. |
| <b>일반 사용자 지정:</b> | 브러시 획에 대한 추가 표준 매핑 옵션을 전환합니다. |
| <b>표준 변형:</b> | 표준 채널에서 브러시 선의 강도를 조정합니다. |
| <b>보통 무작위:</b> | 브러시 획에 적용되는 임의의 표준 변형 양을 조정합니다. |
| <b>혼합 모드(표준):</b> | 브러쉬 선에 사용되는 표준 혼합 모드를 선택합니다. |

### 매끄러움

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>색상 Smoothness:</b> | 기본 색상에 적용된 구와하라 매끄럽게 효과를 조정합니다. |
| <b>거칠음 Smoothness:</b> | [거칠음]에 적용된 [구와하라] 매끄럽게 효과를 조정합니다. |
| <b>금속 Smoothness:</b> | 금속에 적용된 [구와하라] 매끄럽게 효과를 조정합니다. |
| <b>Height Smoothness:</b> | Height에 적용된 구와하라 매끄럽게 효과를 조정합니다. |
| <b>일반 Smoothness:</b> | [표준]에 적용된 [구와하라] 매끄럽게 효과를 조정합니다. |
| <b>앰비언트 오클루전 Smoothness:</b> | 앰비언트 오클루전에 적용된 구와하라 매끄럽게 효과를 조정합니다. |

| <b>그레이디언트 대비:</b> | 그레이디언트 마스크의 대비를 조정합니다. |

### 가장자리 및 공동

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>모드:</b> | 기본 색상에서 캐비티를 매핑할지, 가장자리를 매핑할지 아니면 둘 다 매핑할지 선택합니다. |
| <b>가장자리 및 캐비티 대비:</b> | 가장자리 및 캐비티 마스크의 대비를 조정합니다. |

| <b>사용자 지정 캐비티 색:</b> | 캐비티에서 사용자 정의 색상 사용을 전환합니다. |
| <b>공동 색상:</b> | 캐비티에 혼합되는 사용자 정의 색상을 조정합니다. |
| <b>가장자리 불투명도:</b> | 기본 색상으로 혼합된 가장자리의 강도를 조정합니다. |
| <b>가장자리 스프레드:</b> | 기본 색상으로 혼합된 가장자리의 스프레드를 조정합니다. |
| <b>가장자리의 브러시 획:</b> | 브러시 획으로 가장자리 혼합을 마스킹하는 양을 조정합니다. |
| <b>사용자 지정 가장자리 색:</b> | 가장자리에서 사용자 정의 색상 사용을 전환합니다. |
