## 설명

마스크 윤곽선 필터는 마스크 가장자리에서 윤곽선을 만듭니다.

텍스처 레이어나 마스크 내부(흑백 출력)에서 마스크된 모양 주위에 안쪽, 바깥쪽 또는 이중 윤곽선을 생성하는 데 사용됩니다.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>마스크 위치:</b> | 윤곽선이 마스크 가장자리의 바깥쪽, 안쪽 또는 양쪽에 나타나는지 여부를 선택합니다. |
| <b>검정에서 시작:</b> | 윤곽선이 검정에서 시작되는지 여부를 전환합니다. 이는 일종의 반전 토글(inversion toggle)로서 효과적으로 작용한다. |
| <b>임계값:</b> | 마스크 가장자리를 감지하는 데 사용되는 임계값을 조정합니다. |
| <b>너비:</b> | 윤곽선의 폭을 조정합니다. |
| <b>흐림 효과:</b> | 윤곽선에 적용된 흐림 효과를 조정합니다. |
| <b>곡선 모양:</b> | 윤곽선 밝기 감소 모양을 조정합니다. |
