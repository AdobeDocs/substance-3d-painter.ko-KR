# 베벨 매끄럽게

<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 설명

[베벨 매끄럽게] 필터는 마스크 테두리에서 바깥쪽이나 안쪽 또는 양쪽 모두로 그레이디언트를 그립니다.

이 레이어는 텍스처 레이어나 마스크 내부(흑백 출력)에서 마스크 가장자리로부터 부드러운 경사 그레이디언트를 만드는 데 사용됩니다.

</td>
</tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| <b>거리 맵:</b> 회색 음영 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>방향:</b> | 확장할 마스크 테두리의 면을 선택합니다. |
| <b>거리:</b> | 경사 확장 거리를 조정합니다. |
| <b>보정:</b> | 마스크에 적용된 매끄러움 강도를 조정합니다. |
| <b>곡선 오프셋:</b> | 마스크 테두리를 안쪽 또는 바깥쪽으로 조정합니다. |
| <b>곡선 모양:</b> | 경사 경사에서 압착 또는 둥근 곡선을 사용할지 여부를 선택합니다. |
| <b>마스크 임계값:</b> | 입력에서 마스크의 테두리를 감지하는 데 사용되는 값을 조정합니다. |
| <b>거리 맵 승수:</b> | 최대 거리에 대한 거리 맵의 영향을 조정합니다. |
| <b>경사 줄 바꿈:</b> | 경사 타일이 가로 및 세로로 설정되는지 여부를 전환합니다. |
