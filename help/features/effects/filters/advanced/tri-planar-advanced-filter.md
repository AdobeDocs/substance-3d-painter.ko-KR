# 3회 평면 고급

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![세 개의 평면 고급 아이콘](./Resources/icon_tri_planar_advanced_filter.png "세 개의 평면 고급")

<b>인:</b> 효과/투영

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 설명

Tri-free Advanced 필터는 Tri-평면 Advanced 생성기의 필터 버전으로서, 전체 투영을 위한 수동 제어를 제공합니다. 이렇게 하면 각 축의 회전 및 오프셋 값을 제어할 수 있습니다. 이 필터는 생성기와 달리 레이어 콘텐츠에서 직접 작동하며, 생성기에서는 혼합을 위해 사용자 정의 마스크 입력이 필요합니다.

텍스처 레이어나 마스크 내부에서 3평면 혼합을 추가하는 데 사용됩니다.

</td>
</tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| <b>월드 스페이스 표준:</b> | 구워진 World Space Normal 지도를 사용합니다. |
| <b>위치:</b> | 구워진 위치 맵을 사용합니다. |

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>투영:</b> | 투영할 축을 선택합니다. |
| <b>혼합 모드:</b> | 축 투영이 서로 혼합되는 방식을 선택합니다. |
| <b>혼합 대비:</b> | 투영 혼합의 대비를 조정합니다. |
| <b>텍스처 타일링:</b> | 투영된 텍스처의 타일링을 조정합니다. |
| <b>회전 X:</b> | X축 투영의 회전을 조정합니다. |
| <b>오프셋 X:</b> | X축 투영의 오프셋을 조정합니다. |
| <b>회전 Y:</b> | Y축 투영의 회전을 조정합니다. |
| <b>오프셋 Y:</b> | Y축 투영의 오프셋을 조정합니다. |
| <b>회전 Z:</b> | Z축 투영의 회전을 조정합니다. |
| <b>오프셋 Z:</b> | Z축 투영의 오프셋을 조정합니다. |

### 축 X

<table>
<tr>
<td><b>회전 X:</b></td>
<td>X축 텍스처 투영의 회전을 조정합니다.</td>
</tr>
<tr>
<td><b>오프셋 X X</b></td>
<td>X축을 따라 X축 투영 오프셋을 조정합니다.</td>
</tr>
<tr>
<td><b>오프셋 X Y:</b></td>
<td>Y축을 따라 X축 투영 오프셋을 조정합니다.</td>
</tr>
</table>

>[!NOTE]
>
> 오프셋 매개변수의 제목에 두 축이 포함됩니다. 첫 번째 유형은 투영 축을 정의하고 두 번째 유형은 오프셋 축을 정의합니다. 따라서 **오프셋 X Y**&#x200B;은 특히 X축의 투영을 보고 투영을 로컬 Y축을 따라 오프셋합니다.
>
>**오프셋 X X**&#x200B;은(는) X 투영을 **수평**&#x200B;으로 오프셋하고 **오프셋 X Y**&#x200B;는 X 투영을 **수직**&#x200B;으로 오프셋합니다.
