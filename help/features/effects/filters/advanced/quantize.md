## 설명

[정량화] 필터는 이미지를 제한된 색상 세트로 축소합니다.

이 효과는 텍스처 레이어에서 더 밋밋하거나 포스터화되거나 스타일화된 색상 영역을 만드는 데 사용됩니다.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>색상 양:</b> | 양자화된 이미지에 사용된 최대 색상 수를 조정합니다. 이 값은 또한 추출된 팔레트를 구동하지만, 실제 카운트는 양자화 방법에 따라 더 낮을 수 있다. 추출된 최종 색상 수에 대해 팔레트 색상 양 출력을 확인합니다. |
| <b>윤곽선 매끄럽게 하기:</b> | 입력 이미지에 적용된 매끄러움 반경을 조정하여 양자화된 결과를 보다 견고하고 응집력 있는 형태로 단순화합니다. 값이 높을수록 계산 시간이 눈에 띄게 늘어납니다. |
| <b>디더링:</b> | 양자화 후 남은 색상만 사용하면서 그레이디언트와 색상 혼합을 다시 만드는 데 사용되는 디더링의 양을 조정합니다. 필요한 디더링 효과에 [윤곽선 매끄럽게 하기] 값 0을 사용합니다. |
| <b>디더링 패턴:</b> | 원본 이미지에서 그레이디언트와 색상 혼합을 다시 만드는 데 사용되는 디더링 패턴을 선택합니다. |
| <b>거리 색상 공간:</b> | 양자화하는 동안 색상을 비교하고 분배하는 데 사용되는 색상 공간을 선택합니다. 가시 범위 색상 이미지에는 Lab(색상)을, 노멀 맵 등의 Raw 데이터에는 RGB(데이터)를 사용합니다. |
| <b>Alpha에 적용:</b> | 레이어의 알파 채널 양자화를 전환합니다. |
| <b>Alpha 임계값:</b> | 알파 임계값을 조정합니다. |
