## 설명

[비등방성 구와하라] 필터는 강력한 방향성 기능을 유지하면서 회화적인 스타일화 효과를 만듭니다.

텍스처 레이어나 마스크 내부(흑백 출력)에 사용하여 전체 재질, 노이즈 및 마스크에 대해 스타일화된 모양을 만듭니다.

</td>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| <b>반경 맵:</b> 회색 음영 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |
| <b>사용자 지정 입력:</b> 색상 | 사용자 정의 텍스처 또는 고정점을 사용합니다. |

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>추출 방향:</b> | 필터가 흐림 방향을 어떻게 유도하는지 선택합니다. |
| <b>반경:</b> | 흐림 반경 조정 값이 높을수록 흐림 효과 강도가 높아집니다. 최대값은 32입니다. |
| <b>Smoothness:</b> | 계산된 방향을 따라 색상이 혼합되는 양을 조정합니다. 0에서는 색상이 거의 혼합되지 않은 상태로 대부분 해당 방향으로 변위됩니다. |
| <b>선명도:</b> | 흐린 영역의 대비를 조정하여 더 평평하고 선명하게 보이도록 합니다. |
| <b>텐서 Smoothness:</b> | 이미지에서 계산되어 방향 맵에 저장된 방향에 적용되는 흐림 효과의 양을 조정합니다. 이 값을 높게 지정하면 이미지에 빈도 수가 높은 세부 묘사가 많이 포함된 경우 결과가 더 매끄러워집니다. |
| <b>비등방성:</b> | 방향 맵이 흐림 효과에 얼마나 큰 영향을 주는지 조정합니다. 이 값이 0인 경우에도 방향 맵과 해당 한정자가 결과에 영향을 줍니다. Kuwahara 필터 커널에서 맵을 사용하기 때문입니다. |
| <b>비등방성 각도:</b> | 방향 맵에 적용된 회전을 차례로 조정합니다. 이 회전은 [비등방성 각도 맵] 입력 값에 추가됩니다. |
