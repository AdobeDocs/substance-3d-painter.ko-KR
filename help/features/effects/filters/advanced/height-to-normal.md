## 설명

Height 투 노멀 필터는 Height 채널을 기반으로 정확한 노멀 데이터를 생성한다.

텍스처 레이어에서 Height 정보를 일반 데이터로 변환하는 데 사용됩니다.

</td>
</tr>

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>기존 표준 덮어쓰기:</b> | 기존 일반 데이터 덮어쓰기를 전환합니다. |
| <b>세계 단위 사용:</b> | 변환에 월드 단위 사용을 전환합니다. |
| <b>표준 강도:</b> | **세계 단위 사용**&#x200B;이 **False**&#x200B;이면 이를 사용하여 생성된 일반 데이터의 강도를 조정합니다. |
| <b>표면 크기(cm):</b> | **세계 단위 사용**&#x200B;이 **참**&#x200B;이면 이를 사용하여 표시된 표면의 폭 또는 Height 중 더 큰 값을 조정합니다. |
| <b>Height 깊이(cm):</b> | **세계 단위 사용**&#x200B;이 **참**&#x200B;인 경우, 이를 사용하여 표면의 최대 Height 범위를 조정합니다. |
