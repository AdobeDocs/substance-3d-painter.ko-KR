## 설명

[그레이디언트 곡선] 필터는 사용자 정의 가능한 그레이디언트 곡선을 통해 값을 다시 매핑합니다.

이 효과는 텍스처 레이어나 마스크 내부(흑백 출력)에서 사용하여 회색 음영 값을 사전 설정된 곡선 모양으로 다시 매핑할 수 있습니다.

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>사전 설정:</b> | 곡선 사전 설정을 선택합니다. |
| <b>반전:</b> | 결과의 반전을 토글합니다. |
| <b>균형:</b> | 명도 조정과 유사하게 검정과 흰색 사이의 결과 균형을 조정합니다. |
| <b>대비:</b> | 결과의 대비 또는 감소를 조정합니다. |
