## 설명

MatFX 녹 풍화 필터는 재질 전반에 걸쳐 녹 축적과 풍화를 만듭니다.

그것은 부식, 드립과 노화된 풍화 효과를 추가하기 위해 텍스처 층 또는 재료 스택에 사용됩니다.

</td>
</tr>
</table>

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>흐림 강도:</b> | 흐림 효과 강도를 조정합니다. |
| <b>흐림 효과 줄 바꿈:</b> | 흐림 효과 감싸기를 설정하거나 해제합니다. 흐림 효과 감싸기가 켜져 있으면 텍스처 반대쪽에서 픽셀이 샘플링됩니다. |
| <b>녹 확산:</b> | 녹 분산을 조정합니다. |
| <b>확산 Smoothness:</b> | 분산 Smoothness 조정. |
| <b>광택제 손상 비율:</b> | 광택제 손상 비율을 조정합니다. |
| <b>드립 강도:</b> | 물방울 강도를 조정합니다. |
| <b>드립스 샘플 양:</b> | 샘플 양을 조정합니다. |
| <b>드립스 Smoothness:</b> | 물방울 Smoothness 조정. |

### 혼합

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>표준 강도:</b> | 노멀 맵 혼합 강도를 조정합니다. |
| <b>앰비언트 오클루전 강도:</b> | AO 맵 혼합 강도를 조정합니다. |
| <b>Height 강도:</b> | 높이 맵 혼합 강도를 조정합니다. |

**금속 거칠기**

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>기본 색상 강도:</b> | 기본 색상 강도를 조정합니다. |
| <b>거칠음 강도:</b> | 거칠기 맵 혼합 강도를 조정합니다. |
| <b>금속 강도:</b> | 금속지도 혼합 강도를 조정합니다. |
