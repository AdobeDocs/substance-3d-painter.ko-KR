## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>페인트 불투명도:</b> | 페인트 불투명도를 조정합니다. |
| <b>용지 흡수:</b> | 용지가 페인트를 얼마나 강하게 흡수하는지 조정합니다. |
| <b>누적 형식:</b> | 누적 방법을 선택합니다. |
| <b>테두리 스프레드:</b> | 페인트 테두리의 스프레드를 조정합니다. |
| <b>테두리 밀도:</b> | 페인트 테두리의 밀도를 조정합니다. |
| <b>페인트 가장자리 표시:</b> | 페인트 간 가장자리 표시를 토글합니다. |
| <b>용지 숨기기:</b> | 용지 텍스처의 가시성을 전환합니다. |
| <b>사용자 지정 용지:</b> | 사용자 정의 용지 텍스처 사용 전환 |
