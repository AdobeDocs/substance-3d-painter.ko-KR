## 설명

MatFX 필링 페인트 필터는 플레이킹 및 필링 페인트 효과를 만듭니다.

이는 박리 페인트, 벗겨진 코팅, 및 밑에 있는 재료 노출을 시뮬레이션하기 위해 텍스처 층 또는 재료 스택에 사용된다.

</td>
</tr>
</table>

>[!NOTE]
>
> 밑에 있는 재료를 노출하려면 그룹 내의 [MatFX Filing] 페인트를 사용합니다. 그룹 외부 및 레이어 스택 내의 그 아래의 층들은 박리된 페인트가 표면으로부터 멀리 당겨지는 위치에서 노출될 것이다.

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>흐림 강도:</b> | 흐림 효과 강도를 조정합니다. |
| <b>흐림 효과 줄 바꿈:</b> | 흐림 효과 감싸기를 전환합니다. 이 효과를 활성화하면 텍스처 반대쪽의 픽셀이 샘플링됩니다. |
| <b>박리 수준:</b> | 전체 필링 레벨을 조정합니다. |
| <b>박리 거리:</b> | 페인트가 얼마나 멀리 떨어져 보이는지 조정합니다. |
| <b>조각 수준:</b> | 깜박이는 양을 조정합니다. |
| <b>기포 밀도:</b> | 기포의 밀도를 조정합니다. |
| <b>플래그 지정 밀도:</b> | 플레이킹의 밀도를 조정합니다. |
| <b>플래그 지정 X 양:</b> | X축을 따라 플레이킹의 양을 조정합니다. |
| <b>Y 양 플래그 지정:</b> | Y축을 따라 플레이킹의 양을 조정합니다. |
| <b>곡률 사용:</b> | 곡률 입력 사용을 전환합니다. |
| <b>곡률 거리:</b> | 곡률 샘플링 거리를 조정합니다. |
| <b>곡률 대비:</b> | 곡률 입력의 대비를 조정합니다. |

### 기술 매개 변수

이러한 매개변수를 사용하면 박리된 재료의 상단 서피스를 수정할 수 있습니다.

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>광도:</b> | 광도를 조정합니다. |
| <b>대비:</b> | 결과의 대비 또는 감소를 조정합니다. |
| <b>색조 이동:</b> | 색조 이동을 조정합니다. |
| <b>채도:</b> | 채도를 조정합니다. |
| <b>표준 강도:</b> | 표준 강도를 조정합니다. |
| <b>Height 범위:</b> | 효과에 사용되는 Height 범위를 조정합니다. |
| <b>Height 위치:</b> | 효과에 사용되는 Height 위치를 조정합니다. |
| <b>앰비언트 오클루전 강도:</b> | 앰비언트 오클루전 강도를 조정합니다. |
