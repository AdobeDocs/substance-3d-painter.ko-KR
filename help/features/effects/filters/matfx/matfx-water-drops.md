## 설명

MatFX 물방울 필터는 소재에 물방울과 유출 효과를 만듭니다.

텍스처 레이어 또는 재질 스택에 사용되어 드롭릿, 방향성 스트리킹 및 습식 표면 변동을 추가합니다.

</td>
</tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| <b>앰비언트 오클루전:</b> 회색 음영 | 구운 앰비언트 오클루전 맵을 사용합니다. |
| <b>월드 스페이스 표준:</b> 색상 | 구워진 월드 스페이스 표준 맵을 사용합니다. |
| <b>위치:</b> 색상 | 구워진 위치 맵을 사용합니다. |

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>드롭 양:</b> | 물방울의 양을 조정합니다. |
| <b>비율 조정 X:</b> | 방울의 X 비율을 조정합니다. |
| <b>비율 조정 Y:</b> | 방울의 Y 비율을 조정합니다. |
| <b>무작위 비율 조정:</b> | 드롭에서 임의 비율 변동의 양을 조정합니다. |
| <b>방향 강도 낮추기:</b> | 물방울의 방향 강도를 조정합니다. |

### 위치

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>영향 X:</b> | 위치 입력의 X 영향을 조정합니다. |
| <b>영향 Y:</b> | 위치 입력의 Y 영향을 조정합니다. |
| <b>영향 Z:</b> | 위치 입력의 Z 영향을 조정합니다. |

### 물 축적

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>강도:</b> | 물이 쌓이는 강도를 조정합니다. |
| <b>스프레드:</b> | 물이 모이는 곳의 퍼짐을 조정하세요. |
| <b>AO 기반 강도:</b> | 앰비언트 오클루전이 수분 축적에 미치는 영향을 조정합니다. |

### 월드 공간

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>마스킹 강도:</b> | 월드 공간 마스크의 강도를 조정합니다. |
| <b>상위 강도:</b> | 위쪽을 향한 영역의 물방울 강도를 조정합니다. |
| <b>아래쪽 강도:</b> | 아래쪽을 향한 영역의 물방울 강도를 조정합니다. |
| <b>정면 강도:</b> | 앞면 영역의 물방울 강도를 조정합니다. |
| <b>뒤로 강도:</b> | 후면 영역 물방울의 강도를 조정합니다. |
| <b>오른쪽 강도:</b> | 오른쪽을 향한 영역의 물방울 강도를 조정합니다. |
| <b>왼쪽 강도:</b> | 왼쪽을 향하는 영역의 물방울 강도를 조정합니다. |

### 재질

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>기본 색상 뒤틀기 강도 낮추기:</b> | 물방울 아래의 기본 색상에 적용된 뒤틀기 강도를 조정합니다. |
| <b>회전 벡터 맵 승수를 삭제합니다.</b> | 드롭 회전 벡터 맵에 적용된 승수를 조정합니다. |
| <b>Height 강도를 낮춥니다.</b> | 드롭 Height 효과의 강도를 조정합니다. |
| <b>거칠음 감소:</b> | 물방울의 거칠기를 조정합니다. |
| <b>거칠음 혼합 삭제:</b> | 드롭 거칠기가 재질과 혼합되는 방식을 조정합니다. |
| <b>금속 물방울:</b> | 물방울의 금속 값을 조정합니다. |
| <b>금속 혼합 삭제:</b> | 드롭 금속성 값이 재료와 혼합되는 방식을 조정합니다. |
| <b>표준 강도:</b> | 표준 효과의 강도를 조정합니다. |
