>[!NOTE]
>
> MatFX 세부 정보 Edge Wear 필터가 눈에 보이는 효과를 내기 위해서는 필터 아래의 레이어 스택에 기존의 다양한 표준 정보가 있어야 합니다. 표준 채널에 데이터가 없거나 다양한 항목이 없는 경우 필터는 손상될 가장자리를 찾을 수 없으며 가시적인 효과가 없습니다.

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| **흐림 강도:** | 흐림 효과 강도를 조정합니다. |
| **흐림 효과 줄 바꿈:** | 흐림 효과 감싸기를 전환합니다. 이 효과를 활성화하면 텍스처 반대쪽의 픽셀이 샘플링됩니다. |
| **입력 모드:** | 마모 효과를 구동하는 데 사용할 입력 모드를 선택합니다. |
| **마모 수준:** | 전체 마모 수준을 조정합니다. |
| **마모 대비:** | 마모 마스크의 대비를 조정합니다. |
| **가장자리 Smoothness:** | 마모된 가장자리의 Smoothness을 조정합니다. |
| **그런지 양:** | 마모에 추가되는 그런지 양을 조정합니다. |
| **그런지 비율:** | 그런지 패턴의 비율을 조정합니다. |

|  |  |
