## 설명

MatFX 오일 페인트 필터는 오일 페인트 모양으로 소스 스타일을 적용합니다.

이 레이어는 텍스처 레이어에서 유화 페인트에서 영감을 받은 회화적인 획, 색상 변형 및 표면 세부 묘사를 만드는 데 사용됩니다.

| --- | --- |

<a name="parameters"></a>

## 매개변수

**사전 설정**&#x200B;을 사용할 수 있으며 필터의 다른 여러 매개 변수를 빠르게 업데이트하여 시작점으로 사용할 수 있습니다.

>[!NOTE]
>
> 사전 설정을 선택하면 모든 매개 변수가 사전 설정 값으로 설정됩니다. 손실되지 않도록 필터를 변경한 경우 사전 설정을 시도하기 전에 필터의 복제본을 만들고 가시성을 토글하는 것이 좋습니다.

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>입력 형식:</b> | 효과에 사용되는 입력 유형을 선택합니다. |
| <b>효과 강도:</b> | 효과의 전체 강도를 조정합니다. |
| <b>자세한 정보:</b> | 결과에 유지되는 미세한 세부 사항의 양을 조정합니다. |
| <b>선명도:</b> | 결과의 선명도를 조정합니다. |
| <b>거칠음:</b> | [거칠음] 값을 조정합니다. |
| <b>거칠음 변형:</b> | 결과의 거칠음 변형을 조정합니다. |
| <b>거칠음 세부 사항:</b> | 세부 사항이 거칠기에 미치는 영향의 정도를 조정합니다. |
| <b>표준 강도:</b> | 표준 효과의 강도를 조정합니다. |
| <b>선 방향 영향:</b> | 선 방향이 정상 결과에 얼마나 큰 영향을 주는지 조정합니다. |

### 입력 색상 교정

| 매개 변수 이름 | 설명 |

### 획

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>전역 배율 승수:</b> | 선에 대한 전체 배율 승수를 조정합니다. |
| <b>무작위 크기 조정:</b> | 무작위 크기 조절 변동의 양을 조정합니다. |
| <b>크기:</b> | 선 크기를 조정합니다. |
| <b>무작위 크기:</b> | 임의 크기 변동의 양을 조정합니다. |
| <b>무작위 색상:</b> | 무작위 색상 변경의 양을 조정합니다. |
| <b>선 경도:</b> | 선의 경도를 조정합니다. |
| <b>자동 방향 배율:</b> | 자동 방향이 획에 미치는 영향을 조정합니다. |
| <b>방향 Smoothness:</b> | 선 방향의 Smoothness을 조정합니다. |

### 밝은 영역

| 매개 변수 이름 | 설명 |
| --- | --- |

| <b>선 크기:</b> | 밝은 영역 레이어에 사용된 선 크기를 조정합니다. |

| <b>뒤틀기 강도:</b> | 밝은 영역 레이어의 뒤틀기 강도를 조정합니다. |
