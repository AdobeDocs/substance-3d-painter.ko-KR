## 설명

[MatFX Shut Line] 필터는 재질의 패널 라인 또는 이음새 세부 묘사를 만듭니다.

텍스처 층 또는 재료 스택에 사용되어 셧라인, 엠보싱 이음새 및 지지 Height 및 색상 세부 사항을 추가합니다.

</td>
</tr>

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>캐비티 너비:</b> | 캐비티의 폭을 조정합니다. |
| <b>경사 강도:</b> | 경사 효과의 강도를 조정합니다. |
| <b>엠보스 강도:</b> | 엠보싱의 강도를 조정합니다. |
| <b>Height 강도:</b> | Height 효과의 강도를 조정합니다. |

### 재질

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>선 색:</b> | 선 색상을 조정합니다. |
| <b>소스 재질 불투명도:</b> | 소스 재질의 불투명도를 조정합니다. |
