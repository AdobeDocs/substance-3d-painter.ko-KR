## 설명

MatFX Comic Book 필터는 만화책에서 영감을 받은 느낌으로 재질을 스타일링합니다.

이 렌더러는 텍스처 레이어에서 사용되어 단순화된 음영 및 대담한 시각적 처리 기능을 제공하는 그래픽, 일러스트레이션 렌더링 스타일을 만듭니다.

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| <b>앰비언트 오클루전:</b> 회색 음영 | 구운 앰비언트 오클루전 맵을 사용합니다. |
| <b>곡률:</b> 회색 음영 | 구워진 곡률 맵을 사용합니다. |
