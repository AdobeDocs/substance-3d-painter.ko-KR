# 스타일이 적용된 구운 조명

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

</td>

## 설명

Baked Lighting Stylized 필터는 색상 채널에 재질과 조명 정보를 제공합니다.

패스스루 모드로 설정된 레이어 페인팅에서 사용되며 모든 채널에 적용됩니다. 정확한 시뮬레이션 조명이 필요하지 않거나, 모바일 프로젝트 또는 색상 맵에만 의존하는 에셋 등과 같이 리소스가 제한된 경우 스타일화된 워크플로우에 유용합니다.

</td>
</tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| <b>앰비언트 오클루전:</b> 회색 음영 | 구운 앰비언트 오클루전 맵을 사용합니다. |
| <b>곡률:</b> 회색 음영 | 구워진 곡률 맵을 사용합니다. |
| <b>표준:</b> 색상 | 구운 노멀 맵을 사용합니다. |
| <b>월드 스페이스 표준:</b> 색상 | 구워진 World Space Normals 지도를 사용합니다. |

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>입력:</b> | 입력 자재 워크플로우를 선택합니다. |

| <b>유전 반사율:</b> | 유전체 반사율을 조정합니다. |
| <b>확산 AO:</b> | 확산 조명에 대한 앰비언트 오클루전 기여도를 조정합니다. |
| <b>확산 캐비티:</b> | 확산 조명에 대한 캐비티 기여도를 조정합니다. |
| <b>Specular AO:</b> | Specular 조명에 대한 앰비언트 오클루전 기여도를 조정합니다. |
| <b>Specular 캐비티:</b> | Specular 조명에 대한 캐비티 기여도를 조정합니다. |
| <b>캐비티 Smoothness:</b> | 캐비티 효과의 Smoothness을 조정합니다. |
| <b>가장자리 강도:</b> | 가장자리 효과의 강도를 조정합니다. |
| <b>가장자리 Smoothness:</b> | 가장자리 효과의 Smoothness을 조정합니다. |
| <b>일반 세부 정보 형식:</b> | 사용할 일반 세부 정보를 선택합니다. |
| <b>표준 강도로 Height:</b> | Height-표준 변환 강도를 조정합니다. |
| <b>태양 강도:</b> | 태양광의 강도를 조정합니다. |
| <b>태양 수평 각도:</b> | 태양 조명의 수평 각도를 조정합니다. |
| <b>태양 수직 각도:</b> | 태양 조명의 수직 각도를 조정합니다. |
| <b>태양 색상:</b> | 태양광의 색상을 조정합니다. |
| <b>하늘 강도:</b> | 하늘 조명의 강도를 조정합니다. |
| <b>하늘 색:</b> | 하늘 조명의 색상을 조정합니다. |
| <b>수평선 색상:</b> | 수평선 조명의 색상을 조정합니다. |
| <b>지표 색상:</b> | 지표 조명의 색상을 조정합니다. |
| <b>수평 각도:</b> | 추가 조명의 수평 각도를 조정합니다. |
| <b>수직 각도:</b> | 추가 조명의 세로 각도를 조정합니다. |
| <b>강도:</b> | 추가 조명의 강도를 조정합니다. |
| <b>색상:</b> | 추가 조명의 색상을 조정합니다. |
| <b>수평 각도:</b> | 두 번째 추가 조명의 수평 각도를 조정합니다. |
| <b>수직 각도:</b> | 두 번째 추가 조명의 세로 각도를 조정합니다. |
| <b>강도:</b> | 두 번째 추가 조명의 강도를 조정합니다. |
| <b>색상:</b> | 두 번째 추가 조명의 색상을 조정합니다. |

<td>캐비티 영역의 매끄러운 정도를 조정합니다.</td>
</tr>
<tr>

</tr>
<tr>
<td><b>가장자리 Smoothness:</b></td>
<td>가장자리 영역의 Smoothness을 조정합니다.</td>
</tr>

<td><b>일반 세부 정보 유형:</b></td>
<td>수직에 사용할 세부 정보(메쉬 전용 또는 메쉬 + Height + 표준)를 선택합니다.</td>
</tr>

<td><b>표준 강도로 Height:</b></td>

</tr>
