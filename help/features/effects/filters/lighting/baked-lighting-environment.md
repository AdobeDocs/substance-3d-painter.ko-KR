## 설명

베이크된 조명 환경 필터는 재질 및 환경 조명 정보를 색상 채널로 만듭니다.

패스스루 모드로 설정된 레이어 페인팅에서 사용되며 모든 채널에 적용됩니다. 정확한 시뮬레이션 조명이 필요하지 않거나, 모바일 프로젝트 또는 색상 맵에만 의존하는 에셋 등과 같이 리소스가 제한된 경우 스타일화된 워크플로우에 유용합니다.

</td>
</tr>
</table>

## 입력

| 입력 이름 | 설명 |
| --- | --- |
| <b>앰비언트 오클루전:</b> 회색 음영 | 구운 앰비언트 오클루전 맵을 사용합니다. |
| <b>환경 맵:</b> 회색 음영 | 환경 맵을 사용합니다. |
| <b>표준:</b> 색상 | 구운 노멀 맵을 사용합니다. |

<a name="parameters"></a>

## 매개변수

| 매개 변수 이름 | 설명 |
| --- | --- |
| <b>수평 회전:</b> | 환경 조명의 수평 회전을 조정합니다. |
| <b>수직 회전:</b> | 환경 조명의 세로 회전을 조정합니다. |
| <b>노출:</b> | 구워진 결과의 노출을 조정합니다. |
| <b>Height 강도:</b> | Height 정보가 결과에 미치는 영향을 조정합니다. |
| <b>앰비언트 오클루전 강도:</b> | 베이크의 앰비언트 오클루전 강도를 조정합니다. |
| <b>Specular 오클루전 강도:</b> | 베이크에서 Specular 오클루전의 강도를 조정합니다. |
