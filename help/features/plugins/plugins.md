# 플러그인

Substance 3D Painter에는 사용자 정의 플러그인 을 만들어 사용자 정의 기능 및 비헤이비어를 추가할 수 있는 전용 스크립팅 API가 있습니다.\
플러그인은 Javascript로 작성되며 QML 언어와 결합하여 애플리케이션 내에 사용자 정의 인터페이스를 만들 수 있습니다. API에서 사용할 수 있는 기능에 대한 자세한 내용은 스크립팅 설명서(애플리케이션의 도움말 메뉴에서 사용 가능)를 참조하십시오.

## 기본 플러그인

Substance 3D Painter에는 서로 다른 두 개의 기본 플러그인이 있습니다.

* [자동 저장](autosave.md)
* [리소스 업데이트 프로그램](resources-updater.md)
