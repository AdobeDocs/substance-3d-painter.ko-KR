# 리소스 업데이트 프로그램

![](../../assets/resources-updater-window.png)

**리소스 업데이트 프로그램** 플러그 인을 사용하면 현재 열려 있는 프로젝트에 있는 리소스를 검색할 수 있습니다.\
각 자원은 선반에 있는 다른 자원으로 대체될 수 있습니다. 빨간색으로 표시된 리소스는 &quot;오래된&quot; 리소스이며, 동일한 리소스가 다른 버전이 선반에 있고 (아마도) 더 최신 버전임을 의미합니다.
