# 자동 저장

![](../../assets/autosave-details.png){width="500px"}

자동 저장 플러그인을 사용하면 현재 열려 있는 프로젝트의 **백업을 작성**&#x200B;할 수 있습니다. 이렇게 하면 현재 프로젝트에 영향을 주지 않으면서 옆에 파일이 만들어집니다.

백업 파일은 다음 세 가지 위치에 있을 수 있습니다.

* 현재 프로젝트가 저장된 경우 백업이 프로젝트 옆에 표시됩니다.
* 프로젝트를 저장하지 않은 경우(제목 없음) 백업은 사용자의 문서 폴더에 있는 자동 저장 폴더에 저장됩니다. ( **Documents/Allegorithmic/Substance 3D Painter/autosave** )
* 재정의 설정이 활성화된 경우 백업은 설정에 지정된 경로에 위치합니다.

*자동 저장을 지연시키기 위해 인터페이스에서 다시 알림 단추를 사용할 수 있습니다.*

## 자동 저장은 어떻게 트리거됩니까?

자동 저장은 내부 타이머를 기반으로 하며, 타이머가 자동 저장 프로세스를 시작한 후에 시작됩니다.\
스누징 버튼은 타이머 종료 부근에 있을 때 자체적으로 활성화되므로 자동 저장을 몇 시간 동안 지연시킬 수 있습니다.

모든 시간 기반 값은 설정 창을 통해 수정할 수 있습니다.

## 자동 저장을 비활성화하는 방법

어떤 이유로 자동 저장 프로세스를 비활성화해야 하는 경우 플러그인 메뉴를 통해 수행할 수 있습니다. 그렇게 하려면 **플러그인** > **자동 저장** > **비활성화** 메뉴를 클릭하세요.

## 자동 저장 구성

자동 저장 동작을 구성하려면 **플러그인** > **자동 저장** > **구성** 메뉴를 클릭합니다.

* **자동 저장 간격(분)** : 각 자동 저장 사이에 대기할 시간을 나타냅니다.
* **자동 저장 파일 수**: 지정된 프로젝트에 대해 만들어진 최대 백업 파일 양입니다.
* **다시 알림 간격(분)** : 다시 알림 버튼을 클릭하면 자동 저장이 지연되는 시간입니다.
* **저장 전 경고 시간(초)** : 자동 저장 트리거 전에 스누징 버튼이 활성화되어 진행률 표시줄이 보이기 전까지의 시간입니다.

>[!NOTE]
>
> 다음의 경우 자동 저장 타이머가 일시 중지됩니다.
> 
> * 엔진이 계산을 하고 있다
> * 텍스처 내보내기 중
> * 구성 창이 열립니다.
> * 프로젝트를 현재 저장 중입니다.

창 아래쪽에서 백업 파일의 기본 위치를 덮어쓸 수 있습니다.\
&quot;**항상 다음 디렉터리에 저장**&quot; 설정을 사용하면 모든 백업 파일이 지정된 폴더에 저장됩니다(기본 경로는 사용자의 문서 폴더임).
