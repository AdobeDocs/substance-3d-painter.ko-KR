# 다음으로 전송

![배너 이미지](../assets/sendto_banner.jpg)

<b>보내기</b>은(는) 프로젝트에서 다른 응용 프로그램으로 리소스를 쉽게 내보내고 가져올 수 있는 작업으로, 수동으로 수행할 필요가 없습니다. 보내기 를 사용하여 3D 모델 및 해당 텍스처를 다른 렌더링 응용 프로그램으로 내보내거나 Substance 3D Designer에서 Substance 재질을 받을 수 있습니다.

보내기 작업은 <b>파일 > 보내기</b> 메뉴를 통해 사용할 수 있습니다.

현재 지원되는 <b>보내기</b>는 다음과 같습니다.

* <b>Photoshop</b>(으)로 보내기
* <b>Substance 3D Stager</b>(으)로 보내기
* <b>After Effects</b>(으)로 보내기

Painter은 다음과 같은 다른 애플리케이션에서 리소스를 수신할 수도 있습니다.

* <b>Substance 3D Designer</b>
* <b>Substance 3D Sampler</b>

리소스 수신에 대한 자세한 내용은 [전용 문서 페이지](../content/importing-assets/receiving-assets-from-other-substance-3d-applications.md)를 참조하십시오.

>[!NOTE]
>
> 일부 [보내기] 작업 과정은 Creative Cloud 데스크탑 소프트웨어와 기술적 종속 관계가 있으므로 Painter Adobe 버전에서만 사용할 수 있습니다.
> 
> 또한 필요한 소프트웨어가 설치되지 않은 경우 보내기 메뉴의 일부 작업을 사용할 수 없습니다.
