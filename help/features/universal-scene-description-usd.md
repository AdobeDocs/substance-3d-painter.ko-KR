# Universal Scene Description (USD)

![](../assets/banner-usd.jpg)

USD 워크플로우는 Painter 8.3에서 사용할 수 있습니다. [USD](https://graphics.pixar.com/usd/release/intro.html)은(는) 다양한 유형의 데이터를 전송할 수 있는 공동 작업 친화적인 교환 가능 형식으로 Pixar에서 개발했습니다.

Painter 환경에서 이제 다음을 수행할 수 있습니다.

* [프로젝트 만들기](../getting-started/project-creation.md)에서 범위와 변형 선택, 하위 수준 및 애니메이션 프레임 등 USD 관련 기능을 사용합니다.
* USD 형식을 사용하여 [재질 및 텍스처 내보내기](../export/export-window/export-settings.md).
* 또한 USD은 메시 전용 내보내기를 위한 새로운 파일 형식으로 추가되었습니다.
