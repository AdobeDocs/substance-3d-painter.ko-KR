# UV 타일

![](../../assets/banner-uvtiles.jpg)

UV 타일은 여러 UV 범위에서 두 개 이상의 텍스처 세트를 텍스처 세트 내에서 텍스처링하는 방법입니다.

기본적으로 일반 워크플로우에서는 텍스처가 각 UV 범위에서 반복됩니다. UV 타일을 사용하면 각 범위가 대신 전용 텍스처가 됩니다. 이 작업 과정을 통해 UV를 여러 텍스처 세트로 분할하여 일반 텍스처 해상도를 사실상 높일 수 있습니다. UV 타일은 현재 UDIM 명명 규칙만 지원합니다.

UV 타일 작업 과정에 대해 자세히 알아보려면 다음 페이지를 참조하십시오.

* UV 타일 워크플로를 사용하여 [프로젝트 만들기](../../getting-started/project-creation.md)를 수행하세요.
* [2D 보기](../../interface/viewport/2d-view.md)에서 UV 타일 보기
* 성능 향상을 위한 [UV 타일 마스크](../../interface/layer-stack/geometry-mask.md).
* [이미지 시퀀스](image-sequence.md)를 가져와 사용하는 중입니다.
* [텍스처 집합 설정](../../interface/texture-set/texture-set-settings.md)에서 UV 타일당 해상도를 조정합니다.

>[!NOTE]
>
> UV 타일 프로젝트 작업은 까다로울 수 있으며, 로딩 시간과 일반적인 성능을 개선하기 위해 SSD를 사용하는 것이 좋습니다. 또한 SSD에서도 캐시 위치를 설정하는 것이 좋습니다.
