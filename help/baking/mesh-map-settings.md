# 메시 맵 설정

<b>메시 맵 설정 패널</b>은 굽기 모드에서 사용할 수 있으며 굽기 위해 메시를 준비하는 컨트롤이 있습니다. 지정된 맵의 메시 맵 설정을 조정하려면 <b>메시 맵 베이커 패널</b>에서 맵을 선택합니다. 각 메시 맵에는 다른 설정을 사용할 수 있습니다. [메시 맵 베이커] 패널 위쪽에서 모든 메시 맵이 공유하는 <b>공통 설정 </b>의 컬렉션을 사용할 수 있습니다.

메시 맵 간에 공유되는 모든 설정은 각 개별 메시 맵이 아닌 일반 설정 페이지에 표시됩니다.

## 공통 설정

일반 설정 페이지에는 모든 메시 맵이 베이킹되는 방식에 영향을 미치는 컨트롤이 포함되어 있습니다.

### 출력 설정

| 설정 | 함수 |
| --- | --- |
| 출력 크기 | 생성된 메시 맵의 X 및 Y 해상도를 정의합니다. 사각형이 아닌 해상도를 허용하려면 잠금을 클릭합니다. |
| 확장 폭 | 구워진 정보가 UV 섬의 테두리를 벗어나는 정도를 조정합니다. |
| 확산 적용 | 생성된 정보의 가장자리에 확산을 적용하려면 이 상자를 활성화합니다. |

### 하이 폴리 파라미터

| 설정 | 함수 |
| --- | --- |
| 낮은 폴리 메쉬를 높은 폴리 메쉬로 사용 | 프로젝트 메시를 기반으로 맵을 굽으려면 이 설정을 활성화합니다. |
| 고해상도 메시 | 프로젝트에 높은 폴리 메쉬를 추가하여 높은 폴리 메쉬에서 프로젝트의 낮은 폴리 메쉬로 만듭니다. 여러 메시를 가져올 수 있습니다. |
| 케이지 | 베이킹 케이지가 생성되는 방식을 결정합니다.<ul data-preserve-html="true"> <li data-preserve-html="true">거리 기준: 모델에서 균일한 거리를 두고 메쉬에서 정점을 부풀려서 케이지를 만듭니다.</li> <li data-preserve-html="true">자동(시험적): Painter은 메쉬를 분석하고 케이지를 자동으로 생성하여 교차점을 만들지 않고도 케이지를 표면에 가깝게 유지해 최상의 결과를 얻을 수 있도록 합니다.</li> <li data-preserve-html="true">사용자 정의 파일: 케이지로 사용하기 위해 만든 파일을 가져옵니다. 불러온 파일은 기본 메쉬와 동일한 개수의 정점을 가져야 올바르게 작동합니다.</li> </ul> |
| 뒷면 무시 | 굽는 동안 뒷면을 무시할지 여부를 전환합니다. 이렇게 하면 아티팩트를 줄일 수 있지만 특정 에지 사례에서 오류가 발생할 수도 있습니다. |
| 일치 | 베이커가 베이킹 중에 개체를 포함할지 여부를 결정하는 방법을 변경합니다.<ul data-preserve-html="true"> <li data-preserve-html="true">항상: 베이킹하는 동안 케이지 내에 부딪히는 모든 높은 폴리 메쉬를 포함합니다.</li> <li data-preserve-html="true">메쉬 이름별: 각 케이지에 대해 해당 메쉬 접미사가 있는 메쉬만 구워냅니다.</li> </ul> |
| 로우 폴리 메시 접미사 | 메쉬 이름으로 일치를 사용하는 경우 이 접미어를 사용하여 낮은 폴리 메쉬를 정의합니다. |
| 하이 폴리 메시 접미사 | 메쉬 이름으로 일치를 사용하는 경우 이 접미어를 사용하여 높은 폴리 메쉬를 정의하고 해당 낮은 폴리 메쉬와 일치시킵니다. |
| 안티앨리어싱 | 생성된 맵의 앤티 앨리어싱 양을 조정합니다. |

#### 기울이기 보정

| 설정 | 설명 |
| --- | --- |
| **페인트 기울이기 수정** | 기울이기 교정 페인팅 모드를 시작합니다. |
| **에지 보호** | 가장자리 보호를 전환하여 굵은 가장자리에 가까운 페인팅된 기울이기 교정 값을 마스크합니다. |
| **가장자리 거리** | 가장자리 보호가 하드 가장자리에서 확장되는 정도 제어 |
| **가장자리 대비** | 가장자리 보호 그레이디언트가 전체 보호에서 보호 안 함으로 얼마나 급격하게 전환되는지 제어합니다. |

## ID 맵 설정

| 설정 | 함수 |
| --- | --- |
| 색상 소스 | ID 맵의 구운 색상이 결정되는 방법을 변경합니다.<ul data-preserve-html="true"> <li data-preserve-html="true">꼭지점 색상</li> <li data-preserve-html="true">자료 색상</li> <li data-preserve-html="true">파일 ID</li> <li data-preserve-html="true">메쉬 ID/폴리그룹</li> </ul> |
| 색상 생성기 | 파일 ID 또는 망 ID/폴리그룹을 색상 소스로 사용하는 경우 색상 생성 방법을 결정합니다.<ul data-preserve-html="true"> <li data-preserve-html="true">임의</li> <li data-preserve-html="true">색조 변경</li> <li data-preserve-html="true">회색 음영</li> </ul> |

## 앰비언트 오클루전 맵 설정

| 설정 | 함수 |
| --- | --- |
| 보조 광선 | 보조 광선 수를 변경합니다. 더 많은 광선들은 증가된 처리 시간의 비용으로 더 나은 결과들을 산출할 수 있다. |
| 최소 폐색기 거리 | 광선이 이동할 수 있는 최소 거리를 조정하여 높은 폴리 기하학에 도달하고 결과 AO 맵에 영향을 줍니다. |
| 최대 오클루더 거리 | 높은 폴리 메시에 부딪치지 않으면서 이 거리보다 더 연장되는 광선들은 폐색되지 않는 것으로 간주되고 AO 맵에 영향을 미치지 않을 것이다. |
| 테두리 상자에 비례 | 이 상자를 선택하면 프로젝트 메쉬의 테두리 상자를 기준으로 거리를 나타내는 다른 설정이 사용됩니다. 따라서 1의 거리는 테두리 상자의 크기와 같습니다. |
| 방사 각도 | 생성된 광선의 angular 범위를 조정합니다. 스프레드 각도가 높을수록 서피스에서 수직으로 위치하지 않는 형상에 의해 서피스가 보다 쉽게 가려질 수 있습니다. |
| 분포 | 광선이 분포하는 방식을 선택합니다. |
| 뒷면 무시 | 뒷면이 오브젝트를 폐색하는 것으로 간주되는지 여부를 변경합니다. |
| 자체 오클루전 | 현재 메시의 앰비언트 오클루전에 영향을 줄 메시를 선택합니다. |
| 감쇠 | 폐색기 거리에 의해 오클루전이 감쇄되는 방법을 변경합니다. |
| 지표 평면 | 이 옵션을 활성화하여 폐색기로 작동하는 그라운드 평면을 만듭니다. |
| 지표 평면 오프셋 | 지표 평면의 위치를 변경합니다. |

## 곡률 맵 설정

| 설정 | 함수 |
| --- | --- |
| 방법 | 곡률 맵을 생성하는 방법을 선택합니다. |
| 보조 광선 | 곡률 맵을 생성하는 데 사용되는 보조 광선 수를 조정합니다. 더 많은 보조 광선은 증가된 처리 시간의 비용으로 더 나은 결과들을 생성할 수 있다. |
| 샘플링 반경 | 베이커가 검색하는 정도를 조정하여 현재 점의 곡률을 계산합니다. |
| 테두리 상자 기준 | 이 옵션을 선택하면 모든 거리가 메시 테두리 상자의 크기에 따라 달라집니다. |
| 자체 교차 | 곡률을 결정할 때 고려할 오브젝트를 선택합니다. |
| 자동 톤 매핑(UV 타일당) | UV 타일 단위로 톤맵 곡률 맵을 자동으로 조정하려면 이 옵션을 선택한 상태로 둡니다. |
| 톤 매핑 최소 | [자동 톤 매핑]이 비활성화되어 있으면 톤 매핑의 최소값을 조정합니다. |
| 톤 매핑 최대 | [자동 톤 매핑]이 비활성화되면 톤 매핑의 최대값을 조정합니다. |

## 위치 맵 설정

| 축 | [단일 축] 모드를 선택한 경우 이 설정을 사용하여 계산할 축을 선택합니다. |
| 표준화 유형 | 테두리 상자, 테두리 구를 사용하여 위치 값을 정규화하거나 정규화를 비활성화하는 방법을 변경합니다. |
| 표준화 비율 | 위치 공간의 최대 경계로 간주되는 영역을 변경합니다. |
