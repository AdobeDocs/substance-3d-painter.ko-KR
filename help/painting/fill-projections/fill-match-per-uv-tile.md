# 칠(UV 타일 당 일치)

**채우기(UV 타일 당 일치)**&#x200B;은(는) [UV 타일](../../features/uv-tiles/uv-tiles.md) 프로젝트에 유용한 특수 2D 투영입니다. 이렇게 하면 각 UV 타일에 대한 시퀀스에서 UDIM 텍스처를 할당할 수 있습니다.

단일 이미지 이상이 각 UV 타일을 채우도록 할당되기 때문에 이 투영에는 전용 설정이 없습니다. 설정이 없으므로 이 모드도 성능에 더 좋습니다.

| 모드 | 설명 |
| --- | --- |
| **UV 투영** | 단일 이미지 또는 시퀀스의 첫 번째 이미지가 모든 UV 타일에 적용됩니다. 변형 컨트롤도 제공합니다. 자세한 내용은 [UV 투영](uv-projection.md)를 참조하세요. <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/uv-3.jpg" width="700px"/></div> |
| **채우기(UV 타일 당 일치)** | 시퀀스의 각 이미지는 전용 UV 타일에 할당됩니다. 변형 컨트롤은 없습니다. <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/fill-match.jpg" width="700px"/></div> |
