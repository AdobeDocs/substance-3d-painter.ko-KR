# Photoshop 브러시 매개 변수 호환성

이 페이지에는 모든 Photoshop 브러시 매개 변수 및 Substance 3D Painter 브러시 엔진과의 호환성이 나열됩니다.

## 일반 호환성

ABR 파일 내부를 보면 Substance 3D Painter이 특정 브러시/도구 사전 설정만 검색합니다.

| *사전 설정 유형* | *지원* | *설명* |
| --- | --- | --- |
| **브러시(비트맵)** | 가져옴 | 알파로 비트맵을 기반으로 한 브러시 사전 설정을 가져옵니다. |
| **브러시(프로시저)** | 무시됨 | 프로시저 모양(예: 원)을 기반으로 하는 브러시 사전 설정은 가져올 수 없습니다. |
| **브러시(에어브러시)** | 무시됨 | 에어브러시 설정이 있는 브러시 사전 설정은 가져올 수 없습니다. |
| **브러시(강모)** | 무시됨 | 강모 설정이 있는 브러쉬 사전 설정은 가져올 수 없습니다. |
| **브러시(침식성)** | 무시됨 | 흐림 효과 설정이 있는 브러시 사전 설정은 가져올 수 없습니다. |
| **연필** | 무시됨 | 연필 사전 설정은 가져올 수 없습니다. |
| **혼합 브러시** | 무시됨 | 혼합 브러시 사전 설정은 가져오지 않습니다. |
| **복제 도장** | 무시됨 | 복제 도장 사전 설정은 가져오지 않습니다. |
| **손가락** | 무시됨 | 손가락 사전 설정은 가져올 수 없습니다. |

## 매개변수

이러한 매개 변수가 수행할 수 있는 작업에 대한 자세한 내용은 공식 [Photoshop 설명서](https://helpx.adobe.com/photoshop/using/creating-modifying-brushes.html) 를 참조하십시오.

일부 Photoshop 브러시 매개 변수는 지원되지 않습니다. 아래에 설명된 각 매개 변수의 상태를 알려면 범례를 참조하십시오.

* **정사각형(■)** : 매개 변수가 지원됨을 나타냅니다. 액세스 방법은 설명을 참조하십시오.
* **십자(✖)** : 매개 변수가 지원되지 않음을 나타냅니다.

>[!NOTE]
>
> 브러시 사전 설정의 컨트롤 매개 변수는 펜 틸트, 페이드 및 펜 압력과 같은 다양한 방법을 통해 제어할 수 있지만 현재 **펜 압력**&#x200B;만 지원됩니다.
