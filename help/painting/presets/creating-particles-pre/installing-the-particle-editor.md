# 입자 편집기 설치

파티클 시스템 비헤이비어를 만들고 편집하려면 팝콘FX 편집기를 사용해야 합니다.\
다음 링크 중 하나에서 편집기를 다운로드합니다. [미러링 1](http://downloads.popcornfx.com/updates/1.5.5.20787/PopcornFx-Editor_Setup_v1.5.5.20787.exe), [미러링 2](https://www.dropbox.com/s/z1vwzvk2ywlug4p/PopcornFx-Editor_Setup_v1.5.5.20787.exe?dl=1).

>[!NOTE]
>
> Painter은 특정 버전의 지원이 필요하기 때문에 이전 버전의 편집기를 사용합니다. 자세한 내용은 [공식 위키](https://wiki.popcornfx.com/)를 참조하십시오.
