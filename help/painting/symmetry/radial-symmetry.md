# 방사형 대칭

방사형 대칭은 축을 중심으로 방사형으로 획 또는 칠 레이어 콘텐츠를 복제합니다.

![](../../assets/radial-demo.gif)

## 조작기를 사용하여 대칭 축의 위치 지정

3D 보기 위쪽의 컨텍스트 도구 모음에 있는 <b>대칭 설정 버튼</b>에서 대칭 표시 설정에 액세스할 수 있습니다. 디스플레이 설정에서 조작기를 활성화하고 사용자 정의할 수 있습니다. 3D 뷰에서 조작기 핸들을 드래그하여 대칭 축의 위치를 변경합니다.

![편집기가 뷰포트에 표시된 방사형 대칭 설정 패널의 스크린샷.](../../assets/RadialSymmetryManip.png){width="600px"}

## 방사형 대칭 매개변수

![속성 패널의 대칭 섹션의 스크린샷](../../assets/FillSymmetry_1.png){width="300px"}

| *매개 변수* | *설명* |
| --- | --- |
| <b>축</b> | 대칭을 수행하는 데 사용되는 장면의 축을 정의합니다. |
| <b>사본 뒤집기</b> | U축 또는 V축에서 교대되는 복사본을 뒤집습니다. 이는 텍스트와 같은 방향이 있는 콘텐츠에 대칭성을 사용할 때 도움이 됩니다. |
| <b>축 위치: X, Y, Z</b> | 프로젝트에서 축의 오프셋을 정의합니다. 이 값은 슬라이더나 조작기를 사용하여 편집할 수 있습니다(위 참조). |
| <b>축 표시</b> | 이 옵션을 활성화하면 대칭 축을 나타내는 투명 선이 뷰포트에 표시됩니다. |
| <b>교차점 표시</b> | 이 옵션을 활성화하면 대칭 축이 메쉬와 교차하는 위치를 나타내기 위해 뷰포트의 메쉬에 점이 그려집니다. |
| <b>커서 표시(브러시 도구)</b> | 활성화되면 두 번째 커서가 대칭의 반대쪽에 표시되어 페인팅이 수행되는 시기를 나타냅니다. |
| <b>페인팅하는 동안 숨기기(브러시 도구)</b> | 이 옵션을 활성화하면 두 번째 커서는 페인팅 진행 중(마우스 클릭이 해제될 때까지)에 숨겨집니다. |
| <b>축 위치 조작기 표시</b> | 뷰포트에서 조작기의 가시성을 전환합니다. |
| <b>조작기 크기</b> | 뷰포트에서 조작기의 크기를 제어합니다. |
