# 투영

![](../../assets/image2015-3-19-17-56-54.png){width="50px"}

투영 은 스크린/뷰포트 공간에 투영하여 재질을 페인팅할 수 있도록 하는 도구입니다. 스텐실과 유사한 컨트롤을 공유합니다.

**단축키 S**&#x200B;을 눌러 투영 변환을 편집할 수 있습니다.

* **S + 왼쪽 마우스 클릭**&#x200B;을 사용하여 스텐실을 회전합니다.
* **S + 왼쪽 마우스 클릭 + SHIFT**&#x200B;를 사용하여 스텐실 회전을 스냅/제한합니다.
* **S + 마우스 오른쪽 단추 클릭**&#x200B;을 사용하여 스텐실을 확대/축소합니다.
* **S + 마우스 가운데 버튼**&#x200B;을 클릭하여 스텐실을 번역합니다.
