# 도구 목록

이 페이지에서는 사용 가능한 모든 페인팅 도구와 사용 방법에 대해 자세히 설명합니다.

| *도구* | *설명* |
| --- | --- |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-paint.png" width="100px"/></div> | [페인트 도구](paint-brush.md)를 사용하면 특정 재질이 있는 브러쉬 획을 망 위에 적용할 수 있습니다. |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-eraser.png" width="100px"/></div> | [지우개](eraser.md)를 사용하면 기존 페인트 정보를 제거할 수 있습니다. |
|  | [패스 도구](path.md)를 사용하면 모델의 표면을 따라 몇 가지 다른 효과를 만들 수 있는 곡선을 정의할 수 있습니다. 브러시 획을 추가하거나, 페인트를 지우거나, 흐림 효과를 적용하거나, 지퍼나 균열 등 패스를 따라 세부 사항을 모두 추가할 수 있습니다. |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-projection.png" width="100px"/></div> | [투영](projection.md)을 통해 현재 시점에 정렬된 재질 또는 텍스처를 적용할 수 있습니다. |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r4-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-polygonfill.png" width="100px"/></div> | [다각형 채우기](polygon-fill.md)를 사용하면 3D 메시에서 다각형을 선택하여 도형을 기반으로 마스크를 만들 수 있습니다. |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r5-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-smudge.png" width="100px"/></div> | [손가락 도구](smudge-tool.md)를 사용하면 색상과 기타 재질 속성을 늘리고, 혼합하고, 흐리게 할 수 있습니다. |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r6-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-clone.png" width="100px"/></div> | [복제 도구](clone-tool.md)를 사용하면 3D 메쉬에 있는 기존 재질의 일부를 복제하거나 패치할 수 있습니다. |
| <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r7-column-c0_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/icon-materialpicker.png" width="100px"/></div> | [재질 피커]를 사용하면 3D 메시 표면에서 프로젝트의 재질 속성을 복사할 수 있습니다.  임시 도구입니다. 색상을 선택하면 이전 도구가 준비됩니다. |
|  | [빠른 마스크](quick-mask.md)를 사용하면 임시 마스크를 만들어 페인트를 적용할 수 있는 위치를 더 많이 제어할 수 있습니다. |
