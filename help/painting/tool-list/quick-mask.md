# 빠른 마스크

빠른 마스크를 사용하면 페인트하지 않을 메시 부분을 마스킹할 수 있습니다.

* **Y**&#x200B;을 눌러 빠른 마스크 편집 모드로 전환하면 임시 마스크를 페인트할 수 있습니다.
* **U**&#x200B;을(를) 다시 눌러 이전 도구로 다시 전환하고 해당 마스크 전체를 페인팅합니다.
* **Y**&#x200B;을 눌러 마스크를 다시 설정하거나 비활성화합니다.
* 빠른 마스크 편집 모드에서 마스크를 반전하려면 **I**&#x200B;을(를) 누릅니다.
