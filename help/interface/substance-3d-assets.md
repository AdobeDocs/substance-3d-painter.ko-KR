# Substance 3D Assets

![](../assets/v10_banner_3d_assets_2-1.jpg)

<b>Substance 3D Assets</b> 도크를 사용하면 응용 프로그램 내에서 직접 같은 이름의 온라인 라이브러리를 검색할 수 있습니다. 원본 라이브러리는 다음 주소에서 사용할 수 있습니다. <https://substance3d.adobe.com/assets>

>[!NOTE]
>
> Steam 버전의 애플리케이션에서는 Substance 3D Assets 창을 사용할 수 없습니다.

## 위치

기본적으로 이 창은 일반 에셋 창 옆에 있는 탭으로 고정되어 있습니다. 창이 닫히면 인터페이스의 맨 오른쪽에 있는 도킹 도구 모음에서 다시 열 수 있습니다.

![](../assets/v10_3dassets_location_tab.png)

![](../assets/v10_3dassets_location_dock.png)

### 에셋 검색

에셋을 검색하려면 창 내에서 사용 가능한 인터페이스를 사용합니다. 상단에는 검색을 구체화하는 검색 필드가 표시되며 필터를 사용할 수도 있습니다.

![](../assets/v10_3d_assets_search.jpg)

### 에셋 다운로드 중

에셋의 다운로드 버튼을 클릭하면 다운로드가 시작되고 창의 다운로드 관리자 내에 표시됩니다. 보려면 창의 왼쪽 하단 버튼을 클릭하면 됩니다.

이 목록은 애플리케이션의 현재 세션 중에 다운로드된 에셋만 표시합니다.

에셋을 다운로드하면 일반 <b>에셋</b> 창에 표시됩니다.

![](../assets/v10_3d_assets_download.png)

>[!NOTE]
>
> 리소스가 다운로드되는 위치는 기본 라이브러리에 따라 다릅니다. 이 위치는 환경 설정에서 변경할 수 있습니다. 전용 [문서 페이지](assets/adding-a-new-library.md)를 참조하세요.

### 제어 메뉴

창의 오른쪽 하단에 있는 버튼은 다음과 같은 몇 가지 동작을 제공합니다.

* <b>폴더 위치 열기</b>: 현재 라이브러리 위치로 파일 탐색기를 엽니다. 이를 통해 다운로드한 에셋(이전 세션 포함)을 디스크에 검색할 수 있습니다.
* <b>페이지 다시 로드</b>: 창 내에서 인터페이스를 다시 로드합니다.
* <b>이전 페이지</b>: 창 내에서 이전 인터페이스로 이동합니다.
* <b>다음 페이지</b>: 창 내의 다음 인터페이스로 이동합니다.
