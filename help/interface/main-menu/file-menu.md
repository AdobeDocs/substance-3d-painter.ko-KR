# 파일 메뉴

![](../../assets/file-menu.png){width="150px"}

파일 메뉴에는 프로젝트를 만들고 저장하는 작업과 리소스를 프로젝트로 내보내거나 가져오는 작업이 포함되어 있습니다.

| 액션 | 설명 |
| --- | --- |
| **새로 만들기** | 새 프로젝트 생성 창을 엽니다. 자세한 내용은 [프로젝트 만들기](../../getting-started/project-creation.md)를 참조하세요. |
| **열기** | 디스크에 있는 기존 프로젝트 파일을 엽니다. |
| **최근 파일** | 최근에 연 프로젝트를 모두 나열합니다. |
| **샘플 열기** | 응용 프로그램과 함께 제공되는 샘플 프로젝트 중 하나를 엽니다. |
| **닫기** | 현재 열려 있는 프로젝트를 닫습니다. |
| **저장** | 현재 프로젝트를 제자리에 저장합니다. |
| **저장 및 압축** | 현재 프로젝트를 제자리에 저장하고 압축합니다(디스크에서 설치 공간 감소). |
| **다른 이름으로 저장** | 현재 프로젝트를 새 이름과 위치로 저장합니다. |
| **복사본으로 저장** | 현재 프로젝트를 새 이름과 위치에 사본으로 저장하고 현재 프로젝트를 열어 둡니다. |
| **템플릿으로 저장** | 현재 프로젝트 설정을 새 프로젝트에 사용할 수 있는 템플릿 파일에 저장합니다. |
| **정리** | 현재 프로젝트에서 사용하지 않는 리소스를 제거합니다(다음 **저장** 후에 적용). |
| **리소스 가져오기** | 자원 임포트 창을 엽니다. |
| **메시 내보내기** | 현재 프로젝트를 3D 모델 파일로 내보낼 수 있는 메시 내보내기 창을 엽니다. |
| **텍스처 내보내기** | 현재 프로젝트를 비트맵 텍스처로 내보낼 수 있는 텍스처 내보내기 창을 엽니다. |
| **보내기** | 다른 응용 프로그램에 프로젝트를 보내려면 모든 **보내기** 작업을 나열합니다. |
| **종료** | 애플리케이션을 닫습니다. 현재 프로젝트에 저장되지 않은 변경 사항이 있는 경우 메시지가 표시됩니다. |

>[!NOTE]
>
> 프로젝트를 저장하는 것은 두 가지 방법으로 할 수 있습니다.
> 
> * **증분** : 일반 저장을 수행할 때 사용되는 기본 메서드입니다. 변경된 정보만 디스크의 프로젝트 파일에서 업데이트됩니다. 이 방법을 사용하면 프로젝트 파일을 완전히 다시 작성할 필요 없이 프로젝트를 매우 빠르게 저장할 수 있습니다.
> * **전체/압축** : 정리 작업을 수행하거나 프로젝트를 &quot;저장 및 압축&quot; 동작으로 저장하면 메서드가 디스크에 프로젝트를 완전히 다시 씁니다. 이 방법을 사용하면 프로젝트 조각화를 제거하고 설치 공간을 줄일 수 있습니다. 참조: [프로젝트가 매우 큽니다](../../technical-support/workflow-issues/project-issues/projects-are-really-big.md).
