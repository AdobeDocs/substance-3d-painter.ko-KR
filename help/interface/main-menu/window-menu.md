# 창 메뉴

![](../../assets/window-menu.png)\
창 메뉴를 통해 창 목록과 인터페이스에 표시되는 창을 표시할 수 있습니다. 도구 모음 메뉴를 사용하여 일부 도구 모음을 숨길 수도 있습니다.

| 액션 | 설명 |
| --- | --- |
| **보기** | 인터페이스에서 사용 가능한 창을 나열합니다. (확인란은 현재 표시되어 있는지 여부를 나타냅니다.) |
| **도구 모음** | 인터페이스에서 사용 가능한 도구 모음을 나열합니다(확인란을 선택하면 현재 표시되는지 표시되며 전환할 수 있음). 도킹, 플러그인 및 도구 |
| **UI 숨기기** | 인터페이스의 모든 창과 도크를 숨기고 뷰포트를 최대화합니다. |
| **UI 재설정** | 현재 창 레이아웃을 기본값으로 다시 설정합니다. |
