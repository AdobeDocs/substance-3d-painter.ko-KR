# 뷰포트 메뉴

![](../../assets/viewport-menu.png)

뷰포트 메뉴는 [뷰포트](https://substance3d.adobe.com/)의 표시 모드를 변경하는 데 사용할 수 있습니다.

| 액션 | 설명 |
| --- | --- |
| **표시 재질** | 뷰포트를 **재질** 모드로 전환하여 조명과 음영이 있는 3D 모델을 표시합니다. |
| **다음 채널 표시** | 뷰포트를 솔로 모드로 전환하여 다음 텍스처 세트 채널을 표시합니다. |
| **이전 채널 표시** | 뷰포트를 솔로 모드로 전환하여 이전 텍스처 세트 채널을 표시합니다. |
| **다음 메시 맵 표시** | 뷰포트를 솔로 모드로 전환하여 다음으로 구워진 메시 맵 유형을 표시합니다. |
| **이전 메시 맵 표시** | 이전에 구운 메시 맵 유형을 표시하려면 뷰포트를 솔로 모드로 전환합니다. |
| **전체 메시 표시** | 뷰포트 카메라를 3D 모델 중앙에 배치합니다. |
| **활성화된 빠른 마스크** | 자세한 내용은 [빠른 마스크](../../painting/tool-list/quick-mask.md) 페이지를 참조하세요. |
| **빠른 마스크 편집** | 자세한 내용은 [빠른 마스크](../../painting/tool-list/quick-mask.md) 페이지를 참조하세요. |
| **빠른 마스크 반전** | 자세한 내용은 [빠른 마스크](../../painting/tool-list/quick-mask.md) 페이지를 참조하세요. |

표시 모드에 대한 자세한 내용은 [표시 설정](../display-settings/display-settings.md)을 참조하세요.

빠른 마스크에 대한 자세한 내용은 [전용 페이지](../../painting/tool-list/quick-mask.md)를 참조하세요.
