# 편집 메뉴

![](../../assets/edit-menu.png)\
편집 메뉴를 통해 실행 취소/다시 실행 작업에 빠르게 액세스할 수 있을 뿐 아니라 프로젝트 설정 및 전역 설정에도 액세스할 수 있습니다.

| 액션 | 설명 |
| --- | --- |
| **실행 취소** | [기록](../history.md)스택에서 한 단계 뒤로 이동합니다. |
| **다시 실행** | [기록](../history.md)스택에서 한 단계 앞으로 이동합니다. |
| **프로젝트 구성** | 현재 프로젝트의 [프로젝트 설정](../project-configuration.md) 창을 엽니다. |
| **설정** | 일반 [응용 프로그램 설정](../settings/settings.md) 창을 엽니다. |
| **메시 맵 굽기** | [굽기](../../baking/baking.md) 창을 엽니다. |
