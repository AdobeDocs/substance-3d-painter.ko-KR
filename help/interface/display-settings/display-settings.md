# 디스플레이 설정

![](../../assets/display-settings-2.png){width="320px"}

**디스플레이 설정** 창에서 환경, 카메라 및 뷰포트 설정을 다시 그룹화합니다. 이 설정은 프로젝트에 대해 전체적으로 적용되며 뷰포트의 모양에 영향을 줄 수 있습니다.

## 보기 모드

![](../../assets/viewmode.png)

뷰 모드는 뷰포트의 모양을 제어합니다. 드롭다운은 세 개의 섹션으로 나뉩니다.

| 섹션 | 설명 |
| --- | --- |
| **조명** | 활성화된 경우 그림자를 포함하여 전체 조명이 있는 3D 모델을 뷰포트에 표시합니다. |
| **단일 채널** | 단독 모드라고도 합니다. 조명이 켜지지 않은 상태에서 특정 채널이나 텍스처만 메시를 뷰포트에 표시합니다. |
| **메시 맵** | 조명이 켜지지 않은 상태에서 구워진 특정 텍스처의 메시만 뷰포트에 표시합니다. |

>[!NOTE]
>
> [뷰포트](../../interface/viewport/viewport.md)의 모서리에 있는 <b>드롭다운</b>을 사용하여 보기 모드를 변경할 수도 있습니다. 채널, 메시 맵 사이를 빠르게 순환하고 재질 모드로 돌아가는 데 사용할 수 있는 [단축키](../settings/shortcuts.md)도 있습니다.
