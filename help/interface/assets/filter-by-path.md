# 경로로 필터링

**경로별 필터링**&#x200B;은(는) 에셋을 탐색하는 데 사용할 수 있는 추가 섹션입니다. 탐색 경계와 동일한 구조를 가지므로 에셋의 경로/위치를 볼 수 있습니다.

![](../../assets/01-01-panel.jpg)

기본적으로 **적용할 수 없는 폴더 숨기기**&#x200B;가 활성화되어 UI에서 빈 폴더를 숨길 수 있습니다. 이 기능은 예를 들어 경로로 필터를 특정 검색어와 결합하거나 에셋 유형을 선택하는 경우 편리할 수 있으며, 검색을 포함하는 관련 위치만 확인할 수 있습니다.

![](../../assets/01-02-hideempty.gif)
