# 하위 라이브러리 탭

하위 라이브러리는 특정 검색 전용의 Substance 3D Painter 새 탭 또는 창입니다.\
기본적으로 열리는 하위 라이브러리 탭은 없으며 기본 에셋 창만 열립니다. 기본 에셋 창에서 다음 두 가지 방법으로 하위 라이브러리 탭을 만들 수 있습니다.

* 저장된 검색 중 하나를 **마우스 오른쪽 단추로 클릭**&#x200B;하고 **새 탭 만들기**&#x200B;를 선택합니다.

![](../../assets/08-01-sublibrary.jpg)

* **검색 쿼리를 선택하거나 입력**(에셋 유형, 탐색 경로, 텍스트 쿼리 또는 경로별 필터링)한 다음 에셋 창 아래쪽에 있는 전용 **단추**&#x200B;를 사용합니다.

![](../../assets/08-02-sublibrary.jpg)

하위 라이브러리를 만들면 자동으로 새 탭이 만들어지고 기본 에셋 창과 같은 공간 내의 인터페이스에 **고정**&#x200B;됩니다.

여기에서 하위 라이브러리 창은 다른 위치에 도킹되거나 인터페이스 또는 다른 화면의 아무 곳에나 자유롭게 떠 있을 수 있습니다.

>[!NOTE]
>
> * 하위 라이브러리는 기본 에셋 창과 기능이 동일하지만 재설정할 때 원래 검색 쿼리로 되돌아갑니다.
> * 메인 에셋 창과 달리 하위 라이브러리를 닫으면 다시 만들어야 합니다.
> * 저장된 검색이 제거되면 하위 라이브러리 창은 닫힐 때까지 계속 존재합니다.
