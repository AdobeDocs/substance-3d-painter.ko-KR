# 메시 맵 설정 패널

[**베이킹 모드**](../../baking/baking.md)&#x200B;에서 **메시 맵 설정 패널**&#x200B;은 **메시 맵 베이커 패널**&#x200B;에 현재 선택한 메시 맵 유형에 대한 매개 변수를 표시합니다.

[**일반 설정**](common-mesh-map-settings.md) 및 **메시 맵 설정 패널**&#x200B;에서 사용할 수 있는 메시 맵 설정의 전체 목록은 [설명서의 굽기 섹션](../../baking/mesh-map-settings.md)에서 사용할 수 있습니다.
