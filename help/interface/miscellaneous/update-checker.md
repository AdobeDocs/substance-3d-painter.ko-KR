# 업데이트 검사기

![](../../assets/update-cc.png)

Creative Cloud 데스크탑에서 Substance 3D Painter 업데이트를 확인할 수 있습니다. 앱 탭으로 이동한 다음 설치된 앱 섹션을 확인합니다. 업데이트를 다운로드할 준비가 되면 **업데이트 사용 가능**&#x200B;이 앱 이름 아래에 표시됩니다.

Painter을 열고 **도움말 > 릴리스 정보**&#x200B;를 사용하여 현재 릴리스에 대한 릴리스 정보에 액세스할 수 있습니다.
