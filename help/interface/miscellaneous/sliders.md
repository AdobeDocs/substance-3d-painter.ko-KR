# 슬라이더

이 페이지에서는 응용 프로그램 인터페이스에서 슬라이더를 사용하는 방법을 보여 줍니다.

| 액션 | 예 | 설명 |
| --- | --- | --- |
| **드래그** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r1-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/drag-slider.gif"/></div> | 슬라이더를 마우스로 가리키면 클릭하고 드래그하여 값을 변경합니다. |
| **정밀도 드래그** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r2-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/precision-slider.gif"/></div> | 슬라이더의 드래그 거리를 늘리려면 클릭하는 동안 키보드에서 Shift 키를 누르고 유지합니다. 이 단축키를 사용하면 슬라이더를 드래그하는 동안 더 정확하게 조정할 수 있습니다. |
| **이동** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r3-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/jump-slider.gif"/></div> | 슬라이더의 아무 곳이나 클릭하여 마우스 위치 아래의 값으로 이동합니다. |
| **위/아래** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r4-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/up-down-sliders.gif"/></div> | 슬라이더를 클릭하여 포커스를 가져온 후 키보드의 위쪽 및 아래쪽 화살표 키를 사용하여 값을 단계별로 늘리거나 줄입니다. |
| **값 버전** | <div><img class="" data-preserve-html="true" id="root_content_flex_items_position_position-par_dx_table_row-r5-column-c1_dynamic_grid_items_grid-cell_position-par_image" src="../../assets/value-edit-slider.gif"/></div> | 슬라이더 바로 위의 텍스트 필드를 클릭하여 키보드를 통해 해당 값을 수동으로 편집합니다. |
