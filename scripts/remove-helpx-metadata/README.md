# 레거시 HelpX 메타데이터 제거

Python 3.10 이상을 사용하는 경우 저장소 루트에서 다음 명령을 실행합니다.

```shell
python remove_helpx_metadta.py 1 <path>
python remove_helpx_metadta.py 2 <path>
```

`1` 모드는 드라이 실행입니다. 일치하는 파일을 나열하고 파일 수를 보고합니다
파일을 변경하지 않고 스캔한 파일, 일치하는 파일 및 일치하는 메타데이터 필드
`2` 모드에서는 해당 필드를 제거하고 제거 횟수를 보고합니다. `<path>` 생략
현재 폴더를 검색합니다. 공백이 포함된 견적 경로입니다.

스크립트는 `.md`개의 파일을 재귀적으로 스캔하고(대/소문자 구분 안 함) 최상위 수준을 제거합니다.
이름이 `helpx`(으)로 시작하는 YAML 맨위 필드(여러 줄 포함)
값. 다른 메타데이터, 주석, 빈 줄, 마크다운 내용,
인코딩 및 줄 끝. 본문에서 `helpx` 참조를 제거하지 않습니다.
모드 `2`을(를) 사용하기 전에 드라이 실행을 검토하십시오.
백업 생성 파일 오류 및 미완료 앞면 문제가 보고되고 생성됩니다.
0이 아닌 종료 상태입니다. 앞면이 닫히지 않은 파일은 변경되지 않은 상태로 유지됩니다.
